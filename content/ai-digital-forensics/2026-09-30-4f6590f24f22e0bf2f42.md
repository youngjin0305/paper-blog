# Agentic Tool-Augmented Reasoning for Explainable Image Forgery Detection

[원문](https://arxiv.org/abs/2609.39066v1) · [PDF](https://arxiv.org/pdf/2609.39066v1)

## 한눈에 보기

이미지 위조의 탐지·국소화·설명을 하나의 다중 턴 추론 과정으로 묶은 에이전트 프레임워크 ATAR를 제시한다. 사법 포렌식 전문가의 "실험적 분석 – 논리적 추론 – 과학적 증거" 절차를 모사해 22개 포렌식 도구를 자율 호출하며, 6개 zero-shot IMDL 벤치마크에서 image-level F1 78.5%로 최강 MLLM 기준선을 11.8 퍼센트포인트 앞선다.

## 초록

기존 이미지 위조 탐지(image forgery detection) 방법은 해석 가능한 증거 없이 이진 점수나 픽셀 수준 마스크만 산출하며, 최근의 멀티모달 대형 언어 모델(multimodal large language model, MLLM) 기반 접근은 증거로부터 추론하는 것이 아니라 이미 정해진 분류 결과에 대한 사후(post-hoc) 설명을 생성한다. 인간 사법 전문가의 포렌식 작업 절차(forensic workflow)에서 착안하여, 우리는 7개의 상호 보완적 도메인에 걸친 22개의 특화된 포렌식 도구를 통합해 다중 턴 추론(multi-turn reasoning)을 통해 이미지 위조를 자율적으로 탐지·국소화·설명하는 프레임워크인 Agentic Tool-Augmented Reasoning(ATAR)을 제안한다. Dual-Stream Forensic Reasoning 패러다임은 의심 영역을 확대해 세밀하게 검사하는 high-level semantic anomaly path와, 포렌식 도구를 호출해 객관적 증거를 추출하는 low-level forgery artifact path를 결합한다. 여기에 Forensics Curriculum Learning을 도입한다. General Experience SFT 단계에서는 자동화된 교사–학생(teacher-student) 멘토링 파이프라인이 다중 턴 도구 사용 추론 궤적(reasoning trajectory)을 합성하고, Forensic Scene RL 단계에서는 Tool Prior Curriculum이 초기 도구 탐색을 안내하면서 점진적으로 제어권을 에이전트에게 이전하며, Structured Evidence Reward가 세밀한 과정 수준(process-level) 감독을 제공한다. IMDL, Deepfake detection, DMDL, AIGC detection에 걸친 실험은 ATAR가 6개의 zero-shot IMDL 벤치마크에서 평균 image-level F1 78.5%를 달성하여 가장 강한 MLLM 기준선을 11.8 퍼센트포인트 앞서고, 다른 과제에서도 특화 탐지기(specialized detectors)와 경쟁력을 유지하면서 훨씬 더 충실하고 근거에 기반한(faithful and grounded) 설명을 산출함을 보여준다.

## 필요성

생성형 AI [19, 50]와 이미지 편집 기술의 급속한 발전으로 위조 이미지의 양과 사실성이 꾸준히 증가하고 있으며, 이는 뉴스 신뢰성, 포렌식 수사, 금융 신원 확인에 점증하는 위협이 되고 있다 [41, 59]. 저자들은 효과적인 위조 탐지가 세 가지를 동시에 요구한다고 정리한다. 이미지가 조작되었는지 분류하고, 조작된 영역을 국소화하고, 그 판단에 대해 해석 가능한 추론을 제시하는 것이다.

그러나 기존 방법은 이 요구의 일부만 충족한다. 기존 image manipulation detection and localization(IMDL) 방법 [5, 17, 30]은 경계 아티팩트, JPEG 압축 불일치, 주파수 영역 이상 같은 low-level 위조 단서 [9, 57]를 포착하지만, 블랙박스 성질 때문에 해석 가능한 추론을 제공하지 못하고 판단에 대한 추적 가능한 증거(traceable evidence)를 만들지 못한다. 반대로 MLLM 기반 접근 [25, 38, 68]은 탐지 모듈과 언어 생성 [37, 61]을 결합해 예측과 텍스트 설명을 함께 내놓지만, 탐지 결정은 모듈이 독립적으로 생산하고 언어 모델은 이미 정해진 결과를 말로 바꿔 쓰는 데 그친다. 더구나 시각 인코더는 low-level 흔적에 대한 지각이 없어 [47], 명백한 의미적 결함이 없을 때 그럴듯하지만 근거 없는 설명을 만들어내도록 강요된다. 두 경우의 핵심 한계는 같다. 분석과 추론이 분리되어 있어 근거에 기반한 설명을 생산할 수 없다는 것이다.

## 연구 분야 흐름

딥러닝 기반 위조 탐지는 low-level 흔적 포착을 축으로 발전해 왔다. 경계 및 noise-view 아티팩트 [5, 9, 67], JPEG 압축 불일치 [30], 고주파 객체 수준 특징 [60], 학습된 noise fingerprint [17]가 대표적이다. AI 생성 이미지에 대해서는 생성기들이 공유하는 아티팩트 [62], diffusion 재구성 오차 [64], 혹은 동결된 CLIP-ViT 특징 [43]을 활용하는 방법이 제시되었다. 이들은 높은 정확도를 달성하지만 해석 가능한 증거를 전혀 제공하지 않는다.

해석 가능성 문제에 대응해 최근 연구는 MLLM [37, 61]을 위조 탐지에 적용한다. 한 갈래는 MLLM에 전용 포렌식 모듈, 즉 mask-aware 추출기 [38], 도메인 유도 탐지기 [6, 68], trace 인코더 [56]를 붙여 의미적 단서와 low-level 단서를 융합한다. 다른 갈래는 탐지를 추론 과제로 재정식화하여 이중 분기 인코더 [15], 가설적 프롬프팅 [25], GRPO 기반 추론 학습 [23]을 사용한다.

또 하나의 흐름은 tool-augmented reasoning이다. 모델이 다중 턴 추론 중 이미지와 능동적으로 상호작용하도록 하는 연구들이 늘고 있으며, RL로 유인한 인터리브 추론으로 crop·zoom·재검사를 학습시키는 방법 [20, 31, 63, 74], 점진적 visual grounding 커리큘럼 [44], RL 기반 외부 도구 호출 [55], plug-and-play visual search [33]가 있다. 더 넓게 tool-augmented LLM에서는 ReAct [69]가 추론과 행동을 교차시켜 환각을 줄이고, T²Agent [10]가 MCTS와 모듈형 도구를 조율해 멀티모달 허위정보를 탐지한다. 학습 측면에서는 GRPO [51]가 critic을 그룹 내 정규화로 대체했고, 커리큘럼 전략 [71, 75]은 탐색 과정에서 점진적으로 제거되는 계층적 가이드를 제공한다.

## 관련 연구

논문은 관련 연구를 두 축으로 정리한다. 첫째 축인 Image Forgery Detection and MLLMs에서 저자들은 CLIP [47] 같은 MLLM 시각 인코더가 high-level 의미를 위해 설계되었기 때문에 JPEG 아티팩트 비정렬이나 노이즈 이상 같은 low-level 흔적을 지각할 수 없다는 점을 지적한다. 진정한 low-level 증거가 없으면 모델은 근거 없는 설명을 환각할 수 있으며, 외부 포렌식 도구로 이 간극을 메운 기존 방법은 없다고 명시한다.

둘째 축인 Tool-Augmented Reasoning에서는 위의 기법들을 위조 탐지에 적용할 때 두 가지 난점이 생긴다고 본다. 하나는 기존 보상 설계가 분류, 국소화, 증거 품질을 하나의 점수로 뭉뚱그린다는 점이고, 다른 하나는 도구 공간이 큰 상황에서 무작위 탐색이 비효율적인데도 현재 커리큘럼은 도구 선택 수준이 아니라 프롬프트 수준에서 작동한다는 점이다. 비교 대상으로 사용된 선행 연구는 기존 IMDL 탐지기 MVSS-Net [5], TruFor [17], ForMa [18], SparseViT [54], MLLM 기반 탐지기 FakeShield [68], SIDA-7B [24], 범용 MLLM GPT-5.4 [53], Gemini-2.5-Pro [8], Qwen3-VL-8B [1], 그리고 문서 도메인의 APSC-Net [46], PSCC-Net [39], AIGC 도메인의 UnivFD [43], DRCT [3]이다.

## 배경 지식

**사법 포렌식 작업 절차.** 논문의 설계 근거는 사법 포렌식 실무에 이미 확립된 방법론이다. 인간 전문가는 구조화된 3단계 절차 [13, 40]를 따른다. 실험적 분석(experimental analysis), 논리적 추론(logical reasoning), 과학적 증거(scientific evidence)이다. 실험적 분석 단계에서 전문가는 먼저 이미지의 의미적 이상 [27]을 살피고, 이어 의심 영역을 확대해 정밀 검사한다. 의미적 결함이 드러나지 않을 때는 특수 장비 [4, 14, 65]를 적용해 육안으로 보이지 않는 신호 수준 흔적을 드러낸다. 그다음 수집된 실험 결과에 대해 논리적 추론을 수행해 판단을 형성하고, 최종 결론을 추적 가능한 근거 사슬과 함께 과학적 증거로 제시한다.

**두 유형의 위조 단서.** 저자들은 위조 단서를 두 개의 최상위 유형 [36]으로 분류한다. High-level Semantics는 물리 법칙이나 상식적 논리를 위반하는 위조로, 의심 영역을 crop·확대해 의미적으로 분석함으로써 식별한다. Low-level Artifacts는 의미적으로는 결함이 없어 보이지만 신호 수준 패턴에 존재하는 지각 불가능한 이상으로, 검증을 위해 반드시 분석 도구를 호출해야 한다. 두 경로는 상호 배타적이지 않으며, 한 방향이 충분한 증거를 주지 못하면 모델이 경로를 전환할 수 있다.

**도구 라이브러리와 행동 태그.** 도구 라이브러리는 7개의 상호 보완적 도메인에 걸친 22개 비지도(unsupervised) 도구를 제공한다. 압축 아티팩트, 센서 노이즈, 통계·주파수 분포, 구조적 불일치, copy-move 중복, AI 생성 특유 패턴, 그리고 기반 모델 기반 이상 탐지(DINOv3 [52] Layer 4 특징에 주성분 분석(principal component analysis, PCA)으로 차원을 축소한 Mahalanobis distance)이다. 각 추론 턴은 텍스트와 하나의 행동 태그 [69]를 담는다. `<grounding>`은 정규화된 바운딩 박스 $[x_1,y_1,x_2,y_2] \in [0,1]^4$와 대상 객체 설명으로 영역을 지정해 crop을 유발하고, `<tool_call>`은 도구를 호출하며, `<answer>`는 최종 판정과 추적 가능한 증거 사슬을 전달한다. 환경은 결과를 다음 턴의 입력으로 반환한다.

**학습 알고리즘 배경.** 정책 최적화에는 GRPO [51]를 사용하며, 그룹 내 정규화와 비대칭 클리핑 [71]($\epsilon^- < \epsilon^+$)을 적용해 양의 이점(advantage)을 가진 궤적에 더 큰 업데이트를 허용한다. 목적함수는

$$\mathcal{L}_{\text{GRPO}} = -\mathbb{E}_q\left[\frac{1}{G}\sum_{i=1}^{G}\min\left(\rho_i \hat{A}_i,\ \text{clip}(\rho_i, 1-\epsilon^-, 1+\epsilon^+)\hat{A}_i\right)\right] + \beta D_{\text{KL}}(\pi_\theta \| \pi_{\text{ref}})$$

이며, 여기서 $\rho_i = \pi_\theta(o_i|q)/\pi_{\text{old}}(o_i|q)$, $\hat{A}_i = (r_i - \mu_G)/\sigma_G$이다.

## 문제 정의

입력 이미지 $I$가 주어지면 모델은 진위 판정 $\hat{y} \in \{\text{authentic}, \text{forged}\}$, 편집된 객체에 대한 텍스트 설명 $\{\hat{e}_1, \ldots, \hat{e}_P\}$(예: 중앙의 호랑이가 splice되었다는 식의 서술), 그리고 과학적 증거를 구성하는 해석 가능한 추론 궤적 $o$를 산출해야 한다. 추론 중 모델은 지정한 영역을 crop해 확대된 국소 세부를 얻거나, $I$와 동일한 공간 해상도의 히트맵을 생성하는 분석 도구 라이브러리 $\mathcal{T} = \{T_1, \ldots, T_{22}\}$에서 도구를 호출할 수 있다.

이 설정에서 세 층위의 문제가 존재한다. 첫째, 분석과 추론의 분리다. 기존 IMDL은 추론과 증거가 없고, MLLM 기반 방법은 결론이 선행되고 설명이 뒤따르므로 어느 쪽도 근거에 기반한 설명을 만들 수 없다. 둘째, 학습 데이터의 부재다. 기존 위조 데이터셋에는 다중 턴 추론 주석이 없고, 도구가 교차된 다중 턴 궤적을 수작업으로 주석하는 비용은 감당할 수 없는 수준이다. 셋째, 강화학습 자체의 두 난점이다. SFT 이후 모델은 다중 턴 추론 형식은 습득했지만 22개 후보 중 최적 도구를 자율적으로 선택하지 못한다. 잘못 고른 도구는 추론 턴을 낭비하는 데 그치지 않고 무관한 하이라이트를 증거로 취급하게 만들어 모델을 능동적으로 오도하며, 대부분의 선택이 무정보 증거를 낸다면 RL 신호가 너무 희소해 학습이 되지 않는다. 또한 모델은 결함 있는 추론을 통해서도 올바른 판정에 도달할 수 있으므로, 단일 스칼라 보상은 최종 답과 추론 과정을 혼동해 그러한 행동을 강화하게 된다.

## 주요 기여

- **ATAR와 Dual-Stream Forensic Reasoning.** 다중 턴 상호작용 추론을 통해 사법 포렌식 작업 절차를 재현하는 패러다임을 제안하여, MLLM이 포렌식 도구를 자율적으로 호출하고 과학적 증거를 산출할 수 있게 한다. High-level semantic anomaly path는 의심 영역을 확대해 세밀 검사하고, low-level forgery artifact path는 7개 도메인의 22개 비지도 도구를 호출해 객관적 증거를 추출한다.
- **Forensic Reasoning Trajectory Synthesis.** 원시 위조 데이터셋을 다중 턴 도구 증강 추론 궤적으로 변환하는 자동화된 교사–학생 파이프라인을 설계하여 General Experience SFT 단계에 공급한다. 각 단계가 도구 출력 또는 의미적 관찰에 근거한, 실제 탐색적 추론을 담은 궤적을 생성한다.
- **Forensic Scene RL.** 초기 도구 탐색을 안내하고 제어권을 점진적으로 에이전트에 이전하는 Tool Prior Curriculum과, 분류·국소화·추론 품질에 대해 독립적으로 검증 가능한 항목으로 감독을 분해하는 Structured Evidence Reward를 제안한다.

성능 측면의 기여로, 저자들은 IMDL [11, 21], Deepfake detection [76], document manipulation detection and localization(DMDL) [72], AI-generated content(AIGC) detection에서 최신 성능을 보고한다. 6개 zero-shot IMDL 벤치마크에서 image-level F1 78.5%와 pixel-level F1 56.4%로 TruFor 대비 각각 +5.6 퍼센트포인트(pp), +6.0 pp를 기록했고, Deepfake detection에서 F1 99.9%, AIGC 학습 데이터를 전혀 쓰지 않고도 AIGC detection에서 F1 87.0%를 달성했으며, true positive에서의 추론 환각을 7.2%로 낮췄다. Forensics Curriculum Learning은 도구 정확도를 41.8%에서 72.0%로 끌어올렸고, Structured Evidence Reward는 과학적 증거가 조작되지 않고 충실하도록 보장한다.

## 제시한 방법론

ATAR(Agentic Tool-Augmented Reasoning)은 사법 감정 전문가의 작업 흐름인 "실험적 분석 – 논리적 추론 – 과학적 증거(experimental analysis – logical reasoning – scientific evidence)"를 멀티모달 대규모 언어 모델(multimodal large language model, MLLM)의 다중 턴(multi-turn) 추론으로 재현하는 에이전트 프레임워크다. 각 턴마다 모델은 의심 영역을 확대해 의미론적으로 검사할지, 신호 수준 증거를 얻기 위해 포렌식 도구를 호출할지 자율적으로 결정하고, 턴 사이의 추론으로 관찰 결과를 해석하며 추가 분석을 계속할지 판단을 내릴지 선택한다. 최종 출력은 진위 판정, 위조 영역의 국소화(localization), 그리고 결론을 뒷받침하는 추적 가능한 증거 사슬로 구성된다.

### Dual-Stream Forensic Reasoning

입력 이미지 $I$에 대해 모델은 진위 판정 $\hat{y} \in \{\text{authentic}, \text{forged}\}$, 편집된 객체의 텍스트 서술 $\{\hat{e}_1, \dots, \hat{e}_P\}$(예: 중앙의 호랑이가 접합되었다는 식의 서술), 그리고 과학적 증거를 구성하는 해석 가능한 추론 궤적 $o$를 산출한다. 추론 중에는 지정 영역을 잘라내 국소 세부를 확대하거나, $I$와 동일한 공간 해상도의 heatmap을 생성하는 도구 라이브러리 $\mathcal{T} = \{T_1, \dots, T_{22}\}$를 호출할 수 있다.

위조 단서는 두 상위 유형으로 구분되며 각각 별개의 추론 경로를 결정한다. **High-level Semantics**는 물리 법칙이나 상식 논리를 위반하는 위조로, 모델은 의심 영역을 crop·확대해 의미론적으로 분석한다(분석가의 육안 검사 단계에 대응). **Low-level Artifacts**는 의미론적으로는 결함이 없으나 신호 수준 패턴에서 드러나는 지각 불가능한 이상으로, 모델이 반드시 분석 도구를 호출해 검증해야 한다(기기 분석 단계에 대응). 두 경로는 상호 배타적이지 않으며, 한 방향이 충분한 증거를 주지 못하면 경로를 전환할 수 있다.

도구 라이브러리는 비지도(unsupervised) 도구 22개로, 압축 아티팩트, 센서 노이즈, 통계·주파수 분포, 구조적 불일치, copy-move 중복, AI 생성 특이 패턴, 그리고 foundation model 기반 이상 탐지(DINOv3 [52] Layer 4 특징에 주성분분석(principal component analysis, PCA)으로 차원을 줄인 Mahalanobis distance)의 일곱 상호보완적 도메인에 걸친다. 각 추론 턴은 텍스트와 하나의 action tag [69]를 포함한다. `<grounding>`은 정규화 bounding box $[x_1, y_1, x_2, y_2] \in [0,1]^4$와 대상 객체 서술로 crop을 유발하고, `<tool_call>`은 도구를 호출하며, `<answer>`는 최종 판정과 증거 사슬을 전달한다. 환경이 결과를 반환해 다음 턴의 입력이 된다. 즉 `<grounding>`과 `<tool_call>`이 실험적 분석, 턴 간 추론이 논리적 추론, 누적 궤적을 포함한 최종 `<answer>`가 과학적 증거에 해당한다.

### Forensic Reasoning Trajectory Synthesis와 General Experience SFT

기존 위조 데이터셋에는 다중 턴 추론 주석이 없고 수작업 주석 비용이 과도하므로, 원시 데이터셋을 도구 증강 추론 궤적으로 변환하는 4단계 자동 파이프라인을 설계했다.

**Instance Annotation.** 이진 마스크만 제공하는 원시 데이터셋을 MLLM 보조 반복 기법으로 객체별 instance mask, 의미 레이블, bounding box, 조작 유형으로 분해하고, 필요한 경우 Segment Anything Model(SAM) [2]로 인스턴스를 분리한다.

**Per-Sample Tool Evaluation.** 보편적으로 최적인 도구는 없으므로, 각 위조 이미지와 (모든 학습셋에서 이용 가능한) 원본에 22개 도구를 모두 실행하고 ground-truth 마스크에 대한 픽셀 수준 area under the curve(AUC)를 계산한다. 순수 탐지 효과는 $\Delta\text{AUC} = \text{AUC}_{\text{fake}} - \text{AUC}_{\text{orig}}$로 측정하여, 원본 기준선이 도구 고유 편향을 제거하게 한다. $\Delta\text{AUC}$가 높아도 위조 영역이 시각적으로 구분되지 않는 heatmap이 나올 수 있으므로 샘플마다 상호보완적인 두 도구를 선택한다. `tool_first`는 조작 영역과 배경 강도 사이의 Cohen's $d$ [7]를 최대화하여 MLLM이 가장 해석하기 쉬운 heatmap을 고르되, 값을 음이 아닌 범위로 clamp하고 $\Delta\text{AUC}$로 스케일해 탐지 품질이 충분한 도구만 고려한다. `tool_best`는 시각적 명료성과 무관하게 $\Delta\text{AUC}$를 직접 최대화해 가장 정확한 도구를 고른다. 커리큘럼 안내와 보상 계산용으로 샘플별 Top-$K$($K$=3) 최적 도구 집합도 생성하며, 최고 $\Delta\text{AUC}$가 0.15 미만인 샘플은 도구 증강 학습에서 제외한다. 최적 도구 도메인은 위조 기법에 따라 체계적으로 이동하여, JPEG 기반 splicing(AutoSplice)은 75.7%가 압축 도구에 집중되는 반면 적대적 합성(FantasticReality)은 주로 노이즈 도구(29.7%)를 유발한다. 모든 도메인이 최소 한 데이터셋에서 1위를 차지해 라이브러리가 필요하면서도 중복적이지 않음을 확인했다.

**Teacher-Guided Trajectory Generation.** student와 teacher는 모두 Qwen3-VL-235B-A22B [1]다. student는 ground truth 없이 탐색하고, teacher는 주석을 보유한 채 세 기제로 탐색을 유도한다. student의 crop마다 teacher는 아직 다루지 않은 ground-truth 마스크와 비교해 mask coverage(마스크 중 crop이 덮은 비율)와 overlap ratio(crop 중 마스크가 점유한 비율)로 판정하여, hit(coverage ≥0.5, overlap ≥0.12), relevant(coverage ≥0.1, overlap ≥0.05), irrelevant로 분류하고 각각 확인, 정교화 안내, 재지정 피드백을 준다. teacher는 다룬 인스턴스를 추적해 모든 조작 영역이 발견되도록 하고, 턴이 지날수록 방향 암시에서 명시적 대상 지정으로 프롬프트 강도를 높인다. low-level 단서에는 `tool_first`와 `tool_best`를 순차 추천하며, crop에서 이상이 나오지 않으면 student가 실패한 가설을 명시적으로 반성하게 하여 가설–검증–기각–조정 주기가 완결된 궤적을 만든다. student가 반복 실패하면 teacher가 ground-truth 위치를 fallback으로 주입한다. 모든 궤적은 전체 인스턴스 포함 여부, action tag 형식 적합성, 도구 호출 유효성을 자동 검증한 뒤 SFT 집합에 포함된다.

**General Experience SFT.** Qwen3-VL-8B [1]의 모든 선형 계층에 Low-Rank Adaptation(LoRA) [22]을 적용하고, vision encoder는 동결, multi-modal projector는 학습 가능하게 두어 heatmap과 crop된 포렌식 뷰 같은 도메인 특수 입력에 시각-텍스트 정렬을 적응시킨다. 손실은 모델 생성 토큰에만 계산하고 환경이 반환한 관찰은 제외한다.

### Tool Prior Curriculum Learning

SFT 모델은 다중 턴 추론 형식은 습득했으나 22개 후보 중 최적 도구를 자율적으로 고르지 못한다. 잘못 선택한 도구는 턴을 낭비할 뿐 아니라 무관한 강조 영역을 증거로 취급하게 하여 모델을 능동적으로 오도하며, 대부분의 선택이 무정보 증거를 낳으면 강화학습(reinforcement learning, RL) 신호가 너무 희소해진다. 이에 최적 도구 사전지식을 초기에 주입하고 점진적으로 제거하는 Tool Prior Curriculum [75]을 도입한다.

low-level artifacts 경로에서 모델이 도구를 선택하면 환경이 모델이 모르게 이를 교체한다. 각 입력에 대해 GRPO가 $G$개 궤적을 샘플링하고, 궤적마다 교체 등급을 결정하는 커리큘럼 강도 $\lambda(i,t)$를 부여한다. $\lambda \ge 0.7$이면 Top-$K$ 최적 도구로 교체, $0.3 \le \lambda < 0.7$이면 2차 등급 도구($\Delta\text{AUC}$ 기준 4–7위)로 교체, $\lambda < 0.3$이면 모델 자신의 선택을 유지한다. 이러한 혼합은 의미 있는 GRPO 기울기에 필수적인 그룹 내 보상 분산을 만들며, high-level semantics 경로 궤적은 커리큘럼을 완전히 우회한다. 강도는 그룹 내 다양성 항과 학습 전역 감쇠 항의 곱으로 정의된다.

$$\lambda(i,t) = \frac{G-i}{G-1} \cdot \frac{1}{1+\exp(\alpha(t-t_0))}$$

정책 최적화는 그룹 내 정규화와 비대칭 clipping [71]($\epsilon^- < \epsilon^+$)을 쓰는 GRPO [51]로, 양의 advantage 궤적에 더 큰 업데이트를 허용한다.

$$\mathcal{L}_{\text{GRPO}} = -\mathbb{E}_q\left[\frac{1}{G}\sum_{i=1}^{G}\min\left(\rho_i \hat{A}_i,\ \mathrm{clip}(\rho_i, 1-\epsilon^-, 1+\epsilon^+)\hat{A}_i\right)\right] + \beta D_{\text{KL}}(\pi_\theta \| \pi_{\text{ref}})$$

여기서 $\rho_i = \pi_\theta(o_i|q)/\pi_{\text{old}}(o_i|q)$, $\hat{A}_i = (r_i - \mu_G)/\sigma_G$다. 교체가 발동하면 모델 출력의 도구 이름이 치환되고 프롬프트 시퀀스가 재토크나이즈되어 이후 턴이 교체된 도구를 문맥으로 관찰한다. 교체된 도구에서 얻은 높은 보상이 해당 도구를 스스로 선택하도록 유도하는 기울기 신호가 되어, 커리큘럼이 감쇠하면서 보조에서 독립적 도구 사용으로 전환이 완성된다(ToolAcc 41.8% → 72.0%).

### Structured Evidence Reward

모델은 결함 있는 추론으로도 올바른 판정에 도달할 수 있고, 단일 스칼라 보상은 최종 답과 추론 과정을 혼동시켜 그런 행동을 강화한다. 신뢰할 수 있는 과학적 증거를 위해 보상을 네 독립 성분 [34]으로 분해하여 각 능력을 따로 감독하며, 각 성분은 결정론적 규칙이나 이진 판단만 하도록 제약된 LLM judge로 산출한다.

$$r = w_1 \cdot r_1 + w_2 \cdot r_2 + w_3 \cdot r_3 + w_4 \cdot r_{\text{fmt}}$$

$r_1 = \mathbb{1}[\hat{y} = y]$는 올바른 분류를 보상하고, $r_{\text{fmt}}$는 잘못된 action tag나 무효한 도구 호출을 벌한다. 모델이 픽셀 마스크가 아닌 텍스트 영역 서술 $\hat{e}_i$를 출력하므로 표준 IoU로 국소화를 직접 평가할 수 없다. $r_2$에서는 ground-truth 마스크를 이미지에 중첩해 모델의 텍스트 예측과 함께 LLM judge에 제출하고, judge가 각 예측 영역을 matched, missed, hallucinated로 분류한다.

$$r_2 = \begin{cases} \dfrac{2 \cdot \text{Prec} \cdot \text{Rec}}{\text{Prec} + \text{Rec}} & \text{forged} \\[4pt] \mathbb{1}[P=0] & \text{authentic} \end{cases}$$

$P$는 예측 영역 수, $|\mathcal{M}|$은 judge가 matched로 판정한 수이고, 어떤 예측과도 매칭되지 않은 ground-truth 인스턴스를 $N_{\text{miss}}$로 두어 $\text{Prec} = |\mathcal{M}|/P$, $\text{Rec} = |\mathcal{M}|/(|\mathcal{M}| + N_{\text{miss}})$로 계산한다.

추론 과정 자체를 감독하는 $r_3 = (c_1 + c_2 + c_3)/3$은 세 기준으로 추론 품질을 평가한다. $c_1$과 $c_2$는 matched 객체별 턴 품질을 추론 경로에 대응하는 세 시나리오로 평가하고, $c_3$은 궤적 전체 품질을 평가한다. **Strategy Selection $c_1$**: low-level artifacts에서는 호출한 도구가 Top-$K$ 최적 집합에 속하는지 결정론적 규칙으로 확인하고, high-level semantics에서는 LLM judge가 모델이 실제 물리적·상식적 위반을 식별했는지 아니면 날조했는지 검증하며, authentic 이미지에서는 도구를 최소 한 번 호출했는지 확인해 의미론적 이상의 부재만으로 진본 판정을 내리는 것을 막는다. **Evidence Quality $c_2$**: low-level artifacts에서는 heatmap 서술이 실제 도구 출력과 일치하는지, high-level semantics에서는 의미론적 관찰이 이미지에 근거하는지, authentic 이미지에서는 heatmap을 정상으로 올바르게 해석했는지 확인한다. **Conclusion Consistency $c_3$**: 최종 판정이 누적 증거와 정합적이며 모순이 무시되지 않고 명시적으로 인정되었는지 검증한다.

### 학습·평가 설정

SFT는 CASIA2 [11], IMD2020 [42], FantasticReality [28], NeXT-IMDL [35], AutoSplice [26](IMDL), OpenForensics [32](Deepfake), DocTamper [45](DMDL) 등 7개 데이터셋에서 합성한 약 41K 다중 턴 궤적을 쓰고, RL은 NeXT-IMDL, OpenForensics, DocTamper(62K 샘플)를 쓴다. Qwen3-VL-8B-Instruct [1]를 LoRA($r$=128, $\alpha$=256)로 모든 선형 계층에서 미세조정하며 vision encoder는 동결한다. SFT는 3 epoch, 8×A100-80GB, DeepSpeed ZeRO-3 [48], lr $2\times10^{-5}$, cosine 스케줄, warmup 0.1, batch 32, 최대 32768 토큰, assistant 턴에만 손실을 적용한다. RL은 GRPO($G$=8, $\beta_{\text{KL}}$=0.001, $\epsilon^-$=0.2, $\epsilon^+$=0.3, $\tau$=0.6, top-$p$=0.90, $\beta_{\text{ent}}$=0.0002), batch 128, 400 step이며 커리큘럼 감쇠는 $t_0$를 전체 step의 50%, $\alpha$=5.0으로 둔다. 보상 가중치는 $w_1$=0.35, $w_2$=0.35, $w_3$=0.25, $w_4$=0.05이고, MLLM judge는 Qwen3-VL-235B-A22B [1]다. 평가 시 ATAR의 텍스트 영역 서술은 GroundedSAM [49]으로 픽셀 마스크로 변환한 뒤 픽셀 수준 Intersection over Union(IoU)과 F1로 측정하며, authentic 예측은 전부 0인 마스크를 산출한다.

### 실험적 검증

평가는 IMDL, Deepfake detection, DMDL 세 도메인 학습 후 AIGC detection을 추가로 zero-shot 평가하는 방식이다. 픽셀 마스크가 있는 도메인 외부 IMDL 집합(CASIAv1+ [11], Columbia [21], NIST16 [16], Coverage [66], Korus [29], CocoGlide [17])은 분류와 국소화를, 문서 위조(T-SROIE [58], FSTS-1.5k [70])는 국소화만, GenImage++ [76](생성기 계열 5종)는 AIGC 분류만 평가한다. 비교 대상은 전용 IMDL 탐지기(MVSS-Net [5], TruFor [17], ForMa [18], SparseViT [54]), MLLM 기반 탐지기(FakeShield [68], SIDA-7B [24]), 범용 MLLM(GPT-5.4 [53], Gemini-2.5-Pro [8], Qwen3-VL-8B [1])과 도메인 특수 기준선(문서용 APSC-Net [46], AIGC용 UnivFD [43], DRCT [3])이다.

**IMDL.** 6개 zero-shot 벤치마크 평균에서 ATAR은 iF1 78.5%, ACC 74.6%, pF1 56.4%, IoU 49.6%로 모두 1위이며, TruFor 대비 iF1 +5.6 percentage points(pp), pF1 +6.0 pp를 기록한다. SFT만으로도 이미 TruFor를 넘고(74.3% 대 72.9%), GRPO가 +4.2 pp를 더한다. 경량 탐지기 ForMa와 SparseViT는 분포 내 데이터에서 경쟁력 있는 국소화(ForMa: CASIA v1+ pF1 62.9%, Coverage 48.7%)를 보이지만 교차 데이터셋에서 심각하게 붕괴하며(ForMa는 Columbia 0.1%, NIST16 5.5%; SparseViT는 Columbia 0.0%, CASIA v1+ 15.3%), 전용 분류 헤드가 없어 이미지 수준 탐지가 우연 수준(iF1 약 66–69%)에 머문다. MLLM 중 FakeShield는 iF1에서 11.8 pp 뒤지고, ATAR의 기반 모델인 Qwen3-VL-8B는 29.0%(−49.5 pp)에 그쳐, 시각 인코더가 지각하지 못하는 신호 수준 흔적을 22개 포렌식 도구로 외부화한 효과를 보여준다.

**DMDL·Deepfake·AIGC.** 문서에서 ATAR은 평균 pF1 36.5%로 최고이며 TruFor(23.4%), GPT-5.4(7.3%)를 크게 앞선다. 문서 이미지는 균일한 배경 위에 조밀하고 구조화된 텍스트가 있어 문자 단위 조작의 픽셀 아티팩트가 자연 이미지 splicing보다 훨씬 미묘한 탓에 전통 탐지기가 모두 pF1 23.4% 이하로 무너지지만, ATAR의 도구 증강 grounding은 영역 수준 검사로 이런 세밀한 불일치를 분리한다. OpenForensics(in-domain) Deepfake에서는 iF1 99.9%, pF1 61.6%로 분류는 TruFor와 동급이면서 국소화는 +19.3 pp 앞서고, 범용 MLLM은 완전히 실패한다(GPT-5.4 11.3%, Qwen3-VL-8B 3.4%). AIGC 학습 데이터를 전혀 쓰지 않았음에도 GenImage++ 5개 생성기 평균 F1 87.0%, ACC 82.2%로 모든 범용 MLLM(Gemini-2.5-Pro 84.4%)과 UnivFD·DRCT 같은 AIGC 특화 기법을 능가한다.

**Ablation.** Full(.785) ≫ w/o Tools(.751) > Random Tool(.726) 순서는 도구의 가치가 올바른 선택에 있음을 보여준다. 무작위 heatmap은 heatmap이 없는 경우보다 나쁘며(−2.5 pp), 모델이 무관한 강조를 증거로 삼아 높은 확신으로 틀린 판정을 고수하기 때문이다. SFT는 다중 턴 형식은 가르치지만 도구 선택은 가르치지 못하고(ToolAcc 41.8%), RL이 이를 72.0%로 올린다. Tool Prior Curriculum이 없으면 RL은 ToolAcc를 38.6%로 SFT-only보다 낮게 떨어뜨리는데, 실패한 무작위 시도가 음의 기울기를 만들어 선택이 소수의 광대역 도구로 붕괴하기 때문이다. 감쇠 없는 고정 커리큘럼은 ToolAcc를 63.4%로 회복하지만 자율 선택을 내재화하지 못한다(iF1 −1.2 pp). 보상에서 $r_2$를 제거하면 정밀한 국소화 없이 $r_1$을 최대화할 수 있어 위조 과다 예측으로 ACC가 4.8 pp 떨어진다. $r_3$을 제거하면 정량 지표는 거의 변하지 않으나(iF1 −0.6 pp) 추론이 단축 패턴 매칭으로 퇴화하여 true positive(TP) 환각률이 7.2%에서 21.6%로 세 배가 된다. 단일 점수(Holistic Reward)는 분류에 지배되어 국소화와 도구 선택의 기울기를 고갈시키며 비균일하게 악화된다(iF1 −2.1 pp, pF1 −6.2 pp, ToolAcc −12.2 pp).

**추론 품질과 도구 전문화.** 6개 zero-shot IMDL 데이터셋에서 계층 표집한 200장을 Qwen3-VL-235B-A22B judge가 Groundedness, Consistency, Faithfulness, Specificity 네 차원을 5점 Likert로 평가했고 [73], ATAR 변형에는 충실성 검증을 위해 도구 생성 heatmap도 함께 제공했다. ATAR은 모든 차원에서 1위(평균 4.12 대 차순위 3.33)이며 Faithfulness(+1.10)와 Groundedness(+0.76)에서 가장 크게 앞선다. Gemini-2.5-Pro는 비ATAR 중 Consistency는 가장 높으나(3.36) Groundedness(2.32)와 Faithfulness(2.41)는 가장 낮아, 실행할 도구 없이 포렌식 용어를 날조하는 양상을 보인다. 가장 중요한 지표는 TP 환각률로, ATAR 7.2%인 반면 Gemini-2.5-Pro는 34.8%에 이른다. 50 샘플 인간 평가(주석자 3인)의 Fleiss' $\kappa$ = .54–.72, Spearman $\rho$ = .74–.86으로 자동 평가가 검증되며 Faithfulness에서 신뢰도가 가장 높다($\rho$ = .86). 도구 도메인 선택을 보면 SFT는 어느 도메인도 33%를 넘지 않는 분산된 분포를 내지만, GRPO는 데이터셋별 전문화로 날카롭게 만들어 Top-1 도메인이 지배적 위조 유형과 일치한다(CASIA v1+/NIST16은 Compression, CocoGlide는 AIGC, Coverage는 Copy-Move, Columbia·Korus는 Noise). 무관한 도구도 억제하여 비압축 TIF 형식인 Columbia에서 Compression은 12.8%에서 4.8%로 감소한다. ΔHit은 SFT의 56–65%에서 RL 후 77–92%로 올라가며, 단일 지배 단서가 있는 Coverage에서 최고(91.6%), 다양한 도구가 필요한 혼합 위조의 Korus에서 최저(76.8%)다. 요컨대 SFT는 언제 도구를 부를지를, RL은 어떤 도구를 부를지를 가르친다.

## 실험 및 평가

### 실험 설정

학습은 세 도메인, 즉 이미지 조작 탐지·국소화(image manipulation detection and localization, IMDL), Deepfake 탐지, 문서 조작 탐지·국소화(document manipulation detection and localization, DMDL)에서 수행하고, 추가로 AI 생성 콘텐츠(AI-generated content, AIGC) 탐지는 zero-shot으로 평가한다. General Experience SFT에는 CASIA2, IMD2020, FantasticReality, NeXT-IMDL, AutoSplice(IMDL), OpenForensics(Deepfake), DocTamper(DMDL) 등 7개 데이터셋에서 합성한 약 41K개의 multi-turn trajectory를 사용하고, Forensic Scene RL에는 NeXT-IMDL, OpenForensics, DocTamper에서 62K 샘플을 사용한다. 도메인 외(out-of-domain) IMDL 평가는 픽셀 마스크가 있는 CASIAv1+, Columbia, NIST16, Coverage, Korus, CocoGlide 6개 벤치마크로, 문서 위조는 T-SROIE와 FSTS-1.5k로 국소화만, AIGC는 GenImage++(5개 생성기 계열)로 분류만 평가한다.

지표는 이미지 수준의 Accuracy와 F1(iF1/ACC), 픽셀 수준의 Intersection over Union(IoU)과 F1(pF1)이다. ATAR은 픽셀 마스크가 아닌 텍스트 영역 설명을 출력하므로, Grounded-SAM으로 마스크로 변환한 뒤 픽셀 지표를 계산하며 authentic 예측은 전부 0인 마스크가 된다.

백본은 Qwen3-VL-8B-Instruct이며 모든 linear layer에 LoRA($r$=128, $\alpha$=256)를 적용하고 vision encoder는 고정한다. SFT는 3 epoch, 8×A100-80GB, DeepSpeed ZeRO-3, lr $2\times10^{-5}$, cosine schedule, warmup 0.1, batch 32, 최대 32768 token이며 손실은 assistant turn에만 계산한다. RL은 GRPO($G$=8, $\beta_{\text{KL}}$=0.001, $\epsilon^-$=0.2, $\epsilon^+$=0.3, $\tau$=0.6, top-$p$=0.90, $\beta_{\text{ent}}$=0.0002), batch 128, 400 step으로, curriculum 감쇠는 $t_0$를 전체 step의 50% 지점, $\alpha$=5.0으로 둔다. 보상 가중치는 $w_1$=0.35, $w_2$=0.35, $w_3$=0.25, $w_4$=0.05이고, MLLM judge는 Qwen3-VL-235B-A22B이다. 도구 평가 단계에서는 표본별 최고 ΔAUC가 0.15 미만인 샘플을 도구 증강 학습에서 제외하고, Top-$K$($K$=3) 최적 도구 집합을 curriculum 및 보상 계산에 사용한다.

### 베이스라인

(1) 설명을 제공하지 않는 전용 IMDL 탐지기 MVSS-Net, TruFor, ForMa, SparseViT, (2) MLLM 기반 탐지기 FakeShield, SIDA-7B, (3) 범용 MLLM인 GPT-5.4, Gemini-2.5-Pro, Qwen3-VL-8B(zero-shot), 그리고 도메인 전용 베이스라인으로 문서의 APSC-Net, PSCC-Net, AIGC의 UnivFD와 DRCT를 비교한다.

### 주요 결과

**IMDL.** 6개 zero-shot 벤치마크 평균에서 ATAR이 iF1 78.5%, ACC 74.6%, pF1 56.4%, IoU 49.6%로 모두 1위이며, TruFor 대비 iF1 +5.6 pp, pF1 +6.0 pp 앞선다. SFT만 적용해도 평균 iF1이 74.3%로 TruFor의 72.9%를 넘고, GRPO가 추가로 +4.2 pp를 더한다. ForMa와 SparseViT는 분포 내 데이터의 국소화에서는 경쟁력이 있으나(ForMa는 CASIA v1+ pF1 62.9%, Coverage 48.7%) 데이터셋 간 전이에서 급격히 붕괴하며(ForMa는 Columbia 0.1%, NIST16 5.5%, SparseViT는 Columbia 0.0%, CASIA v1+ 15.3%), 전용 분류 헤드가 없어 이미지 수준 탐지는 iF1 약 66–69%로 우연 수준에 머문다. MLLM 계열에서는 FakeShield가 iF1 기준 11.8 pp 뒤지고, ATAR의 기반 모델인 Qwen3-VL-8B는 29.0%(−49.5 pp)에 그친다. 저자들은 이를 시각 인코더가 신호 수준 흔적을 지각하지 못하기 때문이며 ATAR은 이를 22개 forensic tool로 외부화한다고 설명한다.

**DMDL.** 문서 위조 국소화 평균 pF1은 ATAR이 36.5%로 최고이며 TruFor 23.4%, GPT-5.4 7.3%를 크게 앞선다. 기존 탐지기는 모두 23.4% 이하로, 문자 수준 조작의 흔적이 자연 영상 splicing보다 훨씬 미세한 문서 영상에서 성능이 무너진다.

**Deepfake.** in-domain인 OpenForensics에서 iF1 99.9%로 분류는 TruFor와 동등하고, 국소화는 pF1 61.6%로 TruFor보다 +19.3 pp 높다. 범용 MLLM은 사실상 실패한다(GPT-5.4 11.3%, Qwen3-VL-8B 3.4%).

**AIGC.** AIGC 학습 데이터를 전혀 쓰지 않았음에도 5개 생성기 평균 F1 87.0%로, 범용 MLLM 중 최고인 Gemini-2.5-Pro의 84.4%와 UnivFD·DRCT 같은 AIGC 전용 기법을 모두 상회한다.

### Ablation

IMDL 6개 데이터셋 zero-shot 평균으로 세 축을 분해한다.

- **Tool Augmentation:** iF1 순서는 Full(.785) ≫ w/o Tools(.751) > Random Tool(.726)이다. 무작위 heatmap은 heatmap을 아예 쓰지 않는 것보다 −2.5 pp 더 나쁜데, 모델이 무관한 강조 영역을 증거로 간주해 잘못된 결론을 높은 확신으로 확정하기 때문이다. 즉 도구의 가치는 존재 자체가 아니라 올바른 도구 선택에 있다.
- **Training Pipeline:** SFT는 multi-turn 형식은 가르치지만 도구 선택은 가르치지 못해 ToolAcc(Top-$K$ 최적 도구 적중률)가 41.8%이고, RL이 이를 72.0%로 끌어올린다. Tool Prior Curriculum을 제거하면 RL이 오히려 ToolAcc를 38.6%로 떨어뜨려 SFT-only보다 낮아지는데, 실패한 무작위 시도가 음의 gradient를 만들어 선택이 소수의 광역 도구로 수렴한다. 감쇠 없는 고정 curriculum은 ToolAcc를 63.4%까지 회복하지만 자율적 선택을 내재화하지 못해 iF1이 Full 대비 −1.2 pp이다. 점진적 감쇠만이 높은 ToolAcc와 일반화를 동시에 달성한다.
- **Reward Design:** $r_2$를 빼면 정확한 국소화 없이도 $r_1$을 최대화할 수 있어 모델이 위조로 과다 예측하고 ACC가 4.8 pp 하락한다. $r_3$를 빼면 정량 지표는 iF1 −0.6 pp로 거의 변하지 않지만 추론이 지름길 패턴 매칭으로 퇴화하며, true positive(TP) 환각률이 7.2%에서 21.6%로 세 배가 된다. 즉 $r_3$의 효용은 정확도가 아니라 설명가능성이다. 단일 점수의 Holistic Reward는 iF1 −2.1 pp, pF1 −6.2 pp, ToolAcc −12.2 pp로 비균일하게 악화되어, 하나의 스칼라가 분류에 지배되고 국소화·도구 선택에 gradient가 거의 가지 않음을 보인다.

### 추론 품질과 도구 특화

6개 zero-shot IMDL 데이터셋에서 계층 표집한 200장에 대해 MLLM judge(Qwen3-VL-235B-A22B)가 원본 이미지, 정답 레이블, 익명화된 설명을 받아 Groundedness, Consistency, Faithfulness, Specificity를 5점 Likert로 채점하고, ATAR 변형에는 충실성 검증을 위해 도구 heatmap을 추가로 제공한다. 또한 조작된 주장이 하나 이상 포함된 설명의 비율인 Hallucination Rate를 전체와 TP에 대해 보고하며, 3명 주석자의 50 샘플 인간 평가로 Fleiss' $\kappa$와 Spearman $\rho$를 통해 judge를 검증한다. ATAR은 모든 차원에서 1위(평균 4.12, 차순위 3.33)이고 Faithfulness(+1.10)와 Groundedness(+0.76)에서 격차가 가장 크다. Gemini-2.5-Pro는 비-ATAR 중 Consistency는 가장 높으나(3.36) Groundedness(2.32)와 Faithfulness(2.41)가 가장 낮아, 실제로 도구를 실행하지 않은 채 포렌식 용어를 꾸며내는 경향을 보인다. 가장 중요한 지표인 TP 환각률은 ATAR이 7.2%, 전체 환각률은 11.5%이며, Gemini-2.5-Pro는 TP에서 34.8%에 달해 범용 MLLM이 정답을 맞힌 경우에도 증거를 조작함을 확인한다. 인간–judge 일치도는 $\kappa$ = .54–.72, $\rho$ = .74–.86이고 Faithfulness에서 신뢰도가 가장 높다($\rho$ = .86).

도구 선택 분포를 보면 SFT는 어느 도메인도 33%를 넘지 않는 분산된 분포를 보이지만, GRPO 이후에는 데이터셋의 지배적 위조 유형과 Top-1 도메인이 일치하는 특화가 나타난다. JPEG 압축된 CASIA v1+/NIST16은 Compression, GLIDE inpainting인 CocoGlide는 AIGC, Coverage는 Copy-Move, splicing인 Columbia와 Korus는 Noise가 1위가 된다. 무관한 도구를 억제하는 학습도 관찰되는데, 비압축 TIF 형식 때문에 JPEG ghost 계열이 무의미한 Columbia에서 Compression 비중이 12.8%에서 4.8%로 감소한다. 최적 도구 집합 적중률 ΔHit은 SFT의 56–65%에서 RL 후 77–92%로 상승하며, 단일 지배적 단서를 가진 Coverage가 91.6%로 가장 높고 다양한 도구가 필요한 혼합 위조의 Korus가 76.8%로 가장 낮다. Freq.와 Str. 도메인은 일괄적으로 −3–6 pp 감소해 상대적으로 약한 대안으로 가지치기된다. 저자들은 이를 SFT가 도구를 언제 호출할지를, RL이 어느 도구를 쓸지를 가르친다고 요약한다. 사례 연구에서는 도구에 의해 반박된 가설을 수정하고, 의미 수준과 신호 수준 증거를 결합하며, 복수 영역에 걸쳐 증거를 누적하는 궤적이 제시되어, 고정된 탐지 파이프라인이 아니라 입력에 따라 전략을 조정함을 보인다.

## 고찰

### 방법론에 대한 평가

ATAR(Agentic Tool-Augmented Reasoning)의 설계는 사법 포렌식 전문가의 3단계 작업 흐름, 즉 실험적 분석(experimental analysis)–논리적 추론(logical reasoning)–과학적 증거(scientific evidence)를 다중 턴 상호작용 추론으로 재현하려는 데서 출발한다. 기존 IMDL(image manipulation detection and localization) 계열은 경계 아티팩트, JPEG 압축 불일치, 주파수 영역 이상 같은 저수준 단서를 포착하지만 블랙박스이므로 추적 가능한 증거를 내놓지 못하고, MLLM(multimodal large language model) 기반 기법은 탐지 모듈이 결정한 결과를 언어로 사후 서술하는 데 그친다는 것이 논문의 문제 제기다. 특히 CLIP류 시각 인코더가 고수준 의미에 맞추어 설계되어 JPEG 아티팩트 정렬 오류나 노이즈 이상 같은 신호 수준 흔적을 지각하지 못하므로, 근거 없는 설명을 생성하게 된다는 지적은 외부 도구 도입의 동기를 분명히 한다.

핵심 구성은 **이중 스트림 포렌식 추론(Dual-Stream Forensic Reasoning)**이다. 고수준 의미 이상 경로는 물리 법칙이나 상식 논리를 위반하는 영역을 잘라내어 확대해 검사하고, 저수준 위조 아티팩트 경로는 7개 상호보완 영역(압축 아티팩트, 센서 노이즈, 통계·주파수 분포, 구조적 불일치, copy-move 중복, AI 생성 특이 패턴, 그리고 DINOv3 Layer 4 특징에 PCA로 차원을 줄인 Mahalanobis distance를 쓰는 foundation-model 기반 이상 탐지)에 걸친 22개 비지도 도구를 호출해 객관적 증거를 얻는다. 두 경로는 배타적이지 않으며 한쪽이 충분한 증거를 주지 못하면 모델이 경로를 전환할 수 있다. 각 턴은 텍스트와 하나의 행위 태그를 담는데, `<grounding>`은 정규화 바운딩 박스 $[x_1,y_1,x_2,y_2] \in [0,1]^4$와 대상 객체 설명으로 크롭을 촉발하고, `<tool_call>`은 도구를 호출하며, `<answer>`는 최종 판정과 증거 사슬을 전달한다.

훈련 전략인 **Forensics Curriculum Learning**은 두 단계다. 1단계 General Experience SFT에서는 기존 위조 데이터셋에 다중 턴 추론 주석이 없다는 문제를 **Forensic Reasoning Trajectory Synthesis** 4단계 파이프라인으로 해소한다. (i) Instance Annotation은 이진 마스크를 MLLM 보조 반복 기법으로 객체별 마스크·의미 레이블·박스·조작 유형으로 분해하고 필요 시 SAM(Segment Anything Model)을 호출한다. (ii) Per-Sample Tool Evaluation은 어떤 도구도 보편적으로 최적이 아니라는 전제 아래 위조 이미지와 원본 모두에 22개 도구를 적용하고 픽셀 수준 AUC를 계산해 $\Delta\mathrm{AUC} = \mathrm{AUC}_{\text{fake}} - \mathrm{AUC}_{\text{orig}}$로 순수 탐지 효과를 측정한다. 원본 기준선이 도구 고유 편향을 제거하는 구조다. 다만 $\Delta\mathrm{AUC}$가 높아도 히트맵에서 위조 영역이 시각적으로 구분되지 않을 수 있으므로, 조작 영역과 배경 강도 간 Cohen's $d$를 최대화해(음수는 0으로 절단하고 $\Delta\mathrm{AUC}$로 스케일) MLLM이 해석하기 쉬운 tool_first와, 시각적 명료성을 무시하고 $\Delta\mathrm{AUC}$만 최대화하는 tool_best를 표본별로 각각 선택한다. 커리큘럼 안내와 보상 계산용 Top-$K$($K$=3) 최적 도구 집합도 함께 생성하며, 최고 $\Delta\mathrm{AUC}$가 0.15 미만인 표본은 도구 증강 훈련에서 제외된다. (iii) Teacher-Guided Trajectory Generation에서는 학생과 교사가 모두 Qwen3-VL-235B-A22B이고, 학생은 정답 없이 탐색하며 교사는 주석을 보유한 채 안내한다. 학생 크롭은 마스크 커버리지와 겹침 비율로 hit(커버리지 ≥0.5, 겹침 ≥0.12), relevant(커버리지 ≥0.1, 겹침 ≥0.05), irrelevant로 분류되고 각각 확인·보정 안내·방향 전환 피드백을 받는다. 교사는 이미 발견한 인스턴스를 추적해 모든 조작 영역이 탐색되게 하고, 턴이 지날수록 방향 암시에서 명시적 목표 지정으로 안내 강도를 높이며, 반복 실패 시 정답 위치를 주입한다. 크롭에서 이상이 없을 때 학생이 실패한 가설을 명시적으로 되짚게 해 가설–검증–기각–조정 주기를 갖춘 궤적을 만든다는 점이 특징이다. (iv) SFT는 Qwen3-VL-8B의 모든 선형 계층에 LoRA(Low-Rank Adaptation)를 적용하고 시각 인코더는 동결, 멀티모달 프로젝터는 학습해 히트맵·크롭 뷰 같은 도메인 입력에 정렬을 맞추며, 손실은 환경이 반환한 관측을 제외한 모델 생성 토큰에만 계산한다.

2단계 Forensic Scene RL은 GRPO를 쓰되 두 난점을 해결한다. 첫째, SFT 모델은 22개 후보에서 최적 도구를 고르지 못해 잘못된 도구가 턴을 낭비할 뿐 아니라 무관한 강조 영역을 증거로 오인하게 만들고 RL 신호를 희박하게 한다. **Tool Prior Curriculum**은 저수준 경로에서 모델이 고른 도구를 모델이 모르게 환경이 교체하는데, 강도 $\lambda(i,t)$가 $\lambda \ge 0.7$이면 Top-$K$ 최적 도구로, $0.3 \le \lambda < 0.7$이면 2순위 집단($\Delta\mathrm{AUC}$ 기준 4–7위)으로 교체하고 $\lambda < 0.3$이면 모델 선택을 유지한다. 고수준 경로 궤적은 커리큘럼을 우회한다. 강도는 그룹 내 다양성 항과 훈련 전역 감쇠 항의 곱이다.

$$\lambda(i,t) = \frac{G-i}{G-1} \cdot \frac{1}{1+\exp(\alpha(t-t_0))}$$

교체가 발생하면 출력 내 도구 이름을 바꾸고 프롬프트를 재토큰화해 이후 턴이 교체된 도구를 맥락으로 관측하므로, 높은 보상이 해당 도구를 자율적으로 고르도록 기울기를 유도하고 커리큘럼 감쇠와 함께 통제권이 에이전트로 이전된다. 최적화는 그룹 내 정규화와 비대칭 클리핑($\epsilon^- < \epsilon^+$)을 쓴다.

$$\mathcal{L}_{\text{GRPO}} = -\mathbb{E}_q\left[\frac{1}{G}\sum_{i=1}^{G}\min\left(\rho_i \hat{A}_i,\ \mathrm{clip}(\rho_i, 1-\epsilon^-, 1+\epsilon^+)\hat{A}_i\right)\right] + \beta D_{\mathrm{KL}}(\pi_\theta \| \pi_{\text{ref}})$$

여기서 $\rho_i = \pi_\theta(o_i|q)/\pi_{\text{old}}(o_i|q)$, $\hat{A}_i = (r_i - \mu_G)/\sigma_G$다.

둘째, 단일 스칼라 보상은 최종 답과 추론 과정을 뒤섞어 결함 있는 추론으로 맞춘 답까지 강화한다. **Structured Evidence Reward**는 보상을 규칙 기반 또는 이진 판단으로 제한된 LLM judge가 평가하는 네 독립 항목으로 분해한다.

$$r = w_1 \cdot r_1 + w_2 \cdot r_2 + w_3 \cdot r_3 + w_4 \cdot r_{\text{fmt}}$$

$r_1 = \mathbb{1}[\hat{y} = y]$는 분류 정확성, $r_{\text{fmt}}$는 잘못된 행위 태그나 무효 도구 호출에 벌점을 준다. 모델이 픽셀 마스크가 아니라 텍스트 영역 설명 $\hat{e}_i$를 내놓으므로 표준 IoU로 국소화를 직접 평가할 수 없어, $r_2$는 정답 마스크를 이미지에 중첩해 예측 텍스트와 함께 judge에 제출하고 각 예측을 matched/missed/hallucinated로 분류한 뒤 $\mathrm{Prec} = |\mathcal{M}|/P$, $\mathrm{Rec} = |\mathcal{M}|/(|\mathcal{M}| + N_{\text{miss}})$의 조화평균을 쓰며 진짜 이미지는 $\mathbb{1}[P=0]$로 평가한다. $r_3 = (c_1+c_2+c_3)/3$은 추론 품질을 전략 선택($c_1$), 증거 품질($c_2$), 결론 일관성($c_3$)으로 나눈다. $c_1$은 저수준에서 호출 도구가 Top-$K$ 집합에 속하는지 규칙으로 확인하고, 고수준에서는 실제 물리·상식 위반을 짚었는지 judge가 검증하며, 진짜 이미지에서는 의미 이상 부재만으로 진위를 선언하지 못하게 최소 한 번의 도구 호출을 요구한다. $c_2$는 히트맵 서술이 실제 도구 출력과 일치하는지, 의미 관찰이 이미지에 근거하는지, 히트맵이 정상으로 올바르게 해석되었는지를 본다. $c_3$은 최종 판정이 누적 증거와 일관되고 모순이 무시되지 않고 명시적으로 인정되는지 검증한다.

### 실험 결과에 대한 평가

평가는 IMDL, Deepfake detection, DMDL(document manipulation detection and localization) 세 도메인 훈련에 AIGC(AI-generated content) detection 제로샷 평가를 더한 구성이다. SFT는 CASIA2, IMD2020, FantasticReality, NeXT-IMDL, AutoSplice(IMDL), OpenForensics(Deepfake), DocTamper(DMDL) 등 7개 데이터셋에서 약 41K 다중 턴 궤적을 쓰고, RL은 NeXT-IMDL·OpenForensics·DocTamper 62K 표본을 쓴다. 도메인 외 IMDL 평가셋은 CASIAv1+, Columbia, NIST16, Coverage, Korus, CocoGlide이며, 문서 위조는 T-SROIE와 FSTS-1.5k로 국소화만, GenImage++(5개 생성기 계열)는 분류만 평가한다. ATAR의 텍스트 영역 설명은 GroundedSAM으로 픽셀 마스크로 변환한 뒤 픽셀 IoU와 F1로 측정하고, 진짜로 예측된 경우는 전부 0인 마스크가 된다. 설정은 LoRA($r$=128, $\alpha$=256), 3 epoch, 8×A100-80GB, DeepSpeed ZeRO-3, lr $2\times10^{-5}$, cosine 스케줄, warmup 0.1, batch 32, 최대 32768 토큰이며, RL은 GRPO($G$=8, $\beta_{\mathrm{KL}}$=0.001, $\epsilon^-$=0.2, $\epsilon^+$=0.3, $\tau$=0.6, top-$p$=0.90, $\beta_{\text{ent}}$=0.0002), batch 128, 400 step, 커리큘럼 감쇠는 전체 step의 50% 지점 $t_0$와 $\alpha$=5.0, 보상 가중치는 $w_1$=0.35, $w_2$=0.35, $w_3$=0.25, $w_4$=0.05이고 judge는 Qwen3-VL-235B-A22B다.

성능은 6개 제로샷 IMDL 벤치마크 평균에서 iF1 78.5%, ACC 74.6%, pF1 56.4%, IoU 49.6%로 1위이며 TruFor 대비 iF1 +5.6pp, pF1 +6.0pp다. SFT만으로도 74.3%로 TruFor의 72.9%를 넘고 GRPO가 +4.2pp를 더한다. MLLM 계열에서 FakeShield는 11.8pp 뒤지고, 기반 모델 Qwen3-VL-8B는 29.0%(−49.5pp)에 머물러 시각 인코더가 신호 수준 흔적을 지각하지 못한다는 주장을 뒷받침한다. 경량 탐지기 ForMa와 SparseViT는 분포 내 국소화에서 경쟁력이 있으나(ForMa는 CASIA v1+에서 pF1 62.9%, Coverage에서 48.7%) 교차 데이터셋에서 급락하고(ForMa는 Columbia 0.1%, NIST16 5.5%; SparseViT는 Columbia 0.0%, CASIA v1+ 15.3%) 전용 분류 헤드가 없어 이미지 수준 탐지가 iF1 66–69% 수준의 우연 근방에 머문다. DMDL 평균 pF1은 36.5%로 TruFor 23.4%, GPT-5.4 7.3%를 크게 앓서며, 문서 이미지가 균일한 배경에 조밀한 구조적 텍스트를 담아 문자 단위 조작의 픽셀 아티팩트가 자연 이미지 splicing보다 훨씬 미세하다는 점이 기존 탐지기 붕괴의 원인으로 제시된다. Deepfake에서는 iF1 99.9%로 TruFor와 동급이면서 pF1 61.6%로 +19.3pp 우위를 보이고, 범용 MLLM은 거의 실패한다(GPT-5.4 11.3%, Qwen3-VL-8B 3.4%). AIGC 데이터로 훈련하지 않았음에도 5개 생성기 평균 F1 87.0%로 Gemini-2.5-Pro 84.4%와 UnivFD·DRCT를 앞선다.

절제 실험은 세 축에서 구성 요소의 역할을 분리한다. 도구 증강에서 Full(.785) > w/o Tools(.751) > Random Tool(.726)의 순서는 도구의 가치가 올바른 선택에 있음을 보여주며, 무작위 히트맵은 히트맵이 없는 경우보다 2.5pp 더 나쁘다. 모델이 무관한 강조를 증거로 취급해 틀린 판정을 높은 확신으로 확정하기 때문이다. 훈련 파이프라인에서 SFT는 다중 턴 형식만 학습해 ToolAcc가 41.8%이고 RL이 72.0%로 끌어올리지만, Tool Prior Curriculum이 없으면 실패한 무작위 시도가 음의 기울기를 만들어 선택이 소수 광역 도구로 붕괴하면서 ToolAcc가 SFT보다 낮은 38.6%로 떨어진다. 감쇠 없는 고정 커리큘럼은 ToolAcc를 63.4%로 회복하지만 자율 선택을 내재화하지 못해 iF1이 1.2pp 낮다. 보상 설계에서 $r_2$를 빼면 정밀한 국소화 없이도 $r_1$을 최대화할 수 있어 위조로 과다 예측하며 ACC가 4.8pp 하락한다. $r_3$를 빼면 정량 지표는 iF1 −0.6pp로 거의 변하지 않지만 추론이 단축 패턴 매칭으로 퇴화하여 true positive(TP) 환각률이 7.2%에서 21.6%로 세 배가 되는데, 저자들은 $r_3$의 가치가 정확도가 아니라 설명가능성에 있다고 못박는다. 통합 단일 보상은 iF1 −2.1pp, pF1 −6.2pp, ToolAcc −12.2pp의 비균질 열화를 보여 단일 점수가 분류에 지배되어 국소화와 도구 선택의 기울기 신호를 고갈시킨다는 점을 드러낸다.

정성 평가는 6개 제로샷 IMDL 데이터셋에서 층화 표집한 200장을 대상으로 Groundedness, Consistency, Faithfulness, Specificity를 5점 Likert로 채점한다. ATAR은 평균 4.12로 차순위 3.33을 앞서며, Faithfulness(+1.10)와 Groundedness(+0.76)에서 격차가 가장 크다. 도구 출력이 검증 가능한 기준점을 제공해 조작을 막는다는 해석이다. Gemini-2.5-Pro는 비ATAR 중 Consistency가 가장 높은 3.36이면서 Groundedness 2.32와 Faithfulness 2.41로 가장 낮은 분열을 보이는데, 실행할 도구 없이 포렌식 전문 용어를 꾸며내기 때문이다. 가장 중요한 지표인 TP 환각률은 판정은 맞추고 정당화를 조작하는 단축 추론을 측정하며, ATAR은 전체 11.5%·TP 7.2%, Gemini-2.5-Pro는 TP 34.8%다. 50표본·3명 주석자 인간 평가는 Fleiss' $\kappa$ .54–.72, Spearman $\rho$ .74–.86으로 judge를 검증하고 Faithfulness에서 신뢰도가 가장 높다($\rho$=.86).

도구 전문화 분석에서 SFT는 어떤 영역도 33%를 넘지 않는 분산된 분포를 보이지만, GRPO 이후에는 데이터셋별 지배적 위조 유형과 Top-1 영역이 일치한다. JPEG 압축된 CASIA v1+·NIST16은 Compression, GLIDE로 인페인팅된 CocoGlide는 AIGC, Coverage는 Copy-Move, splicing 기반 Columbia·Korus는 Noise가 선택된다. 비압축 TIF 포맷인 Columbia에서 JPEG ghost 계열이 쓸모없어지면서 Compression 비중이 12.8%에서 4.8%로 억제되는 현상은 무관한 도구를 스스로 걸러내는 학습을 보여준다. $\Delta$Hit는 SFT의 56–65%에서 RL의 77–92%로 올라가고, 단일 지배 단서가 있는 Coverage가 91.6%로 가장 높고 다양한 도구를 요구하는 혼합 위조의 Korus가 76.8%로 가장 낮다. Freq.와 Str. 영역은 일반적으로 더 약한 대안으로 가지치기되어 3–6pp 균일하게 감소한다. 저자들은 SFT가 언제 도구를 부를지를, RL이 어느 도구를 부를지를 가르친다고 정리한다. Table 1의 영역별 최적 도구 분포도 이를 뒷받침하는데, JPEG 기반 splicing인 AutoSplice는 압축 계열에 75.7%가 집중되고 적대적 합성인 FantasticReality는 주로 노이즈 계열(29.7%)을 작동시키며, 모든 영역이 최소 한 데이터셋에서 1위를 차지해 도구 라이브러리가 필요하면서 중복되지 않음을 확인한다.

### 한계와 남은 쟁점

논문 자체가 드러내는 제약은 몇 갈래다. 첫째, Per-Sample Tool Evaluation이 위조 이미지의 원본 쌍을 요구하며(훈련셋 전체에는 제공됨) 최고 $\Delta\mathrm{AUC}$가 0.15 미만인 표본은 도구 증강 훈련에서 아예 배제되므로, 도구가 유효한 증거를 남기지 않는 사례는 학습 신호에서 빠진다. 둘째, RL 이후에도 Top-$K$ 최적 도구 적중률은 72.0%에 머물러 도구 선택이 완전히 해결되지 않았고, Korus처럼 위조 유형이 혼합된 집합에서 $\Delta$Hit가 가장 낮다. 셋째, 국소화는 텍스트 영역 설명을 GroundedSAM으로 마스크화한 결과로 측정되고 보상 $r_2$·$r_3$의 상당 부분이 LLM judge의 이진 판단에 의존하므로, 평가 축 자체가 모델 외부 구성 요소의 품질과 결합된다. 인간–judge 일치도는 Faithfulness에서 가장 높고 Consistency($\kappa$=.54)에서 가장 낮아 차원별 신뢰도가 고르지 않다. 넷째, 분류 지표가 추론 퇴화를 완전히 가린다는 발견($r_3$ 제거 시 iF1 0.6pp 하락 대 TP 환각 3배 증가)은 설명가능성 평가를 별도로 수행해야 한다는 함의를 준다. 또한 Columbia의 픽셀 수준 최고 성능은 TruFor(pF1 .833)가 유지하고 NIST16 IoU 등 일부 항목은 SparseViT가 앞서는 등, ATAR의 우위는 평균과 도메인 외 일반화에서 두드러지며 모든 개별 지표를 지배하지는 않는다. Case Study의 완전한 추론 흔적은 보충 자료로 미뤄져 본문에서 검증 가능한 범위도 제한적이다.

## 결론

ATAR은 실험적 분석–논리적 추론–과학적 증거라는 사법 포렌식 작업 흐름을 설명가능한 이미지 위조 탐지로 구현한 에이전트형 프레임워크다. 의미 검사와 22개 포렌식 도구에서 나오는 이중 스트림 증거를 바탕으로 에이전트는 관측을 해석하고 가설을 검증하며 도구가 반박한 방향을 여러 턴에 걸쳐 포기하는 논리적 추론을 수행한다. Forensics Curriculum Learning은 도구 정확도를 41.8%에서 72.0%로 끌어올리고, Structured Evidence Reward는 증거가 조작되지 않고 충실하도록 보장해 TP 환각률을 범용 MLLM의 34.8% 대비 7.2%로 낮춘다. 그 결과 IMDL, Deepfake, DMDL, AIGC 벤치마크 전반에서 최고 수준의 탐지 성능을 달성하면서 기존 기법보다 훨씬 근거 있는 설명을 산출한다. 방법론적 교훈은 두 가지로 요약된다. 외부 도구를 통한 저수준 증거의 외재화가 MLLM 시각 인코더의 구조적 한계를 우회하는 실효적 경로라는 점, 그리고 보상을 분류·국소화·추론 품질로 분해하지 않으면 단일 점수가 분류에 지배되어 설명 충실성이 지표에 드러나지 않은 채 붕괴한다는 점이다.
