# Learning Rich Features for Image Manipulation Detection

[원문](https://arxiv.org/abs/1805.04953v1) · [PDF](https://arxiv.org/pdf/1805.04953v1)

## 한눈에 보기

조작 이미지에서 변조 영역을 찾는 image manipulation detection을 위해 RGB stream과 steganalysis rich model(SRM) 기반 noise stream을 bilinear pooling으로 결합한 two-stream Faster R-CNN을 제안하고, 네 개의 표준 데이터셋에서 단일 stream 및 기존 기법을 능가하는 성능(NIST16 기준 $F_1$ 0.722, AUC 0.937)과 resizing·compression에 대한 강건성을 보인다.

## 초록

image manipulation detection은 이미지 내용보다 변조 흔적(tampering artifacts)에 더 주의를 기울이기 때문에 전통적인 semantic object detection과 다르며, 이는 더 풍부한 특징(richer features)을 학습해야 함을 시사한다. 저자들은 two-stream Faster R-CNN 네트워크를 제안하고, 조작된 이미지가 주어졌을 때 변조된 영역을 검출하도록 이를 end-to-end로 학습한다. 두 stream 중 하나는 RGB stream으로, RGB 이미지 입력에서 강한 대비 차이(strong contrast difference), 부자연스러운 변조 경계(unnatural tampered boundaries) 등과 같은 변조 흔적을 찾기 위한 특징을 추출하는 것을 목적으로 한다. 다른 하나는 noise stream으로, steganalysis rich model filter layer에서 추출된 noise 특징을 활용하여 진정한(authentic) 영역과 변조된 영역 사이의 noise 불일치(noise inconsistency)를 발견한다. 그 다음 두 stream의 특징을 bilinear pooling layer를 통해 융합하여 이 두 모달리티의 공간적 공동 발생(spatial co-occurrence)을 추가로 통합한다. 네 개의 표준 image manipulation 데이터셋에 대한 실험은 제안된 two-stream 프레임워크가 각각의 개별 stream을 능가하며, 또한 resizing과 compression에 대한 강건성을 갖추고 대안적 방법들과 비교하여 state-of-the-art 성능을 달성함을 보여준다.

## 필요성

이미지 편집 기술과 사용자 친화적인 편집 소프트웨어가 발전하면서 저비용으로 변조 이미지를 생성하는 과정이 널리 보급되었다. 변조 기법 중 splicing, copy-move, removal이 가장 일반적이다. splicing은 진정한 이미지에서 영역을 복사해 다른 이미지에 붙이는 방식이고, copy-move는 같은 이미지 내에서 영역을 복사·붙여넣는 방식이며, removal은 진정한 이미지에서 영역을 제거한 뒤 inpainting을 수행하는 방식이다. 때로는 이러한 변조 후에 Gaussian smoothing 같은 후처리(post-processing)가 적용된다. 그 결과 사람이 주의 깊게 관찰해도 변조 영역을 인식하기 어렵고, 진정한 이미지와 변조 이미지를 구별하는 일은 점점 더 어려워지고 있다.

이 주제를 다루는 연구 분야인 image forensics는 공격자가 변조 이미지를 부도덕한 상업적·정치적 목적으로 사용하는 것을 막고자 하므로 중요성이 크다. 또한 이미지를 후속적으로 압축하면 source와 target 이미지 사이의 noise 특징 차이가 부분적으로 가려질 수 있어[26, 4], 단일 단서에만 의존하는 접근은 한계가 있다.

## 연구 분야 흐름

image forensics 연구는 변조 이미지 내의 저수준(low-level) 변조 흔적을 검출하는 다양한 접근으로 구성되며, double JPEG compression[4], CFA color array 분석[19], local noise 분석[7] 등이 포함된다. 최근 연구는 local noise features[35, 26]나 Camera Filter Array(CFA) patterns[19] 같은 단서를 이용해 이미지 내의 특정 patch 또는 pixel[11]을 변조 여부로 분류하고 변조 영역을 국소화한다[19, 9, 6]. 다만 이러한 방법 대부분은 하나의 변조 기법에 초점을 맞춘다.

딥러닝의 성공과 함께 image manipulation detection에도 딥러닝이 적용되는 흐름이 나타났다. 한편 traditional object detection 네트워크[28, 18, 10, 32, 16, 31]는 이미지 내 서로 다른 범주의 모든 객체를 검출하는 것을 목표로 하지만, image manipulation detection을 위한 네트워크는 변조된 영역(보통 객체)만 검출하는 것을 목표로 한다. 본 논문은 RGB 이미지 내용과 image noise 특징을 모두 탐색하여 object detection 네트워크를 image manipulation detection에 적용하는 방법을 연구한다.

## 관련 연구

### 저수준 통계 기반 기법

Bianchi 등[4]은 서로 다른 영역에 대해 DCT 계수와 양자화 계수를 추정하는 확률 모형을 제안한다. CFA 기반 방법은 변조 영역이 카메라 내부 필터 패턴을 교란한다는 가정 하에 이 패턴이 도입하는 저수준 통계를 분석하며, Goljan 등[19]은 Gaussian Mixture Model(GMM)로 CFA가 존재하는 영역(진정한 영역)과 CFA가 부재한 영역(변조 영역)을 분류한다.

### SRM 기반 기법

steganalysis rich model(SRM)[15] 같은 local noise features 기반 방법은 image forensics 과제에서 유망한 성능을 보였다. 이들은 인접 pixel로부터 local noise 특징을 추출하여 변조 영역과 진정한 영역 사이의 불일치를 포착한다. Cozzolino 등[7]은 변조 영역과 진정한 영역을 구별하는 데서 SRM 특징의 성능을 탐구·입증했고, 양자화(quantization)와 절단(truncation) 연산을 포함해 SRM 특징을 CNN과 결합하여 manipulation localization을 수행했다[8]. Rao 등[27]은 SRM filter kernel을 CNN의 초기화로 사용해 검출 정확도를 높였다. 이들 대부분은 특정 변조 흔적에 집중하여 특정 변조 기법에 제한된다.

### 딥러닝 기반 기법

Chen 등[5]은 CNN 앞에 low pass filter layer를 추가해 median filtering 변조 기법을 검출한다. Bayar 등[3]은 low pass filter layer를 adaptive kernel layer로 바꾸어 변조 영역에서 사용된 필터링 kernel을 학습한다. Zhang 등[34]은 image manipulation detection을 위한 context 특징 학습에 stacked autoencoder를 제안한다. Cozzolino 등[9]은 이 문제를 anomaly detection 과제로 취급하여, 추출된 특징 기반 autoencoder로 재구성이 어려운 영역을 변조 영역으로 구별한다. Salloum 등[29]은 Fully Convolutional Network(FCN) 프레임워크로 이미지로부터 변조 mask를 직접 예측하며, boundary mask도 함께 학습해 FCN이 변조된 edge를 보도록 유도한다. Bappy 등[2]은 Long Short Term Network(LSTM) 기반 네트워크를 작은 image patch에 적용해 변조 patch와 이미지 patch 사이 경계의 변조 흔적을 찾고, pixel 수준 segmentation과 공동 학습한다. 그러나 근처 경계에만 집중하는 방식은 다양한 상황에서 제한적이며, 예컨대 객체 전체를 제거하면 검출을 위한 경계 증거가 남지 않을 수 있다. 본 논문은 이에 대비해 전역적 시각 변조 흔적과 local noise features를 함께 사용한다.

## 배경 지식

### Faster R-CNN과 RPN

Faster R-CNN[28] 같은 딥러닝 검출 모형은 다양한 스케일의 semantic object 검출에서 좋은 성능을 보였다. Region Proposal Network(RPN)는 Faster R-CNN에서 관심 객체를 포함할 가능성이 높은 이미지 영역을 제안하는 구성 요소이며, image manipulation detection에 맞게 변형될 수 있다. RPN의 손실은 다음과 같이 정의된다.

$$L_{RPN}(g_i, f_i) = \frac{1}{N_{cls}}\sum_i L_{cls}(g_i, g_i^{\star}) + \lambda \frac{1}{N_{reg}}\sum_i g_i^{\star} L_{reg}(f_i, f_i^{\star})$$

여기서 $g_i$는 mini batch에서 anchor $i$가 잠재적 조작 영역일 확률, $g_i^{\star}$는 anchor $i$가 positive인지에 대한 ground-truth label이다. $f_i$, $f_i^{\star}$는 각각 anchor $i$와 ground-truth의 4차원 bounding box 좌표이다. $L_{cls}$는 RPN을 위한 cross entropy loss, $L_{reg}$는 제안된 bounding box 회귀를 위한 smooth $L_1$ loss이다. $N_{cls}$는 RPN의 mini-batch 크기, $N_{reg}$는 anchor 위치의 수이며, $\lambda$는 두 손실의 균형을 맞추는 hyperparameter로 10으로 설정된다.

### SRM noise 특징

이 논문의 설정에서 noise는 어떤 pixel의 값과, 이웃 pixel들의 값만을 보간하여 산출한 그 pixel 값의 추정치 사이의 잔차(residual)로 모형화된다. SRM은 30개의 basic filter에서 출발하여, 필터링 후 근처 출력의 최대·최소 같은 비선형 연산과 함께 기본 noise 특징을 모은다. SRM은 이들 필터의 출력을 양자화·절단하고 근처의 co-occurrence 정보를 최종 특징으로 추출한다. 이 과정에서 얻어진 특징은 local noise descriptor로 볼 수 있다[7].

### Bilinear pooling

bilinear pooling[23]은 원래 fine-grained classification을 위해 제안되었으며, two-stream CNN 네트워크에서 공간 정보를 보존하면서 stream들을 결합해 검출 신뢰도를 높인다. 본 논문의 bilinear pooling layer 출력은 $x = f_{RGB}^{T} f_{N}$으로, $f_{RGB}$는 RGB stream의 RoI 특징이고 $f_{N}$은 noise stream의 RoI 특징이다. sum pooling은 분류 전에 공간 특징을 압축한다. 이후 signed square root($x \leftarrow sign(x)\sqrt{|x|}$)와 $L_2$ normalization을 적용한 뒤 fully connected layer로 전달한다. 메모리 절약과 성능 저하 없는 학습 가속을 위해 [17]에서 제안된 compact bilinear pooling을 사용한다.

## 문제 정의

목표는 조작된 이미지가 주어졌을 때 변조된 영역을 검출하는 것이다. 이는 이미지 내용보다 변조 흔적에 주의를 기울여야 한다는 점에서 traditional semantic object detection과 다르며, 따라서 더 풍부한 특징을 학습해야 한다. 특히 RGB channels만으로는 모든 조작 사례를 다루기에 충분하지 않다. splicing 경계를 감추고 대비 차이를 줄이도록 주의 깊게 후처리된 변조 이미지는 RGB stream에게 어려운 과제이다. noise stream의 직관은, 어떤 객체가 한 이미지(source)에서 제거되어 다른 이미지(target)에 붙여질 때 source와 target 이미지 사이의 noise 특징이 일치할 가능성이 낮다는 점이다.

또한 기존 image manipulation 데이터셋[25, 1, 12, 30]은 수백 장 규모의 이미지만 포함하여 심층 네트워크를 학습시키기에 충분하지 않다는 데이터 측면의 문제가 있다. 저자들은 이를 극복하기 위해 COCO[22]를 기반으로 합성 변조 데이터셋을 만들어 모형을 pre-training하고, 테스트를 위해 서로 다른 데이터셋에서 finetune한다.

## 주요 기여

기여는 두 가지이다. 첫째, Faster R-CNN 프레임워크를 two-stream 방식으로 image manipulation detection에 적용하는 방법을 제시한다. RGB tampering artifacts와 local noise feature inconsistencies라는 두 모달리티를 탐색하고, 이를 bilinear pooling하여 변조 영역을 식별한다. 둘째, 두 stream이 서로 다른 변조 기법을 검출하는 데 상호 보완적임을 보이며, 이를 통해 네 개의 image manipulation 데이터셋에서 state-of-the-art 방법들에 비해 향상된 성능을 달성한다.

제안 프레임워크는 manipulation classification과 bounding box regression을 동시에 수행하는 multi-task 구조로, 총 손실은 다음과 같다.

$$L_{total} = L_{RPN} + L_{tamper}(f_{RGB}, f_N) + L_{bbox}(f_{RGB})$$

여기서 $L_{RPN}$은 RPN 손실, $L_{tamper}$는 RGB와 noise stream 양쪽의 bilinear pooling 특징에 기반한 최종 cross entropy 분류 손실, $L_{bbox}$는 최종 bounding box regression 손실이다. 아울러 이 네트워크는 splicing, copy-move, removal에 대한 강건성을 보이며, 의심되는 변조 기법에 대한 분류도 가능하게 한다.

## 제시한 방법론

### 전체 구조

제안 방법은 조작 분류(manipulation classification)와 바운딩 박스 회귀(bounding box regression)를 동시에 수행하는 멀티태스크 프레임워크로, Faster R-CNN [28]을 두 개의 스트림으로 확장해 end-to-end로 학습한다. 위쪽 스트림에는 RGB 이미지가, 아래쪽 스트림에는 SRM 이미지가 입력된다. 두 스트림의 특징은 완전 연결 계층(fully connected layer) 직전에서 bilinear pooling으로 융합되어 조작 분류에 사용되고, RPN(Region Proposal Network)은 RGB 스트림만을 이용해 조작 영역을 지역화한다. 전통적인 객체 검출과 달리 이 RPN은 "객체일 가능성이 높은 영역"이 아니라 "조작되었을 가능성이 높은 영역"을 탐색하며, removal(제거) 과정처럼 제안 영역이 반드시 객체가 아닐 수도 있다는 점이 설계상의 차이다.

### RGB stream

RGB stream은 단일 Faster R-CNN으로서 바운딩 박스 회귀와 조작 분류 모두에 쓰인다. 백본으로 ResNet 101 [20]을 사용하고, ResNet 마지막 합성곱 계층의 출력 특징을 조작 분류에 활용한다. 이 특징을 바탕으로 RPN이 RoI(Region of Interest)를 제안하며, RPN 손실은 다음과 같이 정의된다.

$$L_{RPN}(g_i, f_i) = \frac{1}{N_{cls}}\sum_i L_{cls}(g_i, g_i^{\star}) + \lambda \frac{1}{N_{reg}}\sum_i g_i^{\star} L_{reg}(f_i, f_i^{\star})$$

여기서 $g_i$는 미니배치 내에서 anchor $i$가 조작 가능 영역일 확률, $g_i^{\star}$는 anchor $i$가 positive인지에 대한 ground-truth 레이블이다. $f_i$와 $f_i^{\star}$는 각각 anchor $i$와 ground-truth의 4차원 바운딩 박스 좌표다. $L_{cls}$는 RPN의 cross entropy loss, $L_{reg}$는 제안 바운딩 박스 회귀를 위한 smooth $L_1$ loss이며, $N_{cls}$는 RPN 미니배치 크기, $N_{reg}$는 anchor 위치의 수다. 두 손실의 균형을 맞추는 하이퍼파라미터 $\lambda$는 10으로 설정된다.

RGB stream이 노리는 신호는 조작 경계의 시각적 비일관성, 조작 영역과 진본 영역 간 대비(contrast) 차이 등 중·고수준의 시각적 조작 흔적이다. 그러나 경계를 감추고 대비 차이를 줄이도록 후처리된 조작 이미지는 RGB 채널만으로는 어렵다는 한계가 있어, 두 번째 스트림이 필요해진다.

### Noise stream

Noise stream은 의미적 이미지 내용보다 노이즈 자체에 주목하도록 설계된다. 직관은, 어떤 객체가 원본(source) 이미지에서 떼어져 대상(target) 이미지에 붙여지면 두 이미지의 노이즈 특성이 일치하기 어렵다는 점이다(이 차이는 이후 압축으로 부분적으로 가려질 수 있다 [26, 4]). 여기서 노이즈는 한 픽셀의 값과, 이웃 픽셀 값만을 보간해 추정한 그 픽셀의 값 사이의 잔차(residual)로 모델링된다.

구체적으로는 steganalysis rich model(SRM) [15]에 기반해 noise feature를 뽑는다. SRM은 30개의 기본 필터에서 출발해, 필터링 후 인접 출력의 최대·최소 같은 비선형 연산을 거쳐 기본 노이즈 특징을 모으고, 이 출력을 양자화·절단(quantization and truncation)한 뒤 인접 동시발생(co-occurrence) 정보를 최종 특징으로 추출한다. 이렇게 얻어진 특징은 국소 노이즈 기술자(local noise descriptor) [7]로 볼 수 있다. 설계 선택으로서, 저자들은 커널 3개만 써도 괜찮은 성능이 나오고 30개를 모두 적용해도 유의한 성능 향상이 없음을 확인했기 때문에 커널 3개만 선택했고, 이를 3채널 입력으로 사전학습된 네트워크에 그대로 넣을 수 있도록 했다. SRM filter layer의 커널 크기는 $5 \times 5 \times 3$이고 출력 채널 수는 3이다.

Noise stream의 백본 합성곱 구조는 RGB stream과 동일하며, RoI pooling layer를 RGB stream과 공유한다. 바운딩 박스 회귀에는 RGB 채널만 사용하는데, 실험(Table 1)에서 RPN에 대해 RGB 특징이 noise 특징보다 더 좋은 성능을 보였기 때문이다.

### Bilinear pooling

두 스트림의 융합에는 fine-grained classification을 위해 처음 제안된 bilinear pooling [23]을 적용한다. 공간 정보를 보존하면서 두 모달리티의 공간적 동시발생(spatial co-occurrence)을 결합해 검출 신뢰도를 높이는 것이 목적이다. bilinear pooling layer의 출력은

$$x = f_{RGB}^{T} f_{N}$$

이며, $f_{RGB}$는 RGB stream의 RoI feature, $f_N$은 noise stream의 RoI feature다. 이어 sum pooling으로 분류 전 공간 차원을 압축하고, signed square root($x \leftarrow sign(x)\sqrt{|x|}$)와 $L_2$ normalization을 적용한 뒤 완전 연결 계층으로 전달한다. 메모리 절약과 학습 속도 향상을 위해, 성능 저하 없이 compact bilinear pooling [17]을 사용한다. 완전 연결 계층과 softmax를 지나 RoI 영역의 예측 클래스가 얻어진다.

전체 손실은 조작 분류에 cross entropy loss, 바운딩 박스 회귀에 smooth $L_1$ loss를 써서 다음과 같이 합산된다.

$$L_{total} = L_{RPN} + L_{tamper}(f_{RGB}, f_N) + L_{bbox}(f_{RGB})$$

$L_{RPN}$은 RPN 손실, $L_{tamper}$는 RGB와 noise 양쪽 스트림의 bilinear pooling 특징에 기반한 최종 분류 손실, $L_{bbox}$는 최종 바운딩 박스 회귀 손실이다.

### 구현 세부사항

네트워크는 end-to-end로 학습된다. 입력 이미지와 추출된 noise feature는 짧은 변이 600 픽셀이 되도록 리사이즈된다. anchor는 $8^2, 16^2, 32^2, 64^2$의 네 가지 스케일과 1:2, 1:1, 2:1의 종횡비를 사용한다. RoI pooling 후 특징 크기는 RGB와 noise 스트림 모두 $7 \times 7 \times 1024$이고, compact bilinear pooling의 출력 특징 크기는 16384로 설정된다. RPN 제안의 배치 크기는 학습 시 64, 테스트 시 300이다. 데이터 증강으로는 image flipping을 사용한다. RPN positive 예제(조작 가능 영역)의 IoU(Intersection-over Union) 임계값은 0.7, negative 예제(진본 영역)는 0.3이다. 학습률은 초기 0.001에서 40K 스텝 이후 0.0001로 감소시키고, 총 110K 스텝 학습한다. 테스트 시에는 중복된 겹침 제안 영역을 줄이기 위해 표준 NMS(Non-Maximum Suppression)를 임계값 0.2로 적용한다.

### 사전학습용 합성 데이터셋

기존 표준 데이터셋은 심층 신경망 학습에 데이터가 부족하므로, COCO [22]의 이미지와 주석을 이용해 합성 데이터셋을 자동 생성하여 사전학습에 사용한다. segmentation 주석으로 COCO에서 객체를 무작위로 선택해 다른 이미지에 복사·붙여넣기하며, 동일한 배경과 조작 객체가 학습·테스트 집합에 함께 나타나지 않도록 학습(90%)/테스트(10%)를 분할한다. 최종적으로 42K개의 조작-진본 이미지 쌍이 만들어진다. RoI에 진본 영역이 일부 포함되도록, 학습 시 기본 바운딩 박스를 20 픽셀 확대하여 RGB와 noise 스트림이 조작 영역과 진본 영역 사이의 비일관성을 학습하게 한다. Faster R-CNN의 ResNet 101은 ImageNet에서 사전학습된 것을 쓴다. 모델 출력은 검출 영역이 조작되었는지를 나타내는 신뢰도 점수가 붙은 바운딩 박스다.

합성 COCO 데이터셋에서의 AP 비교(Table 1)는 설계 선택의 근거를 제공한다. RGB Net 0.445, Noise Net 0.461, RGB-N noise RPN 0.472, Noise + RGB RPN 0.620, RGB-N 0.627로, 두 스트림 네트워크가 각 단일 스트림보다 우수하며 RPN의 제안 생성에는 noise 특징보다 RGB 특징이 더 적합함을 보여준다.

## 실험 및 평가

### 사전학습 데이터셋과 실험 설정

기존 이미지 조작 데이터셋은 수백 장 규모에 불과해 심층 네트워크 학습에 부족하므로, 저자들은 COCO [22]의 이미지와 분할 주석(segmentation annotation)을 이용해 합성 조작 데이터셋을 자동 생성했다. COCO에서 객체를 무작위로 선택해 다른 이미지에 복사·붙여넣기 하는 방식으로 총 42K개의 조작/진본 이미지 쌍을 만들고, 동일한 배경과 조작 객체가 학습(90%)과 테스트(10%)에 함께 나타나지 않도록 분할했다. 관심 영역(Region of Interest, RoI)에 일부 진본 영역이 포함되도록 학습 시 기본 바운딩 박스를 20픽셀 확대해, RGB stream과 noise stream이 조작 영역과 진본 영역 간 불일치를 학습하게 했다. Faster R-CNN의 ResNet 101은 ImageNet으로 사전학습된 가중치를 사용하고, 전체 네트워크는 이 합성 데이터셋에서 end-to-end로 학습된다. 평가 지표는 COCO [22] 검출 평가와 동일한 Average Precision(AP)이다.

구현 세부사항으로, 입력 이미지와 추출된 noise feature는 짧은 변이 600픽셀이 되도록 리사이즈된다. 앵커 스케일은 $8^2, 16^2, 32^2, 64^2$의 네 가지, 종횡비는 1:2, 1:1, 2:1이다. RoI pooling 이후의 특징 크기는 RGB·noise stream 모두 $7 \times 7 \times 1024$이며, compact bilinear pooling의 출력 차원은 16384로 설정했다. RPN proposal의 배치 크기는 학습 시 64, 테스트 시 300이다. 데이터 증강으로 이미지 플리핑(image flipping)을 사용하고, RPN 양성 예시(조작 가능 영역)의 Intersection-over-Union(IoU) 임계값은 0.7, 음성 예시(진본 영역)는 0.3이다. 학습률은 0.001에서 시작해 40K 스텝 이후 0.0001로 낮추며 총 110K 스텝 학습한다. 테스트 시 중복되는 겹친 제안 영역을 줄이기 위해 표준 Non-Maximum Suppression(NMS)을 임계값 0.2로 적용한다.

### 스트림 구성 비교(합성 데이터셋 ablation)

합성 COCO 데이터셋에서의 AP 비교(Table 1)는 두 스트림의 역할과 RPN 입력 선택을 검증한다. RGB 이미지만 입력으로 쓰는 단일 Faster R-CNN인 RGB Net은 0.445, noise feature map만 쓰는 Noise Net은 0.461이다. RPN에 noise feature를 사용하는 two-stream 모델(RGB-N noise RPN)은 0.472에 머무르지만, RPN 입력으로 noise와 RGB 특징을 함께 쓰는 Noise + RGB RPN은 0.620, RGB 특징으로 RPN을 구성한 최종 모델 RGB-N은 0.627로 가장 높다. 이는 (1) two-stream 구조가 각 단일 스트림보다 우수하고, (2) 영역 제안 생성에는 noise feature보다 RGB feature가 더 적합함을 보여준다. 이 결과에 따라 바운딩 박스 회귀에는 RGB 채널만 사용한다.

### 표준 데이터셋, 베이스라인, 평가 지표

평가에는 네 개의 표준 데이터셋을 사용한다. NIST Nimble 2016 [1](NIST16)은 splicing, copy-move, removal 세 기법을 모두 포함하며 가시적 흔적을 감추는 후처리가 적용된 어려운 데이터셋으로, ground-truth 조작 마스크를 제공한다. CASIA [12, 13]는 다양한 객체의 spliced·copy-moved 이미지를 제공하며 필터링·블러링 같은 후처리가 적용되고, ground-truth 마스크는 조작 이미지와 원본 이미지의 차분을 임계화해 얻는다(학습에 CASIA 2.0, 테스트에 CASIA 1.0 사용). COVER [30]는 copy-move에 집중한 비교적 작은 데이터셋으로, 붙여넣은 영역과 유사한 객체를 포함시켜 조작 흔적을 감춘다. Columbia 데이터셋은 비압축 이미지 기반 splicing에 집중한다. 학습/테스트 분할(Table 2)은 NIST16 404/160, CASIA 5123/921, Columbia 테스트 180장(학습 없음, 합성 데이터셋으로 학습한 모델의 테스트 전용), COVER 75/25이며, 비교 프로토콜은 NIST16·COVER의 경우 [2], Columbia·CASIA의 경우 [29]와 동일하다. 파인튜닝 시에는 ground-truth 마스크에서 바운딩 박스를 추출해 사용한다.

평가 지표는 픽셀 수준 $F_1$ 점수와 픽셀 수준 AUC(Area Under the receiver operating characteristic Curve)이다. [33, 29]의 프로토콜을 따라 임계값을 변화시키며 각 이미지에서 가장 높은 $F_1$을 최종 점수로 사용하고, AUC 평가를 위해 검출된 바운딩 박스 내 모든 픽셀에 신뢰도 점수를 부여한다.

베이스라인은 JPEG 압축 품질 차이로 압축 오차를 분석하는 ELA [21], 고주파 wavelet 계수로 지역 노이즈를 모델링하는 NOI1 [24], 주변 픽셀로 camera filter array 패턴을 추정해 픽셀별 조작 확률을 내는 CFA1 [14], 조작 경계 이진 마스크와 조작 영역 마스크를 함께 학습하는 multi-task edge-enhanced FCN인 MFCN [29], 패치 수준 조작 경계 분류와 픽셀 수준 분할을 함께 학습하는 LSTM 기반 J-LSTM [2], 그리고 자체 변형인 RGB Net, Noise Net, Late Fusion(두 스트림의 검출 박스를 직접 합치고 겹치는 영역의 신뢰도는 최대값으로 설정), 최종 모델 RGB-N이다. NOI1, CFA1, ELA의 $F_1$은 [29]에 보고된 값을 사용하고 AUC는 [33]이 제공한 코드를 실행해 얻었으며, MFCN과 J-LSTM은 코드가 공개되지 않아 원 논문 수치를 인용했다.

### 주요 결과

$F_1$ 비교(Table 3, NIST16/Columbia/COVER/CASIA 순)에서 RGB-N은 0.722/0.697/0.437/0.408을 기록했다. 전통적 방법인 ELA는 0.236/0.470/0.222/0.214, NOI1은 0.285/0.574/0.269/0.263, CFA1은 0.174/0.467/0.190/0.207로 크게 뒤처진다. 이는 이들이 특정 조작 흔적에만 집중해 국소화에 필요한 정보가 부분적이기 때문이다. MFCN은 0.571/0.612/-/0.541로, NIST16과 Columbia에서는 RGB-N이 더 좋고 CASIA에서는 MFCN(0.541)이 최고값이다. 단일 스트림은 RGB Net 0.567/0.585/0.391/0.392, Noise Net 0.521/0.705/0.355/0.283이며, Late Fusion은 0.625/0.681/0.371/0.397이다.

픽셀 수준 AUC 비교(Table 4)에서 RGB-N은 0.937/0.858/0.817/0.795로 네 데이터셋 모두에서 최고 성능을 달성했다. J-LSTM은 NIST16 0.764, COVER 0.614에 그치는데, 저자들은 J-LSTM이 조작 경계를 증거로 삼기 때문에 조작 영역 전체를 항상 검출하지 못하며, 반면 제안 기법은 수용 영역(receptive field)이 크고 인접 픽셀을 넘어 전역 문맥을 포착해 대비 차이 같은 단서를 더 많이 모을 수 있다고 설명한다. RGB Net은 0.857/0.796/0.789/0.768, Noise Net은 0.881/0.851/0.753/0.693, Late Fusion은 0.924/0.856/0.793/0.777이다.

RGB-N은 Columbia를 제외한 모든 데이터셋에서 개별 스트림을 개선한다. Columbia는 비압축 spliced 영역만 포함해 노이즈 차이가 잘 보존되므로 noise feature만으로 충분하며, 그 결과 Noise Net이 $F_1$ 0.705로 RGB-N(0.697)을 앞선다. 또한 모든 데이터셋에서 Late Fusion이 RGB-N보다 나쁘다는 점이 bilinear pooling 기반 융합 방식의 효과를 보여준다.

### Ablation: 데이터 증강과 공격 강건성

데이터 증강 비교(Table 5, 각 항목은 $F_1$/AUC)에서 증강이 없을 때(No flipping) NIST16 0.716/0.940, COVER 0.312/0.793, CASIA 0.361/0.766인 반면, 이미지 플리핑만 적용하면 0.722/0.937, 0.437/0.817, 0.408/0.795로 향상된다. 플리핑에 품질 70의 JPEG 압축을 더하면 0.712/0.950, 0.425/0.810, 0.413/0.785이고, 분산 5의 가우시안 노이즈를 더하면 0.717/0.947, 0.412/0.801, 0.396/0.776이다. 즉 플리핑이 성능을 개선하며 JPEG 압축·노이즈 추가 증강은 기여가 거의 없다.

JPEG 압축 및 리사이징 공격에 대한 강건성(Table 6, NIST16 $F_1$, 각 항목은 JPEG/Resizing)에서 RGB-N은 무공격(100/1)에서 0.722/0.722, 품질 70·스케일 0.7에서 0.677/0.689, 품질 50·스케일 0.5에서 0.677/0.681을 유지한다. 반면 NOI1은 0.285/0.285 → 0.142/0.147 → 0.140/0.155, ELA는 0.236/0.236 → 0.119/0.141 → 0.114/0.114, CFA1은 0.174/0.174 → 0.152/0.134 → 0.139/0.141로 급격히 저하된다.

### 조작 기법 분류

NIST16은 세 조작 기법 레이블을 제공하므로, 조작 분류 클래스를 splicing, removal, copy-move로 바꾸어 다중 클래스 조작 검출을 수행했다. RGB-N의 AP는 splicing 0.960, removal 0.939, copy-move 0.903, 평균 0.934이다(Table 7). splicing이 가장 쉬운 이유는 비자연적 경계와 대비 차이 같은 RGB 흔적과 노이즈 흔적을 동시에 남길 확률이 높기 때문이고, removal이 copy-move보다 나은 것은 removal 이후의 인페인팅이 noise feature에 큰 영향을 주기 때문이다. copy-move가 가장 어려운 이유는 복사 영역이 같은 이미지에서 오므로 노이즈 분포가 유사해 noise stream을 혼란시키고 두 영역의 대비도 대체로 동일하며, 이상적으로는 두 RoI를 동시에 찾아 비교해야 하지만 현재 방식은 그렇게 하지 않기 때문이다.

### 정성적 결과

COVER, Columbia, CASIA 1.0에서 선택한 예시(Figure 5)는 단일 스트림 중 하나가 실패하는 경우에도 two-stream 네트워크가 좋은 결과를 내는 사례를 보여준다. COVER의 copy-move된 가방은 RGB Net과 Noise Net 모두를 혼란시키지만 RGB-N은 두 스트림의 특징을 결합해 더 나은 검출을 얻고, Columbia 예시에서는 RGB Net이 noise stream보다 정확하지만 두 스트림을 함께 고려한 RGB-N이 더 좋은 결과를 낸다. CASIA 1.0 예시처럼 spliced 객체가 RGB와 노이즈 양쪽에 명확한 흔적을 남기면 세 모델 모두 정확히 검출한다. NIST16에 대한 다중 클래스 결과(Figure 6)에서는 RGB-N이 서로 다른 조작 기법에 대해 올바른 분류를 산출한다.

## 고찰

### 두 stream의 상호 보완성과 그 경계

제안된 RGB-N은 네 개 표준 데이터셋 중 Columbia를 제외한 모든 경우에서 개별 stream 단독 성능을 개선했다. 예외인 Columbia에서는 Noise Net의 $F_1$ 점수가 0.705로 RGB-N의 0.697보다 높았는데, 저자들은 이 데이터셋이 비압축(uncompressed) 상태의 splicing 영역만 포함하여 noise 차이가 매우 잘 보존되기 때문에 noise feature만 사용하는 것으로도 충분하다고 설명한다. 반대로 COVER의 copy-move 예시처럼 복사된 영역이 RGB stream과 noise stream 모두를 혼란시키는 경우에는 두 stream의 결합이 더 나은 검출로 이어진다. 즉 두 modality의 기여는 조작 기법과 후처리 조건에 따라 달라지며, 융합이 항상 단독 stream을 상회한다고 보장되지는 않는다.

융합 방식 자체의 효과는 Late Fusion과의 비교로 뒷받침된다. 두 stream의 검출 박스를 직접 합치고 겹치는 영역의 confidence를 최댓값으로 설정하는 Late Fusion은 모든 데이터셋에서 RGB-N보다 낮은 성능을 보였고, 이는 공간적 공존(spatial co-occurrence) 정보를 유지하는 bilinear pooling 기반 융합이 단순 후처리 결합보다 유효함을 시사한다.

### RPN 입력에 대한 설계상의 제약

합성 COCO 데이터셋 기반 AP 비교(Table 1)에서 RGB-N은 0.627, noise feature를 RPN에 사용한 RGB-N noise RPN은 0.472, noise와 RGB feature를 모두 RPN 입력으로 쓴 Noise + RGB RPN은 0.620이었다. 저자들은 이로부터 region proposal 생성에는 noise feature보다 RGB feature가 더 적합하다고 판단하고, bounding box regression에 RGB 채널만 사용한다. 따라서 noise stream은 조작 분류(manipulation classification)에 대한 추가 증거 제공에 국한되며, 위치 추정 단계에서는 활용되지 않는다는 구조적 한계가 남는다.

### 조작 기법별 성능 차이와 copy-move의 미해결 문제

NIST16에서의 다중 클래스 결과는 splicing 0.960, removal 0.939, copy-move 0.903(mean AP 0.934)으로, splicing이 가장 검출하기 쉽다. splicing은 비자연적 edge와 대비 차이 같은 RGB artifact와 noise artifact를 동시에 발생시킬 확률이 높기 때문이다. removal은 이후 수행되는 inpainting이 noise feature에 큰 영향을 주므로 copy-move보다 높은 성능을 보인다. copy-move는 가장 어려운 기법으로 지목되는데, 그 이유로 (i) 복사된 영역이 같은 이미지에서 오므로 noise 분포가 유사해 noise stream을 혼란시키고, (ii) 두 영역의 대비가 일반적으로 동일해 RGB stream이 구별할 근거가 적으며, (iii) 원리적으로는 두 객체를 서로 비교해야 하지만(즉 두 RoI를 동시에 찾아 비교해야 하지만) 현재 접근은 이를 수행하지 않는다는 점이 제시된다. 이는 저자들이 명시한 방법론적 한계다.

### 기존 방법과의 비교에서 드러나는 논점

ELA [21], NOI1 [24], CFA1 [14] 같은 전통적 방법은 특정 tampering artifact에만 집중하여 위치 추정에 부분적인 정보만 담고 있고, 이것이 성능을 제한한다고 분석된다. J-LSTM [2]과의 비교에서는, J-LSTM이 tampered edge를 증거로 삼기 때문에 조작 영역 전체를 항상 검출하지는 못한다는 점이 지적된다. 더 일반적으로, 경계 인접 영역에만 주목하는 접근은 객체를 완전히 제거하는 경우처럼 경계 증거가 남지 않는 시나리오에서 한계가 있다. 반면 RGB-N은 수용 영역(receptive field)이 더 크고 인접 픽셀이 아닌 전역 문맥(global context)을 포착하므로 대비 차이 같은 단서를 더 많이 수집할 수 있다. MFCN [29]에 대해서는 Columbia와 NIST16에서 우위를 보였다고 기술되며, CASIA의 $F_1$은 MFCN이 0.541로 RGB-N의 0.408보다 높다. 또한 MFCN과 J-LSTM은 코드가 공개되지 않아 원 논문 수치를 그대로 인용했고, NOI1·CFA1·ELA의 $F_1$은 [29]의 보고치를, AUC는 [33]이 제공한 코드를 실행해 얻은 값이라는 비교 조건상의 제약이 함께 명시되어 있다.

### 데이터 부족, 증강, 공격에 대한 견고성

기존 image manipulation 데이터셋 [25, 1, 12, 30]은 수백 장 규모로 심층 네트워크 학습에 충분하지 않다는 것이 출발점의 제약이다. 이를 보완하기 위해 COCO [22]의 segmentation annotation을 이용해 42K 규모의 조작/진본 이미지 쌍으로 구성된 합성 데이터셋을 만들어 사전학습하고, 각 데이터셋에서 미세조정하는 절차가 필요했다. 데이터 증강 비교에서는 image flipping이 증강을 하지 않은 경우보다 성능을 개선했으나, JPEG 압축(quality 70)이나 Gaussian noise(variance 5) 추가는 기여가 거의 없었다. JPEG 압축과 리사이징 공격에 대해서는 NIST16 기준 원본 0.722/0.722에서 quality 70/scale 0.7일 때 0.677/0.689, quality 50/scale 0.5일 때 0.677/0.681을 유지하며 비교 대상 세 방법보다 견고했다. 다만 평가 측면에서 픽셀 단위 AUC는 검출된 bounding box 내 모든 픽셀에 confidence를 부여하는 방식으로 산출되므로, 박스 기반 출력을 픽셀 단위 지표로 환산하는 근사가 개입한다.

## 결론

이 연구는 RGB stream과 noise stream을 함께 사용해 image manipulation detection을 위한 풍부한 특징을 학습하는 two-stream Faster R-CNN을 제안하고 end-to-end로 학습했다. noise feature는 steganalysis 문헌에서 차용한 SRM filter layer로 추출하여, 조작 영역과 진본 영역 사이의 noise 비일관성을 포착할 수 있게 한다. 두 stream의 RoI feature는 bilinear pooling [23, 17]으로 결합되어 두 modality의 공간적 공존 정보를 반영하고, 전체 손실은 $L_{total} = L_{RPN} + L_{tamper}(f_{RGB}, f_N) + L_{bbox}(f_{RGB})$로 구성된다. 저자들은 RGB와 noise feature가 조작 영역을 찾는 데 상호 보완적으로 기여함을 확인했으며, 두 stream의 융합이 성능 향상으로 이어진다는 점은 예상에 부합하는 결과로 평가한다. 표준 데이터셋 실험 결과 제안 방법은 조작 흔적을 검출하는 데 그치지 않고 splicing, removal, copy-move 등 서로 다른 조작 기법을 구분할 수 있음을 보였다. 향후 과제로는 JPEG compression을 포함한 더 많은 특징의 탐색이 제시되었다.
