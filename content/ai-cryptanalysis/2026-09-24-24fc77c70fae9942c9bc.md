# The Tokens Remember: When Tokenization Bypasses Knowledge Editing and Unlearning

[원문](https://arxiv.org/abs/2609.29045v1) · [PDF](https://arxiv.org/pdf/2609.29045v1)

## 한눈에 보기

open-weight LLM에서 model editing과 machine unlearning으로 억제한 지식이, 같은 문자열의 다른 유효한 tokenization을 통해 되살아난다는 점을 보인 연구다. 사전 편집 모델·shadow model·보조 분류기 없이 공개된 모델만으로 동작하는 reference-free 공격 Toketive를 제안해, 평균 38.6%의 alternative tokenization이 편집을 우회하고 F1 84.2%로 편집 사실을 탐지하며 top-5 74.5%로 편집 이전 응답을 복원한다.

## 초록

open-weight LLM은 다운스트림 사용자에게 추론 스택(inference stack)에 대한 통제권을 주지만, 이 유연성은 민감한 지식이 수정 또는 제거되었다는 공개 이후(post-release) 보증을 훼손할 수 있다. Model editing과 machine unlearning은 모델을 처음부터 재학습하지 않고 표적 지식을 수정하거나 제거하는 데 사용된다. 그러나 이러한 기법에 대한 기존 보안 평가는 두 가지 중대한 한계를 가진다. 첫째, 수정 사실을 탐지하거나 편집 이전(pre-edit) 동작을 재구성하기 위해 보통 원래의 pre-edit/unlearning 모델이나 보조 분류기(auxiliary classifiers)에 대한 접근을 요구한다. 둘째, 입력의 canonical tokenization 아래에서만 수정을 평가하여, tokenization을 암묵적으로 무해한 전처리 단계로 취급한다. 우리는 이 가정이 보안 공백을 만든다는 것을 보인다. 즉 동일한 입력 문자열이 서로 다른 계산 궤적(computational trajectories)을 유발하는 여러 유효한 alternative tokenization으로 표현될 수 있으며, 이로 인해 공격자는 국소적(localized) 수정을 우회하고 억제하려 했던 정보를 복원할 수 있다.

우리는 tokenization 기반 side channel을 악용해 (i) 수정된 지식을 탐지하고 (ii) 이에 대응하는 pre-edit 응답을 재구성하는, 단순하지만 강력한 reference-free 공격 Toketive를 제시한다. 이 공격은 공개된 모델만으로 동작하며, pre-edit 모델, 학습 데이터, shadow model, 보조 분류기를 모두 필요로 하지 않는다. 다섯 개 LLM, 여섯 개 데이터셋, 여섯 개 editing 및 unlearning 기법에 걸쳐, alternative tokenization의 38.6%가 수정을 우회하고 pre-edit 응답을 복원함을 확인했다. Toketive는 수정된 사실을 F1 score 84.2%로 탐지하여 가장 강한 baseline 대비 26.2%의 상대적 향상을 보이며, pre-edit 응답을 top-5 accuracy 74.5%로 재구성하여 최고 baseline보다 21.7% 높다. 우리의 결과는 국소적 수정이 대안적 표현(alternative representations)에 대한 적대적 평가 없이 견고한 지식 통제 경계(knowledge-control boundaries)로 취급되어서는 안 된다는 것을 보여준다.

## 필요성

Llama [1], Qwen [2], Mistral [3], Gemma [4], DeepSeek [5], GLM [6], OLMo [7]처럼 공개 가중치 모델이 독점 모델에 견줄 성능을 내면서 널리 배포되고 있으며, 2026년 8월 기준 Hugging Face에는 39만 5천 개 이상의 open-weight 텍스트 생성 체크포인트가 올라와 있다 [12]. 일부 프런티어 모델에 대한 접근이 (일시적으로) 제한된 사례처럼 주권(sovereignty) 우려도 open-weight 모델의 중요성을 키우고 있다 [13], [14], [15].

문제는 모델이 공개되면 개발자가 더 이상 inference stack을 통제하지 못한다는 점이다. 호스팅형 LLM API와 달리, 악의적 사용자를 포함한 다운스트림 사용자는 모델을 임의의 로컬 추론 설정에서 검사·수정·실행할 수 있다 [16], [17], [18]. 그런데도 개발자는 규제 변화 [19], [20], 새로 발견되는 취약점 [21], [22], 사실 지식의 변동 [23], 유해한 암기 콘텐츠 식별 [24]에 맞추어 공개된 모델이 안전하고 정확하며 규정을 준수하도록 유지해야 한다. 재학습은 비용이 과도하므로, 개인식별정보 제거 [29], 오래되거나 잘못된 지식 수정 [30], 불안전한 행동 완화 [31] 같은 표적 수정에는 model editing과 machine unlearning이 효율적 수단으로 쓰인다 [25], [26], [27], [28].

이 기법들의 목표는 수정된 지식이 이후 추론에서, 특히 복원을 시도하는 적대적 상황에서도 신뢰할 만하게 되살아나지 않도록 보장하는 것이다. 그러나 논문은 기존 평가가 canonical tokenization만을 전제하기 때문에, 공격자가 통제할 수 있는 tokenization이라는 공격면이 전혀 점검되지 않은 상태로 남아 있음을 지적한다. GDPR [59] 같은 규제의 잊힐 권리 요청에 따라 편집이 수행된 경우, 사후 감사자나 공격자는 수정된 모델만 가질 수 있으므로 pre-edit 모델을 요구하는 기존 분석 방식 자체가 현실과 맞지 않는다는 점도 필요성의 한 축이다.

## 연구 분야 흐름

Model editing은 재학습 없이 사전학습 언어 모델의 특정 사실 연관을 갱신하는 흐름으로, causal tracing으로 표적 사실을 저장한 feed-forward MLP 층을 찾고 표적 가중치 갱신을 적용하는 locate-then-edit 패러다임이 주류다 [32], [25], [44], [53], [64] 등. 가중치를 직접 바꾸지 않고 외부 모듈을 덧붙이는 parameter-preserving 계열도 존재한다 [78], [79], [80], [81], [82]. Machine unlearning은 특정 학습 데이터의 영향을 제거해 모델이 그 정보를 학습하지 않은 것처럼 행동하게 하는 상보적 목표를 추구하며 [83]–[88], 최근에는 unlearning을 표적 editing의 특수한 경우로 보는 통합적 관점이 제시되었다 [45], [34], [33]. 지식 수정의 대안으로 재학습은 가장 강한 보증을 주지만 배포 규모에서는 비현실적이고 [27], fine-tuning도 비용이 과도할 수 있으며 [44], retrieval-augmented generation(RAG)은 지식 통제를 모델 외부로 옮기지만 새로운 안전 실패를 유발할 수 있다 [89], [90].

평가 측면에서는 reliability, generalization, locality를 측정하는 벤치마크들이 정립되었고 [32], [91], [92], MQuAKE [62]와 ThinkEval [41]은 다중 홉·다단계 질의를 통한 간접적 지식 누출로 평가를 확장했다. 편집이 다른 사실로 전파되는 ripple effect는 잘 알려진 실패 양상이며 [61], [60], [46], [93], unlearning 쪽에서는 TOFU [63], WMDP [94], RWKU [95]가 표준 평가 묶음으로 쓰인다. 한편 adversarial tokenization 연구는 동일 문자열이 모델 어휘로 여러 noncanonical tokenization으로 표현될 수 있고 [101], 모델이 그런 표현에서도 상당한 의미 처리 능력을 유지하며 이 유연성이 요청의 가시적 텍스트를 바꾸지 않고도 안전장치 우회로 무기화될 수 있음을 보였다 [42], [43]. 본 논문은 이 두 흐름(국소적 지식 수정과 tokenization 변이)을 처음으로 결합한다.

## 관련 연구

Editing·unlearning의 보안 함의를 다룬 선행 연구는 정렬(alignment)과 안전 영향 [35], [36], [37], [96]–[98], [57] 외에도 다양한 공격을 제시해 왔다. Membership inference 계열은 forget-set 소속 여부를 사후에 추론할 수 있는지 평가하며 [38], [49], FUMA [48]는 gradient 신호로 무엇이 unlearning되었는지 식별한다. 학습 데이터 추출 공격은 editing을 통한 PII 제거가 불완전함을 보였고 [29], KSTER [39]는 가중치 차분에서 editing subject를 복원하며, TULA-DR [40]은 가중치 차분에 대한 제약 최적화로 unlearning된 텍스트를 재구성한다. DEED [47]는 편집 여부 탐지를 다루고, UnUnlearning [100]은 in-context learning으로 unlearning된 지식이 재도입될 수 있음을 보였으며, 데이터 중심 지표 [99]도 unlearning 측정을 개선한다.

논문은 Table I을 통해 이들과 Toketive를 세 축(pre-edit 모델 필요 여부, 보조 모델 학습 필요 여부, pre-edit 출력 재구성 가능 여부)으로 비교하고 세 가지 구조적 한계를 정리한다. **한계 I: pre-edit 모델 의존.** DEED [47]는 원 모델의 학습 집합을 얻기 위해 원 모델 접근을 가정하고, KSTER [39]는 가중치 차분 $\theta' - \theta$에 대한 스펙트럼 분석을 수행하며, TULA-DR [40]은 가중치 차분에 대한 제약 최적화를 푼다. 잊힐 권리 요청 등으로 편집이 수행된 뒤에는 원 모델이 일반적으로 남아 있지 않으므로 이 가정은 강하고 비현실적이다. **한계 II: shadow model 또는 보조 학습 의존.** U-LiRA [49]는 membership likelihood ratio를 구성하기 위해 다수의 shadow model을 학습하고, RULI [38]는 shadow model과 그 unlearning 변형을 함께 학습하며, DEED [47]는 편집/비편집 사실 레이블로 AdaBoost 분류기를 학습한다. 이는 학습 비용뿐 아니라 학습·unlearning 알고리즘과 데이터 분포에 대한 지식을 요구한다. **한계 III: pre-edit 모델 없이는 pre-edit 응답을 재구성하지 못함.** pre-edit 모델을 요구하지 않는 U-LiRA, RULI, FUMA [48] 가운데 어느 것도 pre-edit 응답을 복원하지 못한다. 앞의 둘은 membership inference이며, FUMA는 무엇이 unlearning되었는지는 gradient 신호로 알려주지만 pre-edit 출력은 복원하지 않는다. 삭제 요청 준수를 검증하는 감사자에게는 편집이 있었다는 사실만으로는 불충분하고, 무엇이 억제되었으며 그것이 여전히 접근 가능한지까지 확인해야 한다. 결정적으로 이들 모두는 canonical tokenization 아래에서만 평가하여, canonical 평가가 모델 행동을 특징짓기에 충분하다고 암묵적으로 가정한다.

## 배경 지식

### Model editing과 machine unlearning의 형식화

사실 지식은 주체 $s$, 관계 $r$, 객체 $o$로 이루어진 삼항 $(s, r, o)$로 표현되며, 자연어 프롬프트 $p(s,r)$(예: "The president of the United States is")가 주어지면 자동회귀 모델 $f_\theta$는 이상적으로 $o$에 높은 확률을 부여한다. Editing은 editing request $e = (s, r, o, o^*)$에 대해

$$f_{\theta'} = E(f_\theta, e)$$

를 산출하며, (i) Reliability: $f_{\theta'}(p(s,r))$가 $o^*$에 높은 확률 부여, (ii) Generalization: 같은 사실을 서술한 패러프레이즈에서도 $o^*$ 회상, (iii) Locality: 무관한 프롬프트의 예측은 대체로 불변을 요구한다. Unlearning은 forget set $D_f$에 대해

$$f_{\theta'} = U(f_\theta, D_f)$$

를 산출하며, (i) Efficacy: $p(s,r)$와 그 패러프레이즈에서 더 이상 $o$에 높은 확률을 부여하지 않음, (ii) Utility: $D_f$ 밖의 사실 예측은 불변, (iii) Privacy: forget-set 사실의 소속 여부가 학습된 적 없는 사실과 구별되지 않음을 요구한다. 두 기법 모두 locate-then-edit/unlearn의 2단계 절차를 따른다 [34], [45]. 먼저 causal tracing으로 표적 사실을 저장한 내부 구성요소(주로 특정 feed-forward MLP 층과 subject 토큰 위치)를 찾고, 다음으로 해당 구성요소에 한정된 가중치 갱신을 적용해 부수 피해를 최소화한다.

### Noncanonical tokenization

문자열 $x = (x_1, \ldots, x_n)$과 Byte-Pair Encoding(BPE)로 구성된 subword 어휘 $V$가 있을 때 [43], [42], $x$의 tokenization은

$$v_1 \oplus v_2 \oplus \cdots \oplus v_m = x$$

를 만족하는 토큰 열 $v = (v_1, \ldots, v_m)$이며 $v_i \in V$, $\oplus$는 문자열 연결이다. LLM 파이프라인은 학습된 merge 규칙을 순서대로 탐욕적으로 적용하는 결정적 tokenizer $k^*$로 각 문자열에 유일한 canonical tokenization $v^* = k^*(x)$를 대응시킨다. 그러나 $v^*$는 전체 tokenization 집합

$$T_V(x) = \{v : v \text{는 } x \text{의 유효한 tokenization}\}$$

의 한 원소일 뿐이며, $|T_V(x)|$는 BPE 어휘에서도 $|x|$에 대해 지수적으로 증가한다. 논문은 `"The phone number of John Doe is"`를 예로 들어, canonical 분절 $t_1$과 더 세분된 분절 $t_2$가 동일 문자열을 복원하면서도 다른 토큰 열과 서로 다른 내부 계산 궤적을 유발함을 보인다. $v \neq k^*(x)$인 임의의 $v \in T_V(x)$를 noncanonical tokenization이라 한다. LLM은 canonical tokenization만으로 학습되지만, noncanonical tokenization도 입력에 대한 상당한 의미 정보를 보존한다는 것이 선행 연구에서 확인되었다 [43]. 즉 조건부 분포는 의미적으로 유효한 상태를 유지하면서도 다른 내부 궤적을 활성화할 수 있다.

### Representational entanglement

입력 토큰이 층을 통과할 때 은닉 표현은 잔차·어텐션·feed-forward 변환에 따라

$$h_i^{(l)} = h_i^{(l-1)} + a_i^{(l)} + m_i^{(l)}$$

로 전개되며, 여기서 $a_i^{(l)}$와 $m_i^{(l)}$는 층 $l$의 attention 및 MLP 기여다. 선행 연구는 사실 연관이 중간 MLP 층의 부분집합(critical layers)에 의해 매개되고, 그 층에서 subject 토큰이 키 유사 활성 패턴을 일으켜 최종 예측을 형성한다고 보고한다 [32], [25], [46]. Representational entanglement [46]는 프로브 층 $L$에서의 두 표현 사이 코사인 유사도

$$S(i,j) = \cos(h_i^{(L)}, h_j^{(L)})$$

로 정의된다. 점수가 높을수록 두 프롬프트가 프로브 층에서 유사한 표현을 유발한다는 뜻이다. Toketive에서 이 유사도는 alternative tokenization 선택의 핵심 신호로 쓰인다. canonical 표현에 너무 가까운 tokenization은 표적 사실 연관을 보존하지만 편집·unlearning 갱신의 영향도 그대로 받고, 너무 먼 tokenization은 갱신을 우회하더라도 관련 사실 연관을 잃는다. 따라서 두 성질을 균형 짓는 중간 유사도 구간을 탐색하는 것이 적응적 tokenization sampler의 기초가 된다.

## 문제 정의

### 위협 모델

모델 $f_\theta$가 편집 또는 unlearning되어 $f_{\theta'}$가 되고 이것이 공개되는 상황을 가정한다. 공격자는 공개 모델의 파라미터와 내부 활성(internal activations)에 접근할 수 있는데, 이는 다운스트림 사용자가 모델을 로컬에서 검사·실행하는 open-weight 기반 모델의 의도된 사용 방식을 반영한다. 최근 연구들도 편집·unlearning된 정보를 복원하기 위해 파라미터와 내부 표현 접근을 활용했고 [47], [48], [39], open-weight 모델은 독점 API의 반복적 추론 비용을 피하면서 경쟁력 있는 성능으로 로컬 실행이 가능해 채택이 늘고 있다 [50]. 양자화·압축·하드웨어 인식 최적화의 진전으로 상용 하드웨어에서도 효율적 실행이 가능하다 [51], [52].

구체적으로 공격자는 (1) noncanonical tokenization을 포함한 임의의 토큰 열로 $f_{\theta'}$를 질의할 수 있고, (2) 임의의 층·위치에서 $f_{\theta'}$의 내부 활성을 읽을 수 있다. 반면 pre-edit 모델 $f_\theta$나 그 출력, 표적 사실의 pre-edit 응답 $o$, $f_\theta$의 학습·파인튜닝 데이터, 어떤 editing/unlearning 기법이 적용되었는지에 대한 정보, shadow model·보조 분류기·학습 설비에는 접근할 수 없다. 이 설정은 공개 모델에서 삭제되었어야 할 PII를 복원하려는 악의적 행위자, 또는 삭제 요청 준수를 감사하는 규제자 모두를 포괄한다.

### 범위

연구 범위는 주어진 프롬프트에 대해 표적 파라미터 부분집합만 수정하는 비정확(inexact) editing·unlearning, 특히 locate-then-edit 패러다임 [44], [25], [53]이다. 최근 연구는 unlearning을 locate-then-edit의 특수 사례로 개념화한다 [34], [45]. Fine-tuning 기반 접근 [54], [55], [56]은 기저 지식을 제거하는 대신 표적 출력을 억제하는 데 그치고 무관한 지식·능력에 상당한 부수 변화를 일으키므로 제외한다 [28], [57], [58]. 실제로 Appendix B 실험에서 fine-tuning은 noncanonical tokenization을 더 효과적으로 억제하지만, editing 기법 대비 $5.2\times$ 큰 ripple effect를 발생시켜 locality를 크게 희생한다(bypass rate 0.32 → 0.08, ripple $1.0\times$ → $5.2\times$).

### 공격 목표와 측정 정의

공격자는 결합된 두 목표를 추구한다. ① Edit/Unlearning Detection: $f_{\theta'}$와 프롬프트 $p(s,r)$만으로 사실 $(s, r, \cdot)$이 학습 이후 수정되었는지 판정한다. ② Adversarial Reconstruction: 수정되었다면 pre-edit 연관 $(s, r, o)$의 원래 객체를 복원한다. 탐지만으로는 편집 발생 사실만 확인되고, 복원만으로는 어떤 사실을 표적할지 미리 알아야 하므로 두 목표는 의도적으로 결합되어 있으며, Toketive는 tokenization 공간에 대한 통합 탐색 절차로 둘을 동시에 처리한다.

평가를 위해 두 가지 양을 정의한다. **Convergence**: $o \in \hat{y}_{v^*}$일 때, noncanonical tokenization $u$가 수렴적이라는 것은 편집 전 삼항 $(s,r,o)$의 객체 $o$가 생성 연속열 $\hat{y}_u$에 나타남을 뜻한다. **Bypass rate**: 각 사실에 대해 $K = 30$개의 noncanonical tokenization $u_i$를 만들고

$$\text{bypass rate} = \frac{1}{K}\sum_{i=1}^{K} \mathbf{1}[o \in \hat{y}_{u_i}]$$

로 계산한다. 여기서 $o$는 갱신 이전 객체, $\hat{y}_{u_i}$는 $u_i$ 아래의 모델 완성이다. tokenization에 불변인 갱신이라면 bypass rate는 0이어야 하며, 값이 높다는 것은 갱신이 canonical 계산 경로만 패치하고 대안 궤적에는 잔여 사실 연관을 남겼다는 뜻이다. 탐지 판정은 detection band에서 모은 후보 집합 $C_{\text{det}}$에 대한 canonical-response bypass rate

$$\nabla = \frac{1}{|C_{\text{det}}|}\sum_{u \in C_{\text{det}}} \mathbf{1}[o^* \in \hat{y}_u]$$

를 임계값 $\tau_{\text{det}}$와 비교해, $\nabla < \tau_{\text{det}}$이면 edited(또는 unlearned), 그렇지 않으면 unedited로 내린다. 여기서 $o^*$는 editing에서는 갱신된 표적 답, unlearning에서는 unlearning 절차가 지정하고 canonical 프롬프트가 산출하는 결정적 대체 응답(예: `"unknown"`)이다.

## 주요 기여

### ① Tokenization을 공격면으로 규명

공격자가 통제하는 tokenization이 공개 이후 지식 통제에서 그동안 간과된 공격면임을 확인하고, 최신 국소적 editing·unlearning 기법이 동일 입력의 대안적 표현에 대해 일반화하지 못함을 보였다. 이 취약성은 사용자가 자유롭게 alternative tokenization으로 질의를 구성할 수 있는 open-weight 모델에서 특히 중요하다.

예측 가능성 분석(Q1)에서는 representational entanglement가 noncanonical tokenization의 수렴 여부를 예측하는 신호임을 확인했다. 다섯 모델·여섯 데이터셋에서 entanglement는 AUC 0.684~0.850, rank-biserial 상관 $|rb|$ 0.368~0.699를 기록했고, 어휘적 baseline인 edit distance(정규화 Levenshtein 거리)는 AUC 0.526~0.674, $|rb|$ 0.052~0.348에 머물렀다. entanglement의 최악 결과(AUC 0.684)가 edit distance의 최선 결과(AUC 0.674)를 넘어서, 두 신호 사이에 일관된 분리가 존재한다. 격차는 RippleEdits에서 가장 두드러져, edit distance는 모든 모델에서 무작위 수준에 근접하는 반면 entanglement는 신뢰성을 유지했다. 30개 모델–데이터셋 조합 전부에서 수렴 tokenization의 평균 entanglement가 비수렴보다 높았고(차이 0.124~0.278), edit distance는 방향이 반대이면서 크기도 작았다($-0.011$~$-0.094$). Calibration 분석에서도 entanglement의 ECE가 모든 설정에서 edit distance보다 낮았으며, TOFU-World Facts에서는 edit distance ECE가 모든 모델에서 0.4를 넘는 반면 entanglement는 0.25 이하였다. MCE는 대부분의 조합에서 entanglement가 우세했고, **OLMo2**의 Real Authors(0.330 대 0.436)와 CounterFact(0.250 대 0.263)가 부분적 예외였다.

Tokenization 불변성 평가(Q2)에서 bypass rate는 19%~57% 범위, 평균 38.6%로 어떤 기법도 tokenization 불변 갱신을 달성하지 못했다. 결과상 가장 견고한 AlphaEdit조차 상당한 비율의 noncanonical tokenization이 갱신 이전 응답을 복원하도록 남겨두었고, LTU(Locate-then-Unlearn)가 가장 취약해 모든 모델의 Real Authors와 World Facts에서 특히 높은 bypass rate를 보였다. **Llama3**에 MEMIT을 적용한 사례에서는 편집 전 70.1%였던 old answer 비율이 편집 후 43.8%로 떨어졌을 뿐이며, 26.5%는 old도 new도 아닌 응답을 냈다. old answer를 내는 tokenization은 높은 entanglement 구간에, new answer를 내는 tokenization은 낮은 구간에 몰려 Toketive가 이용하는 band 구조와 일치했다.

### ② Toketive: reference-free 적대적 공격

공개 모델만 사용하고 pre-edit 모델, 학습 데이터, shadow model, 보조 분류기, 외부 참조 출력을 전혀 요구하지 않으면서, 취약한 수정을 탐지하고 pre-edit 응답을 재구성하는 tokenization 인식 공격을 개발했다. Toketive는 입력 문자열을 정확히 보존하고 유효한 tokenization만 변화시켜 tokenization 의존 계산을 분리하며, 공유 상단 구성요소인 adaptive tokenization sampler의 출력을 탐지와 복원 두 단계로 라우팅한다. Sampler는 ripple effect 예측용으로 제안된 representational entanglement [46]를 단일 프롬프트의 tokenization 공간 내 bypass 예측 신호로 전용한다. 단일 aggressiveness 파라미터 $\alpha \in [0,1]$(초기값 0.5)이 분절 정도를 조절하고, 직전 열 개 표본의 이동 평균 유사도를 이용한 비례 제어기로 자동 조정되며, 대역에 들어오면 작은 무작위 섭동으로 정체를 피한다. 후보 $u$는 연결 결과가 원 문자열 $p$를 정확히 복원할 때만 수용되고, $S(u, v^*) = \cos(h_u^{(L)}, h_{v^*}^{(L)})$ 점수에 따라 detection band, reconstruction band, 대역 외(폐기)로 분류된다. 프로브 층은 $L = \lfloor \text{depth}/3 \rfloor$로 선행 연구 [46]를 따르며, subject 경계는 tokenization마다 재계산되어 다중 토큰 subject, byte-level 토큰, tokenizer 고유 분절을 자연스럽게 처리한다. 복원 단계는 $o^*$를 포함하는 응답을 걸러낸 bypass 집합

$$C_{\text{byp}} = \{u \in C_{\text{rec}} : o^* \notin \hat{y}_u\}$$

에서 객체 스팬 $c_u = \hat{y}_u[|p(s,r)|:]$를 추출해 다수결

$$\hat{o} = \arg\max_c \sum_{u \in C_{\text{byp}}} \mathbf{1}[c_u = c]$$

로 pre-edit 응답을 재구성하고, 빈도 순위로 top-$k$ 정확도를 측정한다. 탐색은 tokenization 공간을 완전 열거하지 않고 고정된 최대 시도 예산 아래 적응적 표본화를 수행하므로, 런타임은 지수적 공간이 아니라 표본 예산에 의해 제한된다. 사실당 비용은 $O(M(n_{\text{det}} + n_{\text{rec}}) \cdot F + (n_{\text{det}} + n_{\text{rec}}) \cdot G)$이고, $M = 300$, $n_{\text{det}} = 20$, $n_{\text{rec}} = 50$이며 $G \gg F$이다. 하이퍼파라미터는 **Llama3** + MEMIT + Known-1000 단일 설정에서 한 번만 보정해 $\tau_{\text{det}} = 0.10$(F1 82.9%에서 정점), entanglement detection band $[0.30, 0.50)$, reconstruction band $[0.70, 1.00)$, edit distance 쪽은 각각 $[0.80, 1.00)$과 $[0.00, 0.50)$로 고정했고, 나머지 179개 조합에 추가 조정 없이 적용했다.

### ③ 포괄적 평가

NVIDIA H200 GPU(각 141 GB) 클러스터에서 다섯 모델(**Llama3** 8B Instruct, **Llama3.1** 8B Instruct, **OLMo2** 13B Instruct, **Tulu3** 8B, **Tulu3.1** 8B), 여섯 데이터셋(CounterFact [32], RippleEdits [61], MQuAKE [62], Known-1000 [32], TOFU – World Facts [63], TOFU – Real Authors [63]), 여섯 기법(AlphaEdit [44], RECT [53], MEMIT [25], PRUNE [64], CoME [33], LTU [34])에 대해 평가했다. CounterFact는 처음 1000개 표본을, MQuAKE와 RippleEdits는 각 1000개 사실 삼항과 프롬프트 템플릿을 사용했고, TOFU는 Q&A 쌍을 프롬프트 형식으로 변환했다. 신뢰할 수 있는 정답 기준을 위해 canonical tokenization이 정답을 내는 사례로 한정했고, 표본화 노이즈를 배제하기 위해 모든 실험에서 결정적 디코딩(탐욕적 디코딩, 표본화 없음)을 썼다. 또한 Efficacy Score [32] 기준으로 편집이 성공한($P(\text{new fact}) > P(\text{old fact})$) 사례만 분석했다. 음성 표본은 동일 탐지기를 편집된 모델과 대응 비편집 기반 모델에 각각 적용해 구성했으므로, 거짓 양성은 별도로 만든 음성 표본이 아니라 noncanonical tokenization 자체의 내재적 변동에서만 발생한다.

탐지(Q3)에서 Toketive는 모든 모델·데이터셋에서 최고 F1을 기록해 평균 84.2%를 달성했다. 두 번째인 edit distance는 66.7%였다. Random sampling은 많은 설정에서 거의 0에 가까운 FPR과 완벽한 정밀도를 보였지만 TPR이 매우 낮아, 균일 표본화된 noncanonical tokenization은 detection band에 거의 들어오지 못해 편집된 사실을 안정적으로 표시하지 못했다. FUMA [48]를 변형해 $f_{\theta'}$만으로 토큰 평균 손실의 전체 파라미터 gradient L2 노름을 점수로 쓰는 FUMA-gradient baseline은 대부분 조합에서 TPR과 FPR이 동시에 1에 가까워 정밀도가 약 50%로 붕괴하고 평균 F1 60.8%에 그쳤다. 즉 원 모델을 쓸 수 없는 이 엄격한 설정에서 gradient 노름 신호는 비판별적이다.

복원에서는 Toketive가 평균 top-1 60.9%, top-5 74.5%로, 다른 baseline을 최소 21.7% 앞섰다. Random sampling은 평균 top-1 30.7%, top-5 36.9%로, band 필터링 없는 bypass 연속열은 너무 다양해 갱신 이전 객체로 수렴하지 못했다. Edit distance는 random보다 개선되고 일부 **OLMo2** 설정에서 Toketive에 근접했으나 대다수 조합에서 열세였고, 격차는 MQuAKE와 CounterFact에서 가장 컸다. 정성적으로, AlphaEdit으로 편집된 **Llama3**에서 canonical tokenization은 편집된 답 *George R.R. Martin*을 내지만 한 noncanonical tokenization은 pre-edit 답 *George Orwell*을 복원했고, 또 다른 tokenization은 편집 행동에서 벗어났으나 *Michael Moorcock*이라는 오답을 내 복원에 실패했다.

### ④ 방어 분석과 robustness-locality 트레이드오프

발견된 bypass tokenization을 이후 갱신에 반영하는 tokenization 인식 적응적 editing 전략을 조사했다. **Llama3**에서 representational entanglement 0.9를 초과하는 1,000개 edit-control 사실 쌍을 대상으로 적응적 MEMIT을 최대 네 번 반복하며, 매 반복마다 Toketive로 갱신 이전 응답을 여전히 복원하는 noncanonical tokenization을 찾아 추가 unlearning 표적으로 삼았다. 그 결과 bypass rate는 표준 MEMIT의 0.32에서 2회 반복 후 0.14, 3회 0.09, 4회 0.04로 감소했다. 그러나 견고성 향상은 locality를 크게 희생했다. Ripple effect가 표준 MEMIT의 $1.0\times$에서 $3.3\times$, $6.7\times$, $8.6\times$로 증가해, 더 넓어진 갱신이 표적 밖 인접 사실을 상당히 변경했다. 즉 bypass rate를 0.32에서 0.04로 낮추려면 ripple effect가 $8.6\times$ 늘어나는 robustness-locality 트레이드오프가 존재한다.

일반적으로 tokenization 불변성 강제는 유효 tokenization 공간이 입력 길이에 따라 커지고 서로 다른 tokenization이 서로 다른 내부 궤적을 유발하기 때문에 어렵다. 반복 editing으로 이 공간을 명시적으로 덮으려 하면 점점 더 넓은 파라미터 수정이 필요해지므로, 국소적 갱신의 단순 확장은 표적 editing·unlearning의 동기인 locality를 보존하면서 확장 가능한 해법이 되기 어렵다 [61], [60], [46]. 논문은 tokenization에 무관한 표현을 학습하는 등 구조적·표현적 접근이 더 원리적인 해법일 수 있지만, subword tokenization이 모델 내부와 상호작용하는 방식을 재고해야 한다고 보며, 부수 효과를 크게 늘리지 않는 tokenization 견고 지식 수정은 열린 문제로 남긴다.

### 윤리 및 공개

연구는 공개된 모델과 벤치마크 데이터셋만 사용했고 민감한 실제 데이터를 다루지 않았으며, 위협 모델을 동일 입력 문자열의 alternative tokenization으로 공개 모델을 질의하는 범위로 한정해 비공개 학습 데이터나 독점 시스템, 숨겨진 인터페이스 접근이 필요한 공격은 다루지 않는다. 대규모 악용을 위한 배포용 도구 대신 구조적 취약성에 초점을 두며, 저장소에 연구·평가 목적 한정 사용 고지를 포함할 것이라고 밝힌다. 재현을 위해 Toketive 소스 코드, RQ-1·RQ-2·RQ-3 전 실험의 스크립트와 설정 파일, 실험 워크플로·환경 문서를 익명 저장소로 제공한다. 평가된 다섯 모델은 모두 HuggingFace에서 접근 가능한 공개 가중치 모델이고 데이터셋도 모두 공개 벤치마크다.

## 제시한 방법론

### 위협 모델과 공격 목표

Toketive는 편집·언러닝이 적용되어 공개된 모델 $f_{\theta'}$만 접근 가능한 참조 비의존(reference-free) 공격이다. 공격자는 (1) 임의의 토큰 시퀀스, 즉 어떤 문자열의 비정규 토크나이제이션(noncanonical tokenization)으로도 $f_{\theta'}$를 질의할 수 있고, (2) 임의 층·위치의 내부 활성값을 읽을 수 있다. 반면 편집 전 모델 $f_\theta$, 편집 전 응답 $o$, 학습·파인튜닝 데이터, 적용된 편집/언러닝 기법 정보, shadow model·보조 분류기·학습 설비에는 접근할 수 없다. 목표는 ① 편집/언러닝 탐지(해당 사실 $(s,r,\cdot)$이 사후 수정되었는지 판정)와 ② 적대적 복원(수정되었다면 원래 객체 $o$ 회복)이며, 두 목표는 의도적으로 결합된다. 탐지 없는 복원은 어떤 사실을 겨냥할지 미리 알아야 하고, 복원 없는 탐지는 편집 발생 사실만 확인할 뿐이기 때문이다.

### 기본 개념: 토크나이제이션 집합과 표현 얽힘

문자열 $x$와 서브워드 어휘 $V$에 대해 토크나이제이션은 $v_1 \oplus v_2 \oplus \cdots \oplus v_m = x$($\oplus$는 문자열 접합, $v_i \in V$)를 만족하는 토큰 열이다. 결정적 토크나이저 $k^*$는 학습된 머지 규칙을 탐욕적으로 적용해 유일한 정규 토크나이제이션(canonical tokenization) $v^* = k^*(x)$를 산출하지만, 이는 전체 집합

$$T_V(x) = \{v : v \text{ is a valid tokenization of } x\}$$

의 한 원소일 뿐이며 $|T_V(x)|$는 BPE 어휘에서도 $|x|$에 따라 지수적으로 증가한다. $v \neq k^*(x)$인 원소를 비정규 토크나이제이션이라 부른다. LLM은 정규 토크나이제이션만으로 학습되지만 비정규 토크나이제이션도 상당한 의미 정보를 보존하면서 서로 다른 내부 계산 궤적을 활성화한다 [43].

은닉 표현은 잔차·어텐션·피드포워드 변환을 따라

$$h_i^{(l)} = h_i^{(l-1)} + a_i^{(l)} + m_i^{(l)}$$

로 진화하며, 사실 연합은 중간 MLP 층(critical layers)의 부분집합이 매개한다 [32], [25], [46]. 탐침 층 $L$에서의 표현 얽힘(representational entanglement) [46]은 코사인 유사도로 정의된다.

$$S(i,j) = \cos\!\left(h_i^{(L)}, h_j^{(L)}\right)$$

### 설계 원리: 중간 유사도 대역

Toketive의 핵심 설계 선택은 얽힘 점수를 단일 프롬프트의 토크나이제이션 공간 내 **우회 예측 신호**로 재활용하는 것이다. 정규 표현과 너무 가까운 토크나이제이션은 대상 사실 연합을 보존하지만 편집/언러닝 업데이트에도 함께 영향을 받고, 너무 먼 토크나이제이션은 업데이트를 우회하더라도 관련 사실 연합을 잃는다. 따라서 두 성질을 균형시키는 중간 유사도 구간을 탐색한다. 저자들은 이 신호를 지식 국소화에 대한 특정 이론의 근거가 아니라 공격 성공률로만 평가되는 알고리즘적 라우팅 휴리스틱으로 명시하며, 형식적 특성화는 미해결 문제로 남긴다.

### 정규 참조 단계 (CANONICALREF)

표본 추출 전에 $v^* = k^*(p(s,r))$에 대해 단 한 번의 순방향 패스를 수행해 두 값을 기록한다. 하나는 정규 출력 $o^* \leftarrow f_{\theta'}(v^*)[|p|:]$(편집 후 응답으로, 편집에서는 갱신된 목표 답, 언러닝에서는 언러닝 절차가 지정한 결정적 대체 응답, 예: "unknown"), 다른 하나는 마지막 critical layer $L$의 주어 마지막 토큰 위치 은닉 상태 $h^* = \mathrm{HIDDEN}(f_{\theta'}, v^*, L, s)$이다. 탐침 층은 $L = \lfloor \mathrm{depth}/3 \rfloor$로 설정하며, 중간층 표현이 그래디언트 기반 대안 [60]보다 얽힘 지표로 훨씬 신뢰도가 높다는 선행 결과 [46]를 따른다. 이후 모든 표본 점수는 $h^*$ 기준으로 측정된다.

### 적응형 토크나이제이션 샘플러 (SAMPLE)

샘플러는 단일 공격성 파라미터 $\alpha \in [0,1]$로 제어되며 $\alpha_0 = 0.5$로 초기화된다. $\alpha$가 클수록 프롬프트가 더 세밀한 서브워드로 분절되고, 작을수록 정규형에 가까운 분절이 생성된다. 후보 $u$마다 순방향 패스로

$$S(u, v^*) = \cos\!\left(h_u^{(L)}, h_{v^*}^{(L)}\right)$$

를 계산하고, 접합 결과가 원 문자열 $p$와 정확히 일치할 때만 후보를 수용해 문자 시퀀스 불변성을 보장한다. 점수에 따라 후보는 세 경로로 라우팅된다: 탐지 대역 $[\beta_l^{\text{det}}, \beta_h^{\text{det}})$는 Phase ①로, 복원 대역 $[\beta_l^{\text{rec}}, \beta_h^{\text{rec}})$는 Phase ②로, 대역 밖은 생성 질의 없이 폐기된다.

주어 구간은 토크나이제이션마다 독립적으로 재식별되므로 주어가 여러 토큰, 바이트 수준 토큰, 토크나이저별 분절로 쪼개지는 경우를 자연히 수용한다. 토크나이저는 고정 어휘 $V$를 갖는 블랙박스 매핑으로 취급하여 BPE 등 특정 방식에 의존하지 않고, 동일 문자열로 디코딩되는 $T_V(x)$ 위에서만 작동한다.

**비례 제어기(proportional controller).** 샘플러는 폐기된 후보까지 포함한 최근 얽힘 점수의 롤링 윈도우(다양성 버퍼)를 유지한다. 최근 $B = 10$개 점수의 평균 $\bar{s}$를 목표 대역과 비교해, $\bar{s} > \beta_h$면 $\alpha \leftarrow \min(0.95, \alpha + \eta)$로 올려 더 발산적인 분절을 만들고, $\bar{s} < \beta_l$면 $\alpha \leftarrow \max(0.05, \alpha - \eta)$로 내려 후보를 대역으로 끌어당긴다. 이미 대역 안이면 $\varepsilon \sim \mathcal{U}(-\eta/2, \eta/2)$의 작은 난동을 더해 고정된 공격성에서 탐색이 정체되는 것을 방지한다($\eta = 0.08$). 수용된 표본만이 아니라 모든 시도의 점수를 기록하는 이유는 제어기가 표본 분포의 전체 모습을 보고 수용률이 낮은 구간에서 빠르게 회복하도록 하기 위해서다.

**후보 생성(GENTOK)과 유효성 제약.** $\alpha$는 세그먼트당 최대 토큰 수 $m$을 결정한다($\alpha < 0.3$이면 1, $< 0.5$면 2, $< 0.7$면 3, 그 외 4). 위치 $i$에서 후보 집합은 최대 세그먼트 길이 $W = 19$자 제한, $|\tau(c_{ij})| \le m$, 그리고 왕복 제약 $\tau^{-1}(\tau(c_{ij})) = c_{ij}$를 만족하는 $(\tau(c_{ij}), j)$들로 구성된다. 이 왕복 검사가 토크나이저별 규칙 없이 바이트·Unicode 안전성을 보장한다. 후보가 없으면 단일 문자로 대체해 진행을 보장한다. 가중치는 $\alpha \le 0.5$일 때 $w(t,j) \leftarrow \ell/2$로 긴 세그먼트를, 그 외에는 $w(t,j) \leftarrow 1/\max(1, \ell/2)$(단 $|t| > 1$이면 2배)로 짧고 다중 토큰인 분할을 선호하며, $P(t,j) = w(t,j)/\sum_{(t',j')} w(t',j')$로 표집한다. $u = v^*$이거나 $\tau^{-1}(u) \neq p$이면 $\bot$를 반환하고, 중복 토크나이제이션은 제거되며 특수 토큰은 절대 삽입하지 않는다.

**예산과 폴백.** 요청 표본 $n$개당 시도 예산은 $M = 300$, 총 최대 $nM$ 시도이며 정족수가 차면 즉시 종료된다. 예산이 먼저 소진되면 검증은 통과했으나 대역 밖인 후보를 대역까지의 거리 $d = \min(|e-\beta_l|, |e-\beta_h|)$ 오름차순으로 채워 표본 크기를 고정하고 사실 간 통계 비교 가능성을 유지한다. 즉 대역 경계는 경성 보장이 아닌 표집 목표이며, 폴백 풀도 부족하면 $n$보다 적게 반환한다.

### Phase ①: 편집/언러닝 탐지

$n_{\text{det}}$개의 탐지 대역 후보 $C_{\text{det}}$를 모으고, 각 $u \in C_{\text{det}}$에 대해 완성 $\hat{y}_u = f_{\theta'}(u)$가 편집 후 객체 $o^*$를 포함하는지 확인해 정규 응답 우회율을 계산한다.

$$\nabla = \frac{1}{|C_{\text{det}}|} \sum_{u \in C_{\text{det}}} \mathbf{1}\left[o^* \in \hat{y}_u\right]$$

업데이트가 토크나이제이션 전반으로 일반화되면 $\nabla \approx 1$이고, 표면적 패치에 그치면 다수가 우회하여 $\nabla$가 낮아진다. 판정 규칙은

$$\ell = \begin{cases} \text{edited (or unlearned)} & \text{if } \nabla < \tau_{\text{det}} \\ \text{unedited (or not unlearned)} & \text{otherwise}\end{cases}$$

이며, $\ell$이 미수정으로 판정되면 즉시 $(\text{unedited}, \bot)$를 반환하고 종료한다.

### Phase ②: 편집 전 응답 복원

$\ell = \text{edited}$일 때만 실행된다. 복원 대역은 정규 표현과 내부적으로 충분히 유사해 동일한 사실 지식을 끌어오지만, 키 벡터가 $k^*$와 완전히 정렬되지 않아 패치된 회로를 벗어날 만큼은 다른 토크나이제이션을 포착한다. $n_{\text{rec}}$개 후보 $C_{\text{rec}}$에서 편집 후 답이 나온 표본을 걸러 우회 집합을 만든다.

$$C_{\text{byp}} = \{u \in C_{\text{rec}} : o^* \notin \hat{y}_u\}$$

각 출력에서 객체 구간 $c_u = \hat{y}_u[|p(s,r)|:]$를 추출하고 다수결(plurality vote)로 집계한다.

$$\hat{o} = \arg\max_{c} \sum_{u \in C_{\text{byp}}} \mathbf{1}\left[c_u = c\right]$$

$C_{\text{byp}} = \emptyset$이면 $(\text{edited}, \bot)$를 반환한다. 평가 시 후보 객체 구간을 빈도순으로 정렬해 최빈값을 top-1 예측으로, 상위 $k$개 안에 정답 편집 전 객체가 포함되는지를 top-$k$ 정확도로 측정한다.

### 하이퍼파라미터 보정

탐지 임계값과 대역 경계는 단일 개발 설정(**Llama3** + MEMIT + Known-1000)에서 한 번만 보정한 뒤 나머지 179개 실험 전체에 고정 적용되며, 모델·데이터셋·편집 기법별 재조정은 수행하지 않는다. 이는 Toketive가 표적별 보정에 의존하지 않음을 보이기 위한 의도적 선택이다. $\tau_{\text{det}}$는 F1이 $\tau^* = 0.10$에서 82.9%로 뾰족하게 최대가 되고 그 이상에서 단조 감소하므로 $\tau_{\text{det}} = 0.10$으로 고정한다. 대역 경계는 탐지에서 $\beta_l^{\text{det}} = 0$을 고정하고 $\beta_h^{\text{det}}$를, 복원에서 $\beta_h^{\text{rec}} = 1.0$을 고정하고 $\beta_l^{\text{rec}}$를 각각 F1과 top-1 정확도 기준으로 스윕해 결정했다. 표현 얽힘 샘플러는 탐지 대역 $[0.30, 0.50)$, 복원 대역 $[0.70, 1.00)$를, edit distance 샘플러는 탐지 대역 $[0.80, 1.00)$, 복원 대역 $[0.00, 0.50)$를 사용한다. 표본 정족수는 $n_{\text{det}} = 20$, $n_{\text{rec}} = 50$이다.

### 탐색 비용

Toketive는 토크나이제이션 공간을 전수 열거하지 않고 고정된 최대 시도 예산 아래 적응적으로 표집하므로, 실행 시간은 지수적으로 큰 공간 크기가 아니라 표집 예산에 의해 한정된다. 사실 하나당 지배적 비용은 순방향 패스 수이며

$$O\!\left(M(n_{\text{det}} + n_{\text{rec}}) \cdot F + (n_{\text{det}} + n_{\text{rec}}) \cdot G\right)$$

로, $F$는 순방향 패스 1회 비용, $G$는 출력 길이에 비례하는 자기회귀 생성 비용($G \gg F$)이다. 은닉 상태 추출이 없는 random·edit distance 기준선은 점수화에 해당하는 $F$ 항이 사라져 $O((n_{\text{det}} + n_{\text{rec}}) \cdot G)$가 된다.

### 방어 측 변형: 적응형 MEMIT

토크나이제이션 인지 방어의 실현 가능성을 보기 위해 MEMIT의 적응형 변형을 함께 제시한다(Algorithm 2). 정규 프롬프트 $p_c$에 표준 MEMIT을 적용해 $o_{\text{new}}$를 주입한 뒤, 매 반복에서 $p_c$의 비정규 토크나이제이션 집합을 생성하고 응답이 여전히 $o_{\text{old}}$를 포함하는 우회 토크나이제이션 $b$를 찾는다. 그러한 $b$가 있으면 동일한 언러닝 목표 $o_{\text{new}}$로 MEMIT을 재적용하고, 우회가 없거나 최대 반복 수 $T$(실험에서는 4)에 도달하면 종료한다. 즉 반복마다 언러닝 절차가 명시적으로 덮는 토크나이제이션 집합이 확장되지만, 그 대가로 업데이트가 영향을 미치는 모델 영역도 함께 넓어진다.

## 실험 및 평가

### 실험 설정

모든 실험은 141GB 메모리의 NVIDIA H200 GPU 클러스터에서 수행되었다. 저자들은 세 가지 연구 질문을 설정한다. _Q1_(예측 가능성, Predictability): 편집되지 않은 모델에서 대체 토크나이제이션이 정규 응답으로 수렴할지를 예측하는 측정 가능한 신호가 존재하는가. _Q2_(토크나이제이션 불변성, Tokenization Invariance): 현재의 editing·unlearning 기법이 동일한 의미의 프롬프트의 대체 토크나이제이션 전반에 일반화되는 갱신을 만들어내는가. _Q3_(공격 효능, Adversarial Efficacy): 공격자가 pre-edit model이나 pre-edit 응답에 접근하지 않고 사실의 변경 여부를 식별하고 pre-edit 응답을 복원할 수 있는가.

**데이터셋.** 사실 편집과 machine unlearning을 포괄하는 6개 벤치마크를 사용한다. ① CounterFact: $(s,r,o)$ 삼항과 반사실 변형으로 프롬프트를 구성해 편집의 efficacy, 패러프레이즈 일반화, 특이성을 평가한다. ② RippleEdits: 단일 사실 편집의 ripple effect를 측정하는 진단용 벤치마크. ③ MQuAKE: 상호 의존적 사실의 연쇄로 구성된 multi-hop 질문 집합으로, 반사실 및 시간적 서브셋을 포함한다. ④ Known-1000: 구조화된 지식베이스 삼항에서 파생된 질의응답 데이터셋. ⑤ TOFU – World Facts: 일반 상식 Q&A로 unlearning의 부수적 성능 저하 여부를 본다. ⑥ TOFU – Real Authors: 실존 작가에 관한 Q&A로 의미적으로 유사한 엔티티에 대한 간섭을 평가한다. CounterFact는 앞 1000개 샘플, MQuAKE와 RippleEdits는 각 1000개 사실 삼항과 프롬프트 템플릿을 추출해 사용하며, TOFU는 Q&A를 프롬프트 형식으로 변환해 편집·unlearning 프레임워크와 호환시켰다. 신뢰 가능한 정답을 보장하기 위해 **정규 토크나이제이션(canonical tokenization)이 정답을 산출하는 인스턴스로만** 평가를 제한했고, 샘플링 잡음을 배제하기 위해 모든 실험에서 결정적 디코딩(greedy decoding, 샘플링 없음)을 사용했다.

**모델과 기법.** 5개 모델 **Llama3**(8B, Instruct), **Llama3.1**(8B, Instruct), **OLMo2**(13B, Instruct), **Tulu3**(8B), **Tulu3.1**(8B)과 6개 기법을 평가한다. ① AlphaEdit은 편집 섭동을 보존 지식의 null space로 투영한다. ② RECT는 상대적 파라미터 변화량 기반으로 가중치 갱신을 정규화해 일반 능력 저하를 완화한다. ③ MEMIT은 트랜스포머 층의 key-value 메모리 구조를 직접 수정해 대규모 사실 삽입을 지원한다. ④ PRUNE은 편집된 가중치 행렬의 조건수를 제약해 순차 편집 중 섭동을 제한한다. ⑤ CoME은 unlearning과 editing을 결합해 지식 충돌을 줄인다. ⑥ Locate-then-Unlearn(LTU)은 태스크별 뉴런을 식별해 선택적으로 unlearning한다.

**하이퍼파라미터.** 탐지 임계값 $\tau_{\text{det}}$과 band 경계는 **Llama3** + MEMIT + Known-1000이라는 단일 held-out 구성에서 한 번만 보정하고, 남은 179개 실험(총 180개)에 모델·데이터셋·기법별 재조정 없이 고정 적용했다. F1은 $\tau^{*}=0.10$에서 82.9%로 뾰록하게 최대가 되고 그보다 큰 값에서는 단조 감소한다. representational entanglement sampler의 detection band는 $[\beta_l^{\text{det}},\beta_h^{\text{det}})=[0.3,0.5)$, reconstruction band는 $[0.7,1.0)$이며, edit distance sampler는 각각 $[0.80,1.00)$과 $[0.00,0.50)$을 사용한다. 샘플 쿼터는 $n_{\text{det}}=20$, $n_{\text{rec}}=50$이고 요청 샘플당 최대 제안 예산은 $M=300$, 프로브 층은 $L=\lfloor \text{depth}/3 \rfloor$이다.

### Q1: 토크나이제이션 수렴의 예측 가능성

각 프롬프트 $p(s,r)$마다 30개의 무작위 noncanonical tokenization을 생성한다. 수렴(convergence)은 편집되지 않은 삼항의 객체 $o$가 생성 연속부 $\hat{y}_u$에 나타나는 경우로 정의한다. 후보 예측 신호는 (1) representational entanglement — 프로브 층에서 $u$와 $v^{*}$의 은닉 상태 간 유사도, (2) edit distance — 토큰 시퀀스 간 정규화 Levenshtein 거리(어휘적 베이스라인)이다. 평가 지표는 AUC와 rank-biserial 상관 $|rb|$다.

representational entanglement는 AUC 0.684~0.850, $|rb|$ 0.368~0.699를 기록했고, edit distance는 AUC 0.526~0.674, $|rb|$ 0.052~0.348에 머물렀다. 특히 representational entanglement의 **최악값(AUC = 0.684)이 edit distance의 최고값(AUC = 0.674)을 상회**해 두 신호 사이에 일관된 분리가 존재한다. 격차는 RippleEdits에서 가장 크게 나타나, 이 데이터셋에서 edit distance는 모든 모델에서 무작위 성능에 근접했다. 평균 점수 분석에서도 representational entanglement는 30개 모델–데이터셋 조합 **전부**에서 수렴 토크나이제이션이 더 높은 값을 가져 차이가 0.124~0.278이었고, edit distance는 방향이 반대이며 차이도 $-0.011$~$-0.094$로 미미했다. 보정(calibration) 분석에서 Expected Calibration Error(ECE)는 모든 설정에서 representational entanglement가 더 낮았으며, TOFU-World Facts에서 edit distance의 ECE는 모든 모델에서 0.4를 넘는 반면 representational entanglement는 0.25 미만을 유지했다. Maximum Calibration Error(MCE)에서도 다수 조합에서 우세했으나, **OLMo2**의 Real Authors(0.330 대 0.436)와 CounterFact(0.250 대 0.263)에서는 edit distance가 더 나은 부분적 예외가 관찰되었다.

### Q2: editing·unlearning의 토크나이제이션 불변성

bypass rate는 갱신을 회피하고 pre-update 응답을 복원한 noncanonical tokenization의 비율로, $K=30$개 토크나이제이션에 대해 측정한다. 토크나이제이션 불변 갱신이라면 bypass rate가 0이어야 한다. 결과적으로 bypass rate는 **19%~57% 범위, 평균 38.6%**로, 어떤 기법도 토크나이제이션 불변 갱신을 달성하지 못했다. 가장 견고한 AlphaEdit조차 상당 비율의 noncanonical tokenization이 pre-update 응답을 복원하도록 남겨두었고, LTU가 가장 취약해 모든 모델의 Real Authors와 World Facts에서 특히 높은 bypass rate를 보였다. **Llama3** + MEMIT + Real Authors 사례에서는 편집 전 noncanonical tokenization의 70.1%가 구 정답을 복원했고, 편집 후 이 값이 43.8%로 떨어졌을 뿐이며 29.7%가 신 정답, 26.5%가 둘 다 아닌 응답(Others)을 산출했다. entanglement 히스토그램에서 구 정답 토크나이제이션은 높은 유사도 쪽, 신 정답 토크나이제이션은 낮은 유사도 쪽에 몰려 Toketive가 활용하는 band 구조와 일치했다. 전체 분해 결과에서도 신 정답(New%)을 산출하는 noncanonical tokenization은 대부분 설정에서 소수에 불과하고, Others 비율은 대체로 LTU에서 가장 컸다.

### Q3: Toketive의 공격 효능

평가는 Efficacy Score 기준으로 편집이 성공한 인스턴스($P(\text{new fact}) > P(\text{old fact})$)로 제한한다. 탐지 베이스라인은 ① Random sampling(band 선택 없는 균일 무작위 noncanonical tokenization), ② Edit distance(필터링 신호를 정규화 Levenshtein 거리로 대체한 band 라우팅), ③ FUMA-gradient(post-edit model만으로 토큰 평균 손실의 전체 파라미터에 대한 기울기 L2 노름을 연속적 탐지 점수로 사용)이다. 복원 비교에서는 기울기 노름이 pre-edit 응답의 내용 정보를 주지 못하므로 앞의 두 베이스라인만 사용한다. 음성 샘플은 동일한 탐지기를 편집 모델과 해당 unedited base model에 각각 한 번씩 적용해 구성하므로, false positive는 noncanonical tokenization 자체의 내재적 변동성에서만 발생한다.

**탐지.** Toketive는 모든 모델·데이터셋에서 최고 F1을 달성해 평균 **84.2%**를 기록했으며, 이는 가장 강한 베이스라인 대비 26.2%의 상대적 향상이다. 두 번째는 Edit distance로 66.7%였다. Random sampling은 여러 설정에서 FPR이 0에 가깝고 정밀도가 완벽했으나 TPR이 매우 낮아, 균일 샘플링된 토크나이제이션이 detection band에 거의 들어가지 않음을 보였다. FUMA 기반 기울기 베이스라인은 거의 완벽한 TPR과 동시에 거의 완벽한 FPR을 보여 정밀도가 약 50%로 붕괴하고 평균 F1은 60.8%에 머물렀다. $\tau_{\text{det}} \to 1.0$에서 F1이 약 67%로 평탄해지는 구간은 모든 사실을 edited로 라벨링하는 퇴화 사례(TPR 100%, FPR 100%, 정밀도 약 50%)에 해당한다.

**pre-edit 응답 복원.** Toketive는 평균 top-1 정확도 60.9%, top-5 정확도 **74.5%**로 다른 베이스라인을 최소 21.7% 상회했다. Random sampling은 평균 top-1 30.7%, top-5 36.9%에 그쳐, band 필터링이 없는 bypass 연속부는 pre-update 객체로 집중되기에 너무 다양함을 보였다. Edit distance는 Random보다 개선되었고 일부 **OLMo2** 설정에서는 Toketive에 근접하거나 이를 넘었으나 대다수 조합에서 열세였으며, 격차는 MQuAKE와 CounterFact에서 가장 두드러졌다.

**정성적 예시.** AlphaEdit으로 편집된 **Llama3**에서 "The novel 1984 was written by" 프롬프트의 정규 토크나이제이션은 편집된 정답 _George R.R. Martin_ 을 산출했지만, 한 noncanonical tokenization은 pre-edit 정답 _George Orwell_ 을 복원했고, 다른 noncanonical tokenization은 편집된 동작에서 벗어났으나 _Michael Moorcock_ 이라는 틀린 응답을 내 복원에 실패했다.

### 비용 분석과 방어·ablation

사실당 지배적 비용은 $f_{\theta'}$를 통한 순전파 횟수다. 전체 비용은 $O(M(n_{\text{det}} + n_{\text{rec}}) \cdot F + (n_{\text{det}} + n_{\text{rec}}) \cdot G)$이며, $F$는 단일 순전파 비용, $G$는 출력 길이에 비례하고 일반적으로 $G \gg F$인 자기회귀 생성 비용이다. random 및 edit-distance 베이스라인은 은닉 상태 추출이 없어 $O((n_{\text{det}} + n_{\text{rec}}) \cdot G)$로 생성 비용이 지배한다.

방어 분석으로는 적응적 MEMIT을 평가했다. **Llama3**에서 representational entanglement가 0.9를 초과하는 1,000개 edit-control 사실 쌍을 사용해, 각 편집 반복 후 Toketive로 발견한 bypass 토크나이제이션을 다음 unlearning 대상에 추가하는 절차를 최대 4회 반복했다. bypass rate는 표준 MEMIT의 0.32에서 2회 반복 후 0.14, 3회 0.09, 4회 0.04로 감소했으나, ripple effect는 $1.0\times$에서 각각 $3.3\times$, $6.7\times$, $8.6\times$로 증가했다. 즉 bypass rate를 0.32에서 0.04로 낮추려면 표준 MEMIT 대비 $8.6\times$의 ripple effect 증가가 필요하며, 이는 토크나이제이션 견고성과 갱신 locality 사이의 트레이드오프를 드러낸다. 비교 대상으로 평가한 vanilla fine-tuning(전체 파라미터, SGD momentum 0, 학습률 $5 \times 10^{-5}$, 최대 25 스텝, 조기 종료 손실 $5 \times 10^{-2}$, 배치 1, fp32)은 bypass rate를 0.08까지 낮췄지만 MEMIT 대비 $5.2\times$ 큰 ripple effect를 발생시켜, 국소적 수정을 목표로 하는 편집·unlearning에는 덜 적합함을 보였다.

## 고찰

### 방법론

이 연구는 오픈 웨이트(open-weight) LLM이 공개된 뒤에는 개발자가 추론 스택을 더 이상 통제할 수 없다는 점에서 출발해, 모델 편집(model editing)과 기계 언러닝(machine unlearning)의 사후 보증을 토크나이제이션(tokenization) 수준에서 다시 검토한다. 지식은 주체(subject) $s$, 관계(relation) $r$, 객체(object) $o$로 구성된 삼항 $(s, r, o)$로 표현되고, 프롬프트 $p(s,r)$가 주어지면 자기회귀 모델 $f_\theta$가 후속 토큰 분포를 예측한다. 편집은 요청 $e = (s, r, o, o^{*})$에 대해 $f_{\theta'} = E(f_\theta, e)$를 만들어 reliability, generalization, locality를 달성하려 하고, 언러닝은 forget set $D_f$에 대해 $f_{\theta'} = U(f_\theta, D_f)$를 만들어 efficacy, utility, privacy를 목표로 한다. 두 기법은 모두 causal tracing으로 대상 사실을 저장한 feed-forward MLP 층과 subject 토큰 위치를 찾고 그 부분만 갱신하는 locate-then-edit(또는 unlearn) 패러다임을 공유한다.

핵심 관찰은 비정규 토크나이제이션(noncanonical tokenization)에 있다. 어휘 $V$에 대해 문자열 $x$의 토크나이제이션은 $v_1 \oplus v_2 \oplus \cdots \oplus v_m = x$를 만족하는 토큰열이며, 실제 파이프라인은 병합 규칙을 탐욕적으로 적용해 유일한 정규 토크나이제이션 $v^{*} = k^{*}(x)$만 사용한다. 그러나 전체 집합 $T_V(x) = \{v : v \text{는 } x \text{의 유효한 토크나이제이션}\}$의 크기는 $|x|$에 따라 지수적으로 커지고, 같은 문자열이라도 다른 토큰열은 서로 다른 내부 계산 경로를 유도한다. 저자들은 이를 side channel로 규정하고, 정규 경로만 패치된 편집·언러닝이 미패치 경로에 남은 잔여 사실 연합을 통해 누출될 수 있다고 본다.

라우팅 신호로는 표현 얽힘(representational entanglement)을 사용한다. 은닉 표현은 $h^{(l)}_i = h^{(l-1)}_i + a^{(l)}_i + m^{(l)}_i$로 갱신되며, 프로브 층 $L$에서의 얽힘은 코사인 유사도 $S(i,j) = \cos(h^{(L)}_i, h^{(L)}_j)$로 정의된다. 원래 ripple effect 예측을 위해 제안된 이 지표를, 저자들은 단일 프롬프트의 토크나이제이션 공간 안에서 우회 가능성을 예측하는 신호로 전용한다. 프로브 층은 선행 연구를 따라 $L = \lfloor \text{depth}/3 \rfloor$로 두고, 토크나이제이션마다 subject 구간을 재식별해 subject 최종 토큰의 은닉 상태를 뽑는다.

공격 기법 Toketive는 공개된 사후 모델 $f_{\theta'}$와 프롬프트만 입력받아 탐지 라벨 $\ell \in \{\text{edited}, \text{unedited}\}$와, edited인 경우 복원된 편집 전 응답 $\hat{o}$를 출력한다. 먼저 정규 토크나이제이션으로 한 번 순전파해 사후 응답 $o^{*}$와 기준 벡터 $h^{*}$를 기록한다. 이어 공격성 파라미터 $\alpha \in [0,1]$(초기값 0.5)로 문자열 분할의 세분도를 조절하는 적응적 토크나이제이션 샘플러가 후보를 생성한다. $\alpha$는 최근 10개 샘플의 이동 평균 유사도를 입력으로 하는 비례 제어기(proportional controller)로 조정되며, 목표 대역에 들어오면 작은 난수 교란을 주어 정체를 피한다. 후보 $u$는 연결 결과가 원문과 정확히 일치할 때만, 그리고 토크나이저 왕복 조건 $\tau^{-1}(\tau(c)) = c$를 만족할 때만 채택되어 byte-level 토큰, 선행 공백, 유니코드 경계가 자동으로 처리된다. 각 후보는 $S(u, v^{*})$에 따라 탐지 대역 $[\beta^{\text{det}}_l, \beta^{\text{det}}_h) = [0.3, 0.5)$, 복원 대역 $[\beta^{\text{rec}}_l, \beta^{\text{rec}}_h) = [0.7, 1.0)$, 또는 폐기로 라우팅된다.

Phase ①에서는 $n_{\text{det}}$개의 탐지 대역 후보 $C_{\text{det}}$에 대해 정규 응답 우회율

$$\nabla = \frac{1}{|C_{\text{det}}|} \sum_{u \in C_{\text{det}}} \mathbf{1}[o^{*} \in \hat{y}_u]$$

를 계산하고, $\nabla < \tau_{\text{det}}$이면 edited로 판정한다. Phase ②에서는 복원 대역 후보 중 $C_{\text{byp}} = \{u \in C_{\text{rec}} : o^{*} \notin \hat{y}_u\}$만 남기고, 생성물에서 객체 구간 $c_u = \hat{y}_u[|p(s,r)|:]$를 추출해 다수결 $\hat{o} = \arg\max_c \sum_{u \in C_{\text{byp}}} \mathbf{1}[c_u = c]$로 편집 전 응답을 복원한다. 탐색은 전수 열거가 아니라 샘플당 최대 시도 $M = 300$, 할당량 $n_{\text{det}} = 20$, $n_{\text{rec}} = 50$의 예산 기반이며, 비용은 $O(M(n_{\text{det}} + n_{\text{rec}}) \cdot F + (n_{\text{det}} + n_{\text{rec}}) \cdot G)$로 순전파 비용 $F$와 생성 비용 $G$에 묶인다. 하이퍼파라미터는 Llama3·MEMIT·Known-1000 한 설정에서 한 번 보정해 $\tau_{\text{det}} = 0.10$으로 고정하고, 나머지 179개 실험에 재조정 없이 적용했다.

### 실험

실험은 NVIDIA H200 GPU(각 141GB) 클러스터에서 수행되며, 세 가지 연구 질문 — 예측 가능성(_Q1_), 토크나이제이션 불변성(_Q2_), 적대적 효용(_Q3_) — 을 다룬다. 모델은 **Llama3**(8B, Instruct), **Llama3.1**(8B, Instruct), **OLMo2**(13B, Instruct), **Tulu3**(8B), **Tulu3.1**(8B)의 다섯 가지이고, 기법은 AlphaEdit, RECT, MEMIT, PRUNE, CoME, Locate-then-Unlearn(LTU)의 여섯 가지다. 데이터셋은 CounterFact, RippleEdits, MQuAKE, Known-1000, TOFU – World Facts, TOFU – Real Authors이며, CounterFact는 앞 1000개 샘플, MQuAKE와 RippleEdits는 각각 1000개 삼항을 프롬프트 템플릿과 함께 추출하고, TOFU는 Q&A를 프롬프트 형식으로 변환했다. 정규 토크나이제이션이 정답을 내는 사례로만 평가를 제한하고, 샘플링 잡음을 제거하기 위해 모든 출력은 결정적 greedy decoding으로 생성한다.

_Q1_에서는 프롬프트마다 30개의 무작위 비정규 토크나이제이션을 만들고, 편집 전 객체 $o$가 생성문에 등장하면 수렴(convergence)으로 정의해 AUC와 rank-biserial 상관 $|rb|$로 예측력을 측정했다. 표현 얽힘은 AUC 0.684–0.850, $|rb|$ 0.368–0.699를 보였고, 어휘적 기준선인 edit distance는 AUC 0.526–0.674, $|rb|$ 0.052–0.348에 머물렀다. 표현 얽힘의 최악값(AUC 0.684)이 edit distance의 최고값(0.674)을 넘어, 두 신호 사이에 일관된 분리가 있음을 보인다. 격차는 RippleEdits에서 가장 크며, 이곳에서 edit distance는 모든 모델에서 무작위 수준에 근접한다. 평균 점수 분석에서도 수렴 토크나이제이션의 얽힘이 비수렴 대비 0.124–0.278 높아 30개 모델–데이터셋 조합 모두에서 부호가 일관됐고, edit distance의 차이는 $-0.011$에서 $-0.094$로 작고 방향이 반대였다. 보정 분석에서 ECE는 모든 설정에서 표현 얽힘이 우수했고, MCE는 **OLMo2**의 Real Authors(0.330 대 0.436)와 CounterFact(0.250 대 0.263)에서만 edit distance가 앞섰다.

_Q2_에서는 동일한 샘플에 대해 $K = 30$개 비정규 토크나이제이션의 우회율을 측정했다. 우회율은 19%에서 57%까지 분포하며 평균 38.6%로, 어떤 기법도 토크나이제이션 불변 갱신을 달성하지 못했다. AlphaEdit이 상대적으로 가장 견고했으나 여전히 상당 비율이 편집 전 응답을 회복했고, LTU는 Real Authors와 World Facts에서 모든 모델에 걸쳐 가장 취약했다. **Llama3**에 MEMIT을 적용한 Real Authors 사례에서는 편집 전 70.1%였던 구답 비율이 편집 후 43.8%로 줄었을 뿐이며, 신답 29.7%, 그 외 26.5%로 재분포했다. 얽힘 히스토그램에서 구답 토크나이제이션은 높은 유사도에, 신답 토크나이제이션은 낮은 유사도에 몰려 Toketive가 활용하는 대역 구조와 일치했다.

_Q3_에서는 Efficacy Score 기준으로 편집이 성공한 사례($P(\text{new fact}) > P(\text{old fact})$)에 한정해 평가했고, 음성 표본은 동일한 탐지기를 미편집 기본 모델에 적용해 구성함으로써 오탐이 비정규 토크나이제이션의 내재적 변동에서만 발생하도록 했다. 탐지 성능에서 Toketive는 평균 F1 84.2%로 모든 모델·데이터셋에서 최고였고, 두 번째인 edit distance는 66.7%였다. Random sampling은 FPR이 거의 0이고 정밀도가 완벽한 설정이 많았지만 TPR이 매우 낮았고, FUMA에서 착안한 gradient 기준선은 TPR과 FPR이 동시에 1에 가까워 정밀도가 약 50%로 붕괴하며 평균 F1 60.8%에 그쳤다. 복원에서는 top-1 60.9%, top-5 74.5%로 최고 기준선보다 21.7% 높았고, random sampling은 top-1 30.7%, top-5 36.9%에 머물러 구조 없는 탐색이 편집 전 객체로 집중되지 못함을 보였다. 질적 예시에서는 AlphaEdit으로 편집된 **Llama3**가 정규 토크나이제이션에서는 편집된 답을 내지만, 한 비정규 토크나이제이션은 편집 전 답을 회복하고, 다른 비정규 토크나이제이션은 둘 모두와 다른 오답을 내는 세 양상이 함께 관찰된다.

### 한계와 논의

저자들이 제시한 방어 방향은 토크나이제이션 견고 갱신이다. 부록 A의 adaptive MEMIT은 각 반복에서 Toketive로 우회 토크나이제이션을 찾아 다음 언러닝 대상에 추가하는데, 우회율은 MEMIT의 0.32에서 2회 0.14, 3회 0.09, 4회 0.04로 떨어진다. 그러나 ripple effect는 $1.0\times$에서 $3.3\times$, $6.7\times$, $8.6\times$로 증가해, 견고성과 locality 사이의 트레이드오프가 드러난다. 본 연구 범위에서 제외된 fine-tuning 역시 우회율을 0.08로 낮추지만 ripple effect가 MEMIT의 $5.2\times$에 달해, 표적 지식 수정의 목적 자체를 훼손한다. 유효한 토크나이제이션 공간이 입력 길이에 따라 커지므로 반복 편집으로 이 공간을 덮는 전략은 확장성이 떨어지며, 토크나이제이션에 무관한 표현을 학습하는 구조적·표현적 접근이 더 원리적일 수 있으나 subword 토크나이제이션과 모델 내부의 상호작용을 재검토해야 한다는 점에서 열린 문제로 남는다.

방법론 자체의 한계도 명시된다. 표현 얽힘의 형식적 특성화는 미해결 문제이며, 저자들은 목적이 기계론적이 아니라 알고리즘적이라고 선을 그어 지식 저장의 인과 이론에 대한 근거로 쓰지 않는다. 탐색은 전수 열거가 아닌 예산 제한 적응 샘플링이라 대역 경계는 보장이 아니라 목표이며, 예산이 소진되면 대역 밖 후보를 목표 대역과의 거리 순으로 채워 표본 크기를 맞추고 그조차 부족하면 $n$보다 적은 표본을 반환한다. 범위는 locate-then-edit 계열의 비정확(inexact) 편집·언러닝에 한정되고, 평가 대상은 모두 공개 모델과 공개 벤치마크로 민감한 실제 데이터는 쓰이지 않았다. 윤리 측면에서 저자들은 위협 모델을 공개 모델에 대한 대체 토크나이제이션 질의로 한정하고, 대규모 악용을 위한 배포용 도구가 아니라 구조적 취약점 노출과 평가 프로토콜 개선에 기여하는 것을 목표로 밝힌다.

## 결론

Toketive는 토크나이제이션을 양호한 전처리 단계가 아니라 side channel로 취급함으로써, 현재의 편집·언러닝 기법이 같은 문자열의 대체 표현으로는 일반화되지 않는 표면적 갱신을 만든다는 사실을 드러낸다. 다섯 모델, 여섯 데이터셋, 여섯 기법에 걸쳐 평균 우회율 38.6%가 관측되어, 억제되었다고 간주된 지식이 토크나이제이션을 인지한 공격자에게 널리 접근 가능한 상태로 남는다. Toketive는 원본 모델, shadow model, 보조 분류기에 대한 접근 없이 편집 탐지와 편집 전 응답 복원을 하나의 탐색 절차로 통합하며, F1 84.2%와 top-5 복원 정확도 74.5%로 최강 기준선을 각각 26.2%, 21.6% 상회한다. 결론적으로 국소적 수정은 적대적 표현 공간에 대한 평가 없이는 견고한 지식 통제 경계로 취급되어서는 안 되며, 정규 토크나이제이션 기반 평가와 공개 후 보안 보증 사이의 간극을 메우는 것이 과제로 남는다.

This paper supports reproducibility while accounting for
safety and responsible disclosure concerns.
**Artifacts.** We provide an anonymous artifact repository containing: (i) the source code for Toketive, (ii) scripts and
configuration files for all experiments (RQ-1, RQ-2, and RQ3), (iii) documentation describing the experimental workflow
and environment.
**Access** **During** **Review.** All artifacts are hosted in an anonymous repository accessible to the program committee during
double-blind review. The repository contains no identifying
information and is available at: [https://anonymous.4open.scie](https://anonymous.4open.science/r/Toketive)
[nce/r/Toketive.](https://anonymous.4open.science/r/Toketive)
**Reproducibility.** All core claims in the paper can be independently evaluated using the provided artifacts. To support
reproducibility, we provide code, detailed documentation and
dataset information.
**Models** **and** **Datasets.** All five models evaluated in this
work are publicly available open-weight models accessible via
HuggingFace. All datasets are publicly available benchmarks.
