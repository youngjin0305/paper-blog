# A Novel Approach to Construct a Good Dataset for Differential-Neural Cryptanalysis

[원문](https://ieeexplore.ieee.org/document/10510376/) · [PDF](https://xplorestaging.ieee.org/ielx7/8858/10843954/10510376.pdf?arnumber=10510376)

## 한눈에 보기

differential-neural cryptanalysis에서 neural distinguisher 학습의 출발점인 differential dataset의 품질을 PCA와 K-means clustering으로 사전 평가해 좋은 input difference를 찾는 탐색 알고리즘을 제안한 연구다. SPECK과 SIMON에 적용해 유효한 input difference를 찾아냈고, Gohr의 neural input difference 탐색 알고리즘보다 높은 정확도와 약 30% 짧은 실행 시간을 보였다.

## 초록

최근 딥러닝과 differential cryptanalysis를 결합한 differential-neural cryptanalysis가 강력하고 실용적인 암호분석 방법으로 주목받고 있다. 이 접근법은 전통적으로 상당한 시간과 전문성을 요구했던 암호학적 성질 분석을 딥러닝이 수행하게 해 준다는 장점이 있다. 그러나 딥러닝 모델의 black-box 특성 때문에 암호분석자가 differential dataset의 구성 방식을 이해하기 어렵다. 특히 differential dataset은 neural distinguisher를 만들어내는 토대가 되므로, 고품질 differential dataset을 구성하는 효과적인 방법론이 시급히 필요하다. 이 논문에서는 differential-neural cryptanalysis를 위한 좋은 differential dataset을 구성하는 새로운 접근법을 제안한다. 먼저 Principal Component Analysis(PCA)와 K-means clustering을 사용해 학습이 잘 되는(well-trainable) differential dataset과 그 밖의 differential dataset의 차이를 찾는 분석을 수행하였다. 이 분석 결과를 바탕으로, well-trainable differential dataset을 생성하기 위한 탐색(exploring) 알고리즘을 제안하였다. 제안 알고리즘은 유의한 principal component를 식별하는 방식으로 differential dataset 내의 input difference를 평가한다. 그러한 성분이 발견되면 해당 differential dataset에 대해 cluster 평가를 수행한다. 실험에서 제안 알고리즘은 유리한 input difference를 성공적으로 식별하였고, 이는 SPECK과 SIMON에 대한 neural distinguisher 학습의 정확도 향상으로 이어졌다. 기존 Gohr의 neural input difference 알고리즘의 성능과 비교하여, 제안 알고리즘은 더 높은 정확도의 좋은 input difference를 찾는 데 더 효과적이었다. 실행 시간 관점에서는 약 30%의 개선을 보였다.

## 필요성

높은 정확도의 neural distinguisher를 구성하려면 deep learning pipeline 전체를 깊이 고려해야 한다. 이 pipeline은 dataset generation, model design and training, evaluation의 세 단계로 이루어지는데, 기존 연구 대부분은 모델 설계·학습·평가에 집중했다. 그러나 dataset generation은 pipeline의 출발점이며 모델 성능에 큰 영향을 주므로, 고품질 학습 데이터셋(논문에서는 neural distinguisher의 학습 데이터셋을 differential dataset이라 지칭)을 생성하는 방법론이 필요하다.

Gohr는 differential dataset 생성을 위한 두 가지 방법을 제시했다. 첫째는 differential cryptanalysis를 통해 이미 알려진 높은 확률의 differential characteristic에서 input difference를 가져오는 방법이고, 둘째는 무작위로 선택한 input difference 기반 differential dataset으로 neural distinguisher를 소규모 학습시켜 input difference를 탐색하는 neural difference search 알고리즘이다. 전자는 전통적인 differential cryptanalysis를 요구하고, 후자는 많은 neural distinguisher 학습 과정을 요구한다는 결정적인 한계가 있다. 또한 모든 differential dataset이 높은 정확도의 학습 결과를 내는 것은 아니지만, differential-neural cryptanalysis의 효율성과 효과를 높이는 differential dataset 생성에 대한 충분한 논의는 아직 이루어지지 않았다.

## 연구 분야 흐름

암호 분야에서 지난 수십 년간 machine learning을 암호분석에 사용한 결과들이 있었으나 대부분은 side-channel attacks(SCA)에 집중되어 있었다 [4], [5], [6]. 최근에는 ciphertext에 대응하는 plaintext를 예측하거나 [7], ciphertext를 구별하거나 secret key를 복구하려는 시도가 등장했다 [8], [9]. 특히 CRYPTO'19에서 A. Gohr [8]는 neural distinguisher 개념을 제안했다. 이는 전통적인 differential cryptanalysis로 높은 확률이 알려진 differential characteristic을 갖는 plaintext pair를 암호화해 만든 real ciphertext pair와, 무작위 plaintext pair를 암호화해 만든 random ciphertext pair를 구별하도록 학습시킨 딥러닝 모델이다. neural distinguisher의 정확도는 전통적인 differential distinguisher를 능가했고, key recovery attack도 성공적으로 수행되어 11-round SPECK-32/64의 subkey를 복구했다. 이처럼 암호분석자가 많은 시간과 노력을 들여야 하는 대상 암호의 특성 분석을 학습 과정이 대신하므로, 이 접근은 differential-neural cryptanalysis라 불리며 강력하고 실용적인 기법으로 주목받고 있다.

이후 neural distinguisher의 성능 개선 [9], [10], [11], [12], [13], [14], 다양한 block cipher로의 적용 [15], [16], [17], key recovery attack 개선 [18]에 관한 연구가 활발히 진행되었다.

## 관련 연구

EUROCRYPT'21에서 Benamira et al. [9]는 neural distinguisher가 학습한 특성에 대한 실험적 해석과 성능 개선을 제시했다. 그 결과 Gohr의 neural distinguisher가 학습한 특성이 SPECK-32/64의 truncated differential characteristic으로 해석될 수 있음을 보였고, 단일 key로 ciphertext를 batch 처리함으로써 정확도를 개선할 수 있음을 보였다. 이들은 (0x0040, 0x0000) 데이터셋에서 좋은 결과를 낸 ciphertext의 0과 1의 bias를 조사해 5-round SPECK-32/64에 대한 truncated differential characteristic $(10*****00*****10, 11*****01*****00)_2$ 를 도출했으며, 본 논문의 eigenvector 해석 방법론도 이 분석 방식에서 착안했다.

ASIACRYPT'22에서 Bao et al. [18]은 key recovery attack에서 neural distinguisher 앞단에 붙는 구조를 개선해 공격을 13 라운드까지 확장했다.

[11]에서는 input difference 설정을 위한 differential characteristic 탐색에 SAT/SMT solver를 사용했다. 이러한 최적화 기법은 수작업 탐색에 비해 시간과 노력을 줄이지만, 최적화 문제로 변환하는 과정에서 대상 암호에 대한 전문적인 암호학 지식이 여전히 필요하다는 한계가 남는다.

Gohr는 사람의 노력이 필요하다는 한계를 해결하기 위해 *GreedyOptimizerWithExplorationBias*라는 알고리즘을 제시했다. 이 알고리즘은 input difference를 무작위로 선택해 데이터셋을 만들고 neural distinguisher를 소규모 학습시켜 좋은 정확도를 보이는 input difference를 선택한다. 본 논문은 이를 편의상 neural input difference exploration(NIDE)이라 부른다.

## 배경 지식

### neural distinguisher

neural distinguisher는 입력 데이터가 학습된 class에 해당하는지를 구별하며, 입력이 어느 class에 속하는지의 분류에 기반한 likelihood를 반환한다. 이 분류 문제는 random과 real ciphertext의 두 class로 구성된 binary classification [20]으로 정의된다. random ciphertext는 대응하는 plaintext 사이에 아무 관계가 없는 경우이고, real ciphertext는 대응하는 plaintext 사이에 특정 difference가 존재하는 경우다. neural distinguisher를 ciphertext pair가 주어졌을 때 $y$ 를 추측하는 분류기 $g(x): X \rightarrow 0,1$ 로 두고 분류 오류 확률을 $\mathbf{P}$ 로 두면, 문제는 다음과 같이 정의된다.

$$\arg\min_{g: X \rightarrow \{0,1\}} \mathbf{P}[g(x) = y].$$

neural distinguisher의 구조는 residual neural network(ResNet) [21]에 기반하며 initial layer, residual blocks, prediction head의 세 부분으로 나뉜다. initial layer에서는 입력 ciphertext pair가 word 단위로 배열되고 각 bit가 입력 노드로 들어가 모델이 ciphertext word의 각 bit 특성을 학습하게 한다. 이어 residual blocks가 ciphertext pair의 학습을 처리하고, 이를 기반으로 prediction head가 분류를 수행한다. SPECK-32/64에 대해 이 구성을 학습시키면 5/6/7/8-round에서 전통적인 differential distinguisher보다 더 나은 분류 정확도를 얻었다.

### differential dataset 생성 방식

plaintext pair를 $(P, P')$, ciphertext pair를 $(C, C') \in X$, label을 $y \in \{0,1\}$ (0: random, 1: real), 암호화 함수를 $E(pt,k)$ 로 둔다. label이 1이면 plaintext pair는 $P' = P \oplus \Delta$ 를 만족한다. 그리고 ciphertext pair는 label에 따라 random key $k$ 로 plaintext pair를 암호화해 생성된다.

$$(C, C') = \begin{cases} (E(P,k), E(P',k)), & \text{if } label = 0, \\ (E(P_0,k), E(P' \oplus \Delta), k), & \text{if } label = 1.\end{cases}$$

real case 데이터 생성에 사용된 input difference $\Delta$ 는 (0x0040, 0x0000)으로, [25]에서 제시된 differential characteristic의 일부다. 이는 낮은 hamming weight를 가지며 (0x0040/0000)에서 (0x8000/8000)으로 가는 결정적(deterministic) 1-round SPECK-32/64 transition을 갖는다. 즉 Gohr는 differential dataset 생성 시 hamming weight와 input difference의 transition을 핵심 요소로 고려했다. 낮은 hamming weight는 비선형 연산으로 인한 1-bit difference의 발생을 줄일 수 있고, 분석에 유리한 형태로 전파되는 transition은 더 높은 확률로 더 많은 라운드를 분석할 수 있게 하므로 이는 differential cryptanalysis 관점에서 합리적이다.

### PCA

PCA [22]는 손실을 최소화하면서 차원 수를 줄이는 주요 방법 중 하나다. 데이터를 가장 잘 표현하는 축을 찾고 그 축으로 데이터를 투영해 가장 중요한 정보를 추출한다. 먼저 원 데이터의 분산을 최대화하는 새로운 축을 찾기 위해 주어진 데이터 행렬 $A$ 에 대한 covariance matrix를 계산해야 한다. 각 변수의 평균이 0이면 covariance matrix는 다음과 같이 얻어진다.

$$cov(A) = \frac{1}{n-1}AA^T \propto AA^T.$$

이후 eigen decomposition을 수행해 새로운 축을 찾으며, $A \cdot x = \lambda x$ 를 만족하는 eigenvalue $\lambda$ 와 eigenvector $x$ 를 얻는다.

$$AA^T = U \Lambda U^T.$$

여기서 $U$ 의 열벡터는 covariance matrix $AA^T$ 의 eigenvector로, 데이터가 분산된 방향을 나타내며 데이터의 주축 후보가 된다. $\Lambda$ 는 대각 성분 외 모두 0인 diagonal matrix이고 각 대각 성분은 계산된 covariance matrix의 eigenvalue다. eigenvalue는 eigenvector 방향으로의 데이터 분산 크기, 즉 원 데이터가 그 방향으로 얼마나 퍼져 있는지를 나타낸다. eigenvalue를 내림차순으로 정렬하면 중요도 순으로 성분을 얻을 수 있고, 가장 큰 eigenvalue를 갖는 eigenvector가 데이터셋의 가장 중요한 성분이 된다. 연산 과정에서 보듯 PCA는 모든 basis vector를 orthonormal matrix로 가정하는 orthogonal linear transformation으로 볼 수 있다.

### K-means clustering

K-Means clustering [23]은 공통 특성에 기반해 데이터 객체를 $k$ 개의 cluster로 묶는 unsupervised 기계학습 알고리즘이다. 목표는 각 cluster 내 유사도를 최대화하는 것, 즉 centroid와 cluster 내 객체 사이 거리를 최소화하는 것이다. 대상 객체를 $x$, cluster $C_i$ 의 centroid를 $x_i$ 라 할 때 criterion function은 다음과 같다.

$$E = \sum_{i=1}^{k} \sum_{x \in C_i} (|x - x_i|)^2.$$

알고리즘은 두 단계로 진행된다. 첫 단계에서 주어진 $k$ 에 대해 $k$ 개의 centroid를 무작위로 선택하고, 두 번째 단계에서 각 데이터 점을 Euclidean distance로 계산한 가장 가까운 centroid에 할당한다.

$$d(x_i, y_i) = \left(\sum_{i=1}^{n}(x_i - y_i)^2\right)^{1/2}.$$

모든 데이터 객체가 cluster로 묶이면 centroid를 재계산하고, Euclidean distance를 다시 계산해 데이터 객체를 가장 가까운 centroid로 재할당한다. 이 과정은 각 cluster에서 모든 객체로부터 centroid까지의 거리 합이 최소가 될 때까지, 즉 목적 함수 $E$ 가 최소화될 때까지 반복된다.

cluster 밀도 평가에는 silhouette score [27]를 사용한다. silhouette score는 cluster의 평균 거리를 계산해 *inner cluster distance*(cluster 내 데이터 점 간 평균 거리)와 *inter cluster distance*(cluster 간 평균 거리)를 구한다.

### SPECK과 SIMON

SPECK과 SIMON은 2013년 National Security Agency(NSA)가 개발한 ARX 기반 경량 block cipher 계열이다 [24]. 두 암호 모두 block size $2n$ 과 key size $mn$ 에 따라 다양한 instance를 가지며 SPECK-$2n/mn$, SIMON-$2n/mn$ 으로 표기한다. 여기서 $n$ 은 word size, $m$ 은 key word의 개수다. 두 암호는 ARX(Addition, Rotation, and XOR) 설계 전략에 기반하지만 구조와 연산 과정이 다르다. ARX 연산 표기는 다음과 같다. $\boxplus$: modulo $2^n$ modular addition, $\lll j, \ggg j$: 각각 $j$-bit 좌·우 rotation, $\oplus$: bitwise XOR, &: bitwise AND.

SPECK은 소프트웨어에 특화되도록 설계되었고 Threefish 암호의 mixing function 구조를 갖는다. 입력 메시지 $X$ 를 두 개의 $n$-bit word $X = (L, R)$ 로 표현하면 SPECK의 $i$ 번째 round function은 다음과 같다.

$$f(K_i, L_i, R_i) = ((\ggg\alpha(L_i) \boxplus R_i) \oplus K_i, \lll\beta(R_i) \oplus (\ggg\alpha(L_i) \boxplus R_i) \oplus K_i).$$

key $K$ 가 $(l_{m-2}, \ldots, l_0, k_0)$ 일 때 key schedule function은 두 개의 word 수열 $k_i$ 와 $l_i$ 를 다음과 같이 생성한다.

$$l_{i+m-1} = (k_i \boxplus \ggg\alpha(l_i)) \oplus i, \quad k_{i+1} = \lll\beta(k_i) \oplus l_{i+m-1}.$$

$i \geq 0$ 에 대해 $k_i$ 값이 $i$ 번째 round key로 사용된다. round function과 key schedule function에서 $n = 16$ 이면 $\alpha = 7, \beta = 2$ 이고, 그렇지 않으면 $\alpha = 8, \beta = 3$ 이다.

SIMON은 하드웨어에 특화되도록 설계되었고 Feistel 구조를 갖는다. 입력 메시지를 $X = (L, R)$ 로 표현하면 $i$ 번째 round function은 다음과 같다.

$$f(K_i, L_i, R_i) = (g(L_i \oplus R_i \oplus K_i, R_i), \text{ where } g(x) = \lll1(x) \& \lll8(x)) \oplus \lll2(x).$$

key $K$ 가 $(k_0, \ldots, k_{m-1})$ 일 때 key schedule function은 $m$ 에 따라 round key $k_0, k_1, k_2, \ldots$ 를 생성하며, $m = 2, 3, 4$ 각각에 대해 다음과 같다.

$$k_{i+2} = k_i \oplus (I \oplus \ggg1)(\ggg3(k_{i+1})) \oplus C_i,$$
$$k_{i+3} = k_i \oplus (I \oplus \ggg1)(\ggg3(k_{i+2})) \oplus D_i,$$
$$k_{i+4} = k_i \oplus (I \oplus \ggg1)(\ggg3(k_{i+3}) \oplus k_{i+1}) \oplus E_i,$$

여기서 $C_i$, $D_i$, $E_i$ 는 round 의존 상수의 $i$ 번째 bit다(상세 값은 [24] 참조).

### eigenvalue ratio

분석에는 Python sklearn.decomposition의 PCA 라이브러리를 사용했다. 이 라이브러리는 principal component 계산을 eigenvalue decomposition이 아니라 Singular Value Decomposition(SVD) [26]으로 수행한다. 수학적으로 SVD와 eigenvalue decomposition은 같은 결과를 주지만 SVD가 계산상 더 효율적이어서 sklearn이 이를 채택한다. 계산 방식 차이로 라이브러리는 정확한 eigenvalue를 eigenvalue matrix로 제공하지 않고, explained_variance_ratio를 통해 eigenvalue의 추정 비율을 제공한다. $i$ 번째 eigenvalue를 $\lambda_i \in \Lambda$ 로 두면 explained_variance_ratio는 $\lambda_i / \Sigma_{\lambda \in \Lambda}\lambda$ 이며, 본 논문은 이를 편의상 *eigenvalue ratio* $\rho$ 라 부른다.

데이터를 유의하게 표현하는 eigenvector가 전혀 없다면, eigenvalue decomposition으로 찾은 어떤 방향도 데이터 분산을 유의하게 설명하지 못한다는 뜻이며 모든 방향의 설명 정도가 비슷하다는 의미다. 즉 $\lambda_i = \lambda_j$ ($\lambda_i, \lambda_j \in \Lambda$, $i \neq j$)이다. 데이터셋의 차원이 $n$ 이면 찾을 수 있는 방향의 수도 $n$ 이므로 $i$ 번째 eigenvalue ratio는

$$\rho_i = \frac{\lambda_i}{\Sigma_{\lambda \in \Lambda}\lambda} = \frac{\lambda_i}{n\lambda_i} = \frac{1}{n}$$

이 된다. 따라서 유의한 방향의 eigenvalue ratio는 다른 방향보다 큰 $\lambda$ 를 가지므로 $1/n$ 보다 커야 한다. ciphertext pair로 구성된 differential dataset의 차원 수는 (2 × block size)이므로 block size 32의 SPECK에서는 64차원이고, 유의한 방향의 eigenvalue ratio는 $1/64 = 0.015625$ 보다 커야 한다. 이 값을 $\lambda_{base}$ 로 표기한다.

## 문제 정의

NIDE 알고리즘의 구현은 저자의 GitHub 저장소에서 확인할 수 있다. Gohr의 구현에서 $F$ 함수로 학습되는 distinguisher는 Ridge classifier이며, 무작위 input difference로 사전 학습된 neural distinguisher의 중간 출력값을 학습하도록 구성된다. 이는 few-shot learning에 기반한 설계로, 다양한 input difference를 빠르게 학습·탐색할 수 있게 한다. 본 논문은 효과를 평가하기 위해 Gohr가 설정한 것과 동일한 파라미터($F$: preprocessed neural distinguisher가 결합된 Ridge, $t$: 2000, $\alpha$: 0.01, $b$: 32)로 NIDE를 실제 실행했으며, 실행 환경은 Intel Xeon Gold 6230R CPU @ 2.10 GHz와 NVIDIA GeForce RTX 3090이었다. 5-round SPECK-32/64에 대해 100회 실행한 결과 모든 실행에서 약 50–55%의 정확도를 보이는 input difference를 찾았고 평균 실행 시간은 약 200초였다. 그러나 input difference (0x0040, 0x0000)을 사용한 neural distinguisher가 달성한 약 93% 정확도와 비교하면 NIDE가 발견한 input difference는 유의하지 않았다.

이 실험에서 두 가지 주요 한계가 확인되었다. 첫째는 input difference를 완전히 무작위로 선택한다는 점이다. 낮은 Hamming weight가 differential cryptanalysis의 differential probability 관점에서 유리할 수 있는데도 NIDE는 input difference를 완전 무작위로 설정하므로, 좋은 differential characteristic과 연관된 input difference를 찾을 확률이 낮아진다. 둘째는 distinguisher의 소규모 학습 결과에 기반해 input difference를 평가하는 것이 신뢰할 수 없다는 점이다. distinguisher의 학습이 충분히 완료되지 않았을 가능성 때문에 평가 결과가 신뢰할 수 없게 되지만, 이를 개선하기 위해 충분한 학습을 수행하는 것은 많은 input difference를 빠르게 탐색하려는 NIDE의 목표에 부합하지 않는다.

이 두 한계를 개선하려면 두 가지 전략이 필요하다. 첫째는 암호분석 관점에서 유리한 input difference를 우선 탐색하는 것으로, 낮은 hamming weight의 input difference를 탐색하는 방식으로 간단히 실현할 수 있다. 둘째는 딥러닝 모델에 기반하지 않은 다른 방법으로 input difference를 평가하는 것인데, 이를 위해서는 differential dataset에 내재한 특성을 식별·평가하는 방법이 필요하다. 이에 저자들은 one-bit differential dataset에 PCA와 K-means Clustering을 적용하면서 다음 두 질문의 답을 찾고자 했다.

- Q1. 좋은 differential dataset은 어떤 특성을 갖는가?
- Q2. 좋은 differential dataset을 식별하고 평가할 수 있는가?

저자들은 높은 정확도를 보이는 differential dataset이 다른 differential dataset보다 데이터를 더 잘 대표하는 어떤 패턴을 포함할 것이라고 가정했다. 이 가정에 따르면 PCA를 수행한 결과로 상대적으로 큰 eigenvalue를 갖는 eigenvector가 존재할 것으로, 즉 데이터를 효과적으로 대표할 수 있는 유의한 principal component가 존재할 것으로 기대된다.

## 주요 기여

- PCA와 K-means clustering 같은 기계학습 분야에서 흔히 쓰이는 데이터 분석 기법을 활용해 differential-neural cryptanalysis용 differential dataset을 생성하는 새로운 접근법을 제안했다. 이 접근법은 광범위한 암호학 전문 지식을 요구하지 않으며 효율적이고 직관적이며 해석이 쉽다.
- 제안 기법을 SPECK과 SIMON 두 암호에 적용해 실험적으로 평가하여 좋은 input difference를 식별하는 데 효과적임을 입증했다. 이 과정을 통해 SPECK에 대해 9개, SIMON에 대해 80개의 좋은 input difference를 얻었다.
- 제안 기법과 A. Gohr의 neural input difference 탐색 알고리즘 사이의 상세한 비교 분석을 실행 시간과 효능 측면에서 수행했다.
- 부차적 기여로, 광범위하고 시간이 많이 소요되는 neural distinguisher 학습을 수행하고 그 모델들을 제공한다. 제공 모델은 가능한 모든 one-bit differential dataset 경우에 대해 각각 학습된 5-round SPECK-32/64와 8-round SIMON용 neural distinguisher 총 64개, 그리고 hamming weight 2, 3, 4의 input difference를 사용한 5-round SPECK-32/64용 neural distinguisher 6개로 구성된다. 제공된 모델은 이후 differential neural cryptanalysis 연구에 활용될 수 있다.

또한 저자들은 제안 방법을 SPECK과 SIMON에 적용해 각각 5/6 rounds와 8/9 rounds에서 의미 있는 input difference를 식별했고, 이후 neural distinguisher를 학습시켜 이들 input difference가 다른 것들보다 높은 정확도를 달성함을 확인했다. 특히 이 input difference들은 기존 neural distinguisher와 비교해 최고의 정확도를 달성했다. 이 접근법은 전문적인 암호학 지식과 상당한 노력을 요구하는 differential cryptanalysis 같은 전통적 분석 방법과 대비되며, neural distinguisher 학습 전 dataset generation 단계에서 좋은 input difference를 식별하도록 도와 기존 기법보다 더 효율적이고 효과적으로 학습 가능한 differential dataset을 생성할 수 있게 한다.

## 제시한 방법론

### 1. 배경 구조: 신경 구별자와 차분 데이터셋

이 논문의 방법론은 차분-신경 암호분석(differential-neural cryptanalysis)의 딥러닝 파이프라인 중 데이터셋 생성 단계를 대상으로 한다. 신경 구별자(neural distinguisher)는 random과 real 두 클래스를 가지는 이진 분류 문제로 정의되며, 분류기 $g(x) : X \to 0,1$와 분류 오류 확률 $\mathbf{P}$에 대해 다음과 같이 정식화된다.

$$\arg\min_{g : X \to \{0,1\}} \mathbf{P}[g(x) = y]$$

구별자 구조는 ResNet [21] 기반으로 initial layer, residual blocks, prediction head의 세 부분으로 나뉘며, initial layer에서 암호문 쌍을 워드 단위로 배열해 각 비트를 입력 노드에 넣어 암호문 워드의 비트별 특징을 학습하게 한다.

차분 데이터셋(differential dataset)은 평문 쌍 $(P, P')$, 암호문 쌍 $(C, C') \in X$, 레이블 $y \in \{0,1\}$(0: random, 1: real), 암호화 함수 $E(pt,k)$에 대해 다음과 같이 생성된다. 레이블이 1이면 평문 쌍은 $P' = P \oplus \Delta$를 만족한다.

$$(C, C') = \begin{cases} (E(P,k), E(P',k)), & \text{if } label = 0 \\ (E(P_0,k), E(P' \oplus \Delta), k), & \text{if } label = 1 \end{cases}$$

### 2. 기존 방법의 한계 진단

Gohr는 두 가지 데이터셋 생성 방법을 제시했다. 첫째는 차분 암호분석으로 알려진 고확률 차분 특성(differential characteristic)에서 입력 차분(input difference)을 가져오는 방식이다. Gohr가 쓴 (0x0040, 0x0000)은 [25]에서 제시된 차분 특성의 일부로, 낮은 해밍 웨이트(hamming weight)를 가지며 (0x8000/8000)으로 가는 1-라운드 SPECK-32/64 결정론적 전이를 보인다. 즉 Gohr는 해밍 웨이트와 입력 차분의 전이를 핵심 요소로 고려했다. 낮은 해밍 웨이트는 비선형 연산에 의한 1-비트 차분 발생을 줄이고, 분석에 유리한 형태로 전파되는 전이는 더 많은 라운드를 더 높은 확률로 분석할 수 있게 하므로 차분 암호분석 관점에서 합리적이다. 그러나 이 방법은 사전 차분 특성 분석과 광범위한 암호학적 지식·노력을 요구한다. [11]처럼 SAT/SMT solver로 차분 특성을 탐색하는 방식도 최적화 문제로 변환하는 과정에서 대상 암호에 대한 전문 지식이 여전히 필요하다.

둘째는 Gohr의 _GreedyOptimizerWithExplorationBias_ 알고리즘으로, 이 논문은 이를 neural input difference exploration(NIDE)로 부른다(Algorithm 1). NIDE는 입력 차분 $x$를 무작위로 초기화하고, 매 반복에서 무작위 비트 위치 $r$을 뒤집어 $x_{\text{new}} \leftarrow x \oplus (1 \ll r)$를 만든 뒤, 탐색 횟수를 기록하는 해시테이블 $H$를 이용해 $v_{\text{new}} - \alpha \log_2(H[x_{\text{new}}]) > v - \alpha\log_2(H[x])$일 때 이동하는 탐색 편향(exploration bias) 구조를 쓴다. 여기서 함수 $F$는 입력 차분에 따라 차분 데이터셋을 생성하고 신경 구별자를 학습시키는 함수이며, Gohr의 구현에서는 무작위 입력 차분으로 사전 학습된 신경 구별자의 중간 출력값을 학습하는 Ridge classifier로 설정되어 few-shot learning 기반의 빠른 탐색을 가능하게 한다.

저자들은 Gohr와 동일한 파라미터($F$: 전처리된 신경 구별자를 쓴 Ridge, $t$: 2000, $\alpha$: 0.01, $b$: 32)로 Intel Xeon Gold 6230R CPU @ 2.10 GHz와 NVIDIA GeForce RTX 3090 환경에서 5-라운드 SPECK-32/64에 대해 100회 실행했다. 그 결과 모든 실행에서 약 50–55% 정확도의 입력 차분만 찾았고 평균 실행 시간은 약 200초였는데, (0x0040, 0x0000)의 약 93%에 비해 유의미하지 않았다. 여기서 두 한계가 도출된다. (i) 입력 차분을 완전히 무작위로 선택하므로 좋은 차분 특성과 연관된 입력 차분을 찾을 확률이 낮다. (ii) 구별자의 소규모 학습 결과로 입력 차분을 평가하는 것은 학습이 충분히 완료되지 않을 수 있어 신뢰하기 어렵다. 다만 충분한 학습은 많은 입력 차분을 빠르게 탐색한다는 NIDE의 목표에 부합하지 않는다.

이에 따라 두 가지 개선 전략이 설정된다. 첫째, 암호분석 관점에서 유리한 입력 차분, 즉 낮은 해밍 웨이트를 우선 탐색한다. 둘째, 딥러닝 모델에 기반하지 않는 다른 방법으로 입력 차분을 평가한다. 두 번째 전략을 위해 PCA와 K-means clustering을 one-bit 차분 데이터셋에 적용하고, 좋은 차분 데이터셋이 가진 특성(Q1)과 그것을 식별·평가할 수 있는지(Q2)를 묻는다.

### 3. 분석 도구: PCA와 K-means clustering

PCA [22]에서는 데이터 행렬 $A$에 대해 각 변수의 평균이 0일 때 공분산 행렬을 다음과 같이 얻는다.

$$cov(A) = \frac{1}{n-1}AA^T \propto AA^T$$

이후 고유값 분해로 $A \cdot x = \lambda x$를 만족하는 고유값 $\lambda$와 고유벡터 $x$를 구한다.

$$AA^T = U\Lambda U^T$$

여기서 $U$의 열벡터는 공분산 행렬 $AA^T$의 고유벡터로 데이터가 분산된 방향을 나타내며 주축 후보가 된다. $\Lambda$는 대각 성분이 고유값인 대각 행렬이고, 고유값은 해당 고유벡터 방향으로의 데이터 분산 크기를 나타낸다. 고유값을 내림차순 정렬하면 중요도 순으로 성분을 얻을 수 있다. 수학적으로 PCA는 모든 기저 벡터를 정규직교 행렬로 가정하는 직교 선형 변환으로 볼 수 있다.

K-Means clustering [23]은 비지도 학습으로, 대상 객체를 $x$, 클러스터 $C_i$의 중심을 $x_i$라 할 때 기준 함수는 다음과 같다.

$$E = \sum_{i=1}^{k} \sum_{x \in C_i} (|x - x_i|)^2$$

알고리즘은 두 단계로, 먼저 주어진 $k$에 대해 $k$개 중심을 무작위 선택하고, 다음으로 각 데이터 점을 유클리드 거리로 가장 가까운 중심에 할당한다.

$$d(x_i, y_i) = \left(\sum_{i=1}^{n}(x_i - y_i)^2\right)^{1/2}$$

이후 중심을 재계산하고 재할당을 반복하여 목적 함수 $E$가 최소화될 때까지 수행한다.

### 4. 고유값 비율 기준의 설계

구현에는 Python sklearn.decomposition의 PCA 라이브러리를 사용했다. 이 라이브러리는 고유값 분해가 아니라 Singular Value Decomposition(SVD) [26]으로 주성분을 계산한다. SVD와 고유값 분해는 수학적으로 동일한 결과를 주지만 SVD가 계산적으로 더 효율적이기 때문이다. 이 때문에 정확한 고유값 행렬은 제공되지 않고 explained_variance_ratio로 고유값 비율의 추정치가 제공된다. $i$번째 고유값을 $\lambda_i \in \Lambda$라 하면 explained_variance_ratio는 $\lambda_i / \Sigma_{\lambda \in \Lambda}\lambda$이며, 논문은 이를 _eigenvalue ratio_ $\rho$로 부른다.

데이터를 유의미하게 대표하는 고유벡터가 없다면 모든 방향의 설명 정도가 유사하다는 뜻이고, 이는 $\lambda_i = \lambda_j$ ($\lambda_i, \lambda_j \in \Lambda$, $i \neq j$)로 표현된다. 데이터셋 차원이 $n$이면 찾을 수 있는 방향의 수도 $n$이므로 $i$번째 고유값 비율은

$$\rho_i = \frac{\lambda_i}{\Sigma_{\lambda \in \Lambda}\lambda} = \frac{\lambda_i}{n\lambda_i} = \frac{1}{n}$$

따라서 유의미한 방향의 고유값 비율은 $1/n$보다 커야 한다. 암호문 쌍으로 구성된 차분 데이터셋의 차원 수는 (2 × 블록 크기)이므로, 블록 크기 32의 SPECK에서는 64차원이며 기준값은 $1/64 = 0.015625$로 $\lambda_{\text{base}}$라 둔다. PCA 계산에는 신경 구별자 학습에 쓴 데이터셋 크기의 1/10인 $10^6$개 암호문 쌍만 사용해 계산상 이점을 얻었다.

기준선 설정을 위해 5-라운드 SPECK-32/64의 모든 one-bit 차분 데이터셋을 구성하고, Gohr의 모델에 10-depth residual blocks 설정으로 학습해 정확도를 측정했으며 학습 파이프라인과 파라미터는 전 과정에서 일관되게 유지했다. (0x0040, 0x0000)이 93%로 최고였고 (0x0020, 0x0000)도 거의 90%였다.

(0x0040, 0x0000) 데이터셋에서 random case의 고유값 비율은 $|\rho_{\text{random}} - \lambda_{\text{base}}| \leq 0.00024$로 $\lambda_{\text{base}}$와 큰 차이가 없었으나, real case에서는 $\lambda_{\text{base}}$를 초과하는 비율이 여럿 나타나 최대 편차가 random case의 약 50배였고 $|\rho_{\text{real}} - \lambda_{\text{base}}| < 0.01196$으로 표시된다. 데이터셋별로 $\lambda_{\text{base}}$의 10%를 넘는 편차의 개수, 즉 $count(|\rho - \lambda_{\text{base}}| \geq 0.1 * \lambda_{\text{base}})$를 집계했다.

### 5. 고유벡터 계수의 암호분석적 해석

(0x0040, 0x0000)에 대해 편차가 가장 큰 18개 고유벡터를 분석했다. 양의 편차 상위 9개를 PC0-PC8, 음의 편차 하위 9개를 PC55-63이라 한다. 차분 데이터셋의 각 특징은 암호문 쌍의 각 비트에 대응하므로, 고유벡터 계수를 해당 비트의 영향력으로 간주한다. $C_l$, $C_r$은 한 암호문의 좌·우 워드, $C_l'$, $C_r'$은 다른 암호문의 좌·우 워드다. 해석 규칙은 다음과 같다. 양의 상관(positive correlation)은 계수의 절댓값이 0보다 유의하게 크고 부호가 같은 경우로, 대응 비트 값이 같음, 즉 0 차분을 뜻한다. 음의 상관(negative correlation)은 절댓값이 0보다 유의하게 크고 부호가 다른 경우로, 대응 비트 값이 다름, 즉 1 차분을 뜻한다. 예컨대 PC0에서 비트 위치 1의 계수가 부호가 반대이고 절댓값이 0.71이면 1 차분으로, PC1에서 비트 위치 0의 계수가 같은 부호이고 절댓값이 0.71이면 0 차분으로 해석한다. PC0-8과 PC55-63의 결과가 서로 반대라는 점은 전자가 데이터를 효과적으로 대표하는 양의 편차 주성분이고 후자는 비효과적 축임을 시사하여 위 해석을 뒷받침한다. 이를 종합해 다음 절단 차분 특성(truncated differential characteristic)을 도출했다.

$$(1******00*****10, 1******0******00)_2$$

이는 Benamira et al. [9]이 유도한 5-라운드 SPECK-32/64 절단 차분 특성의 부분집합이므로 해석이 타당하다. 이 접근은 [9]의 암호문 분석 방법론에서 착안했다.

### 6. 클러스터링 기반 정량 평가

시각화를 위해 고유값 비율이 가장 큰 세 고유벡터를 축으로 데이터를 투영했다. random case는 가우시안(또는 단봉) 분포의 무작위 표본처럼 구 형태의 단일 클러스터를 형성했다. 반면 real case에서는 학습 정확도가 높은 데이터셋일수록 밀도가 높은 다수의 클러스터를 형성했고, 최고 정확도의 (0x0040, 0x0000)은 3차원 공간에서 서로 최대한 멀어지도록 $3^3 = 27$개의 뚜렷한 클러스터를 형성했다.

클러스터 형성은 고유값 비율·고유벡터 분석보다 정확도 높은 데이터셋의 특성을 더 정확히 나타낸다. 정확도 0.871의 (0x0000, 0x8000)은 (0x0010, 0x0000)보다 4% 높지만 $count(|\rho - \lambda_{\text{base}}| \geq 0.1 * \lambda_{\text{base}})$는 6으로 2 적다. $\max(|\rho - \lambda_{\text{base}}|)$를 보면 (0x0000, 0x8000)은 0.00750으로 (0x0010, 0x0000)의 0.00389보다 크지만, 정확도 0.805의 (0x0000, 0x4000)도 0.00724로 비슷하므로 이 지표만으로는 구분이 어렵다. 그래서 투영 데이터에 K-means clustering을 수행하고 클러스터 밀도를 실루엣 점수(silhouette score) [27]로 평가했다. 클러스터 수는 시각화 결과에 근거해 27로 설정했다. 실루엣 점수는 클러스터의 평균 거리로 _inner_ 및 _inter cluster distance_를 계산하는데, inner cluster distance는 한 클러스터 내 데이터 점 간 평균 거리이고 inter cluster distance는 클러스터 간 평균 거리다. 정확도가 높을수록 실루엣 점수도 높은 상관이 관찰되었다.

이로써 Q1의 답은 좋은 차분 데이터셋이 자신을 구별해 주는 강한 절단 차분 특성을 가지며 차원 축소 시 뚜렷한 클러스터를 형성한다는 것이고, Q2의 답은 PCA로 축소된 차원에서 형성된 클러스터의 밀도를 평가해 정량적으로 식별·평가할 수 있다는 것이다.

### 7. 제안 알고리즘 (Algorithm 2)

입력은 암호문 쌍의 수 $n$, 대상 암호의 키 크기 $ks$, 블록 크기 $bs$, 해밍 웨이트 $hw$, 고유값 비율 임계값 $t_0$, 주성분 개수 임계값 $t_1$, 클러스터 검증 임계값 $t_2$이며, 출력은 입력 차분 $\Delta$, 차분 데이터셋 $D$, 실루엣 점수 $SC$다. 절차는 다음과 같다.

**(a) 데이터셋 생성(lines 5–16).** $K \leftarrow Rand(0, 2^{ks}-1)$로 키를 뽑고, $\Delta \leftarrow RandLowHammingWeight(hw)$로 입력 차분을 선택한다. 이 함수는 목표 해밍 웨이트 $hw$를 만족하는 차분 중 하나를 무작위로 고르는데, 블록 크기 $bs$에서 $hw$개 비트를 고르는 경우의 수는

$$\binom{bs}{hw} = \frac{bs!}{hw!(bs-hw)!}$$

이며, $hw = 1$부터 시작하는 순서로 우선 선택한다. 이는 차분 암호분석 관점에서 유리한 낮은 해밍 웨이트를 우선하기 위한 설계다. 이어 각 샘플마다 $label \leftarrow Rand(0,1)$을 뽑아, $label = 0$이면 $P, P' \leftarrow Rand(0, 2^{bs}-1), rand(0, 2^{bs}-1)$, $label = 1$이면 $P \leftarrow Rand(0,2^{bs}-1)$, $P' \leftarrow P \oplus \Delta$로 두고 $E_K(P) \,||\, E_K(P')$를 $D$에 추가한다. 초기화 단계에서 $\lambda_{random} \leftarrow \frac{1}{2bs}$로 설정한다.

**(b) PCA(lines 17–28).** $A \leftarrow cov(D)$ 후 line 18에서 $\Lambda, V \leftarrow PCA.EigenValueDecomposition(A)$로 고유값 비율 $\Lambda$와 대응 고유벡터 $V$를 얻는다. lines 20–22에서 각 $\lambda_i \in \Lambda$에 대해 $(\lambda_i - \lambda_{base}) \geq t_0$이면 해당 고유벡터를 주성분 배열 $PC$에 저장한다. line 25에서 $Count(PC)$가 $t_1$에 미달하면 line 4로 돌아가 입력 차분을 재선택하고 데이터셋을 다시 만든다. $t_0$와 $t_1$은 고유벡터의 대표력에 따른 선택을 좌우하는 하이퍼파라미터다. line 28에서 얻은 주성분을 축으로 차원 축소를 수행한다.

**(c) 클러스터 평가(lines 29–33).** 축소된 데이터에 $C \leftarrow Kmeans(D, k = 3^{Count(PC)})$로 클러스터링한다. 클러스터 수를 $3^{Count(PC)}$로 둔 것은 앞 장의 (0x0040, 0x0000) 클러스터링 결과에서 도출된 전략으로, 축소 차원에서 가능한 최대 클러스터 분리를 뜻한다. 이어 $SC \leftarrow SilhouetteScore(D, cluster\_label = C)$를 계산하고, $SC \leq t_2$이면 $D \leftarrow null$로 두어 입력 차분 선택 단계로 되돌아간다. $t_2$ 역시 클러스터 형성 평가용 하이퍼파라미터다. $t_2$를 넘으면 탐색된 입력 차분, 실루엣 점수, 차분 데이터셋을 반환한다.

### 8. 하이퍼파라미터 설정과 설계 근거

5-라운드 SPECK-32/64에서는 $t_0 = 0.004$, $t_1 = 3$, $t_2 = 0.4$, $n = 10^5$로 설정했다. 이 값들은 4절의 결과에 기반해 반복 실험을 통한 휴리스틱 접근으로 최적화했다. $2^{bs}$ 공간의 모든 입력 차분을 탐색하는 것은 비현실적이므로 $hw$는 1부터 4까지만 실험했다.

8-라운드 SIMON-32/64에서는 SPECK과 동일한 하이퍼파라미터로는 $t_1 = 3$을 만족하는 고유값 비율이 없어 3차원 차원 축소가 불가능했다. 이로부터 8-라운드 SIMON의 특성이 5-라운드 SPECK보다 본질적으로 약하다고 추정하고, 고유값 분해 관련 하이퍼파라미터를 더 느슨하게 조정해 $t_0 = 0.003$, $t_1 = 2$, $t_2 = 0.3$을 사용했다. 이 설정에서 알고리즘은 $\lambda_i \in \Lambda - \lambda_{base} \geq 0.02$인 고유벡터가 2개 존재하는지 확인하고, 존재하면 2차원 평면으로 투영한 뒤 투영된 데이터가 9개 클러스터를 형성하며 각 클러스터가 최소 0.3의 실루엣 점수를 보이는지 검사한다.

또한 반환되는 데이터셋 크기는 $n$에 비례하므로, $n$을 작게 잡은 경우 데이터셋 생성은 수 초 내에 가능하다는 점을 이용해 탐색된 입력 차분만 취하고 충분한 학습을 위해 더 큰 데이터셋을 다시 생성하는 것이 바람직하다고 권고한다.

## 실험 및 평가

### 실험 환경과 대상

실험은 Intel Xeon Gold 6230R CPU @ 2.10 GHz와 NVIDIA GeForce RTX 3090 환경에서 수행되었다. 대상 암호는 ARX 기반 경량 블록암호인 SPECK과 SIMON이며, 구체적으로 5-round SPECK-32/64와 8-round SIMON-32/64를 표적으로 삼았다. 신경 구별자(neural distinguisher)는 A. Gohr의 모델을 그대로 사용하되 잔차 블록(residual blocks) 깊이를 10으로 설정했고, 학습 파이프라인과 파라미터는 전 실험에서 동일하게 유지했다. 학습 에폭은 200이다.

### 기준선 구축: 1비트 차분 데이터셋 전수 학습

좋은 차분 데이터셋(differential dataset)의 기준선을 만들기 위해, 저자들은 5-round SPECK-32/64에 대해 가능한 모든 1비트 입력 차분(one-bit differential datasets)으로 데이터셋을 구성하고 각각 신경 구별자를 학습시켜 정확도를 측정했다(Table III). 그 결과 Gohr가 SPECK 데이터셋 구성에 사용한 입력 차분 (0x0040, 0x0000)이 93%로 가장 높은 정확도를 보였고, (0x0020, 0x0000)과 같은 다른 입력 차분도 거의 90%에 가까운 정확도를 보였다. 이 데이터셋들을 좋은 차분 데이터셋의 기준선으로 삼아 PCA 분석을 집중적으로 수행했다. PCA 단계에서는 계산상의 이점을 위해 신경 구별자 학습에 쓰인 데이터셋 크기의 1/10에 해당하는 $10^6$개의 암호문 쌍만 사용했다.

### 평가 지표

평가는 세 축으로 이루어진다. 첫째, 고유값 비율(eigenvalue ratio) $\rho$로, sklearn의 `explained_variance_ratio`에 해당하며 $i$번째 고유값에 대해 $\lambda_i/\Sigma_{\lambda\in\Lambda}\lambda$로 정의된다. 모든 방향의 설명력이 같을 때의 기준값은 $\rho_i = 1/n$이며, 암호문 쌍으로 구성된 데이터셋의 차원은 (2 × 블록 크기)이므로 블록 크기 32의 SPECK에서는 차원이 64, 따라서 $\lambda_{\text{base}} = 1/64 = 0.015625$가 된다. 둘째, 클러스터 밀도를 정량화하는 실루엣 점수(silhouette score)이며, 클러스터 내부 거리(inner cluster distance)와 클러스터 간 거리(inter cluster distance)를 평균 거리로 계산한다. 셋째, 최종 검증 지표로서 신경 구별자의 학습 정확도다.

### 분석 결과: 고유값 비율과 고유벡터

(0x0040, 0x0000) 데이터셋에서 random case의 고유값 비율은 $\lambda_{\text{base}}$와 큰 차이가 없어 $|\rho_{\text{random}} - \lambda_{\text{base}}| \leq 0.00024$였다. 반면 real case에서는 $\lambda_{\text{base}}$를 초과하는 고유값 비율이 여러 개 나타났고, 최대 편차는 $|\rho_{\text{real}} - \lambda_{\text{base}}| < 0.01196$으로 random case 대비 약 50배 컸다. $\lambda_{\text{base}}$의 10%를 초과하는 편차의 개수, 즉 $count(|\rho - \lambda_{\text{base}}| \geq 0.1 * \lambda_{\text{base}})$에서도 (0x0040, 0x0000)과 (0x0020, 0x0000)이 높은 값과 큰 $\max(|\rho - \lambda_{\text{base}}|)$를 동시에 보였다(Table IV).

고유벡터 해석에서는 편차가 가장 큰 18개(양의 편차 상위 9개 PC0–PC8, 음의 편차 하위 9개 PC55–PC63)를 분석했다. 각 특성은 암호문 쌍의 각 비트에 대응하며, 계수의 절댓값이 0보다 유의하게 크고 부호가 같으면 양의 상관(positive correlation, 0 차분), 부호가 다르면 음의 상관(negative correlation, 1 차분)으로 해석했다. 예를 들어 PC0에서 $C_l$과 $C_l'$의 비트 위치 1 계수는 부호가 반대이고 절댓값이 0.71이어서 1 차분으로, PC1에서 비트 위치 0은 같은 부호에 절댓값 0.71이어서 0 차분으로 해석된다. 이를 모든 PC에 적용해 합성한 결과 절단 차분 특성(truncated differential characteristic)

$$(1******00*****10,\ 1******0******00)_2$$

을 도출했으며, 이는 Benamira et al. [9]이 유도한 5-round SPECK-32/64 절단 차분 특성의 부분집합이어서 해석의 타당성을 뒷받침한다. 또한 PC0–8과 PC55–63의 해석 결과가 서로 반대라는 점은 전자가 데이터를 효과적으로 표현하는 축, 후자가 비효과적인 축임을 시사한다.

### 분석 결과: 시각화와 클러스터링

고유값 비율 상위 3개 고유벡터를 축으로 데이터를 투영해 시각화했다. random case는 가우시안(또는 단봉) 분포에서 무작위 표본을 추출한 결과처럼 구형의 단일 클러스터를 형성했다. 반면 real case에서는 학습 정확도가 높은 데이터셋일수록 밀도가 높은 다수의 클러스터를 형성했고, 정확도가 가장 높은 (0x0040, 0x0000)은 3차원 공간에서 서로 최대한 멀리 떨어진 $3^3 = 27$개의 뚜렷한 클러스터를 만들었다.

고유값 비율만으로는 한계가 있음도 확인되었다. 정확도 0.871인 (0x0000, 0x8000)은 (0x0010, 0x0000)보다 정확도가 4% 높지만 유의 고유벡터 개수는 6개로 오히려 2개 적었다. $\max(|\rho - \lambda_{\text{base}}|)$를 보면 (0x0000, 0x8000)이 0.00750으로 (0x0010, 0x0000)의 0.00389보다 크지만, 정확도 0.805인 (0x0000, 0x4000) 역시 0.00724로 유사해 이 지표만으로 구분하기는 어려웠다. 이에 투영된 데이터에 K-means clustering을 수행하고(클러스터 수는 시각화 결과에 근거해 27로 설정) 실루엣 점수로 밀도를 평가했으며, 정확도 상위 4개 입력 차분에 대해 정확도가 높을수록 실루엣 점수도 높다는 상관관계를 관찰했다.

### 베이스라인 비교: Gohr의 NIDE 알고리즘

베이스라인은 Gohr의 신경 입력 차분 탐색(neural input difference exploration, NIDE) 알고리즘, 즉 *GreedyOptimizerWithExplorationBias*다. 저자들은 Gohr가 설정한 파라미터를 그대로 사용해($F$: 사전학습 신경 구별자로 전처리된 Ridge classifier, $t$: 2000, $\alpha$: 0.01, $b$: 32) 5-round SPECK-32/64에 대해 100회 실행했다. 모든 실행에서 발견된 입력 차분의 정확도는 약 50–55%에 머물렀고, 평균 실행 시간은 약 200초였다. 이는 (0x0040, 0x0000)의 약 93%에 비해 유의미하지 않은 수준이다. 저자들이 지적한 NIDE의 두 한계는 입력 차분을 완전히 무작위로 선택한다는 점과, 구별자의 소규모 학습 결과에 기반한 평가가 학습이 충분히 완료되지 않아 신뢰할 수 없다는 점이다.

### 실험 1: 5-round SPECK-32/64

하이퍼파라미터는 $t_0 = 0.004$, $t_1 = 3$, $t_2 = 0.4$로 설정하고 암호문 쌍 $n = 10^5$개로 알고리즘을 실행했다. 이 설정은 Section IV의 분석 결과를 바탕으로 반복 실험을 통한 휴리스틱 방식으로 최적화되었다. $2^{bs}$ 공간의 모든 입력 차분을 탐색하는 것은 비현실적이므로 해밍 웨이트(hamming weight) $hw$를 1에서 4까지로 제한했다. 그 결과 9개의 좋은 입력 차분을 찾아냈다(Table VII). 알고리즘은 Section IV에서 학습 정확도가 높았던 1비트 차분 상위 3개를 성공적으로 식별했으며, $hw \geq 3$인 모든 탐색 결과가 80%를 넘는 정확도를, $hw = 2$인 경우는 (0x0040, 0x0000)과 유사하게 92%를 넘는 정확도를 보였다.

효율성 측면에서, 크기 $10^5$의 차분 데이터셋에 대한 고유값 분해, 차원 축소, K-means clustering, 실루엣 점수 계산을 포함한 총 계산 시간은 평균 약 140초였다. 이는 NIDE의 약 200초 대비 약 30%의 실행 시간 단축이며, 사용 데이터는 약 1/100에 불과하다. 다만 $n$을 작게 잡으면 반환되는 데이터셋도 작아지므로, 이 경우 탐색된 입력 차분만 취하고 충분한 학습을 위해 더 큰 데이터셋을 재생성하는 편이 바람직하다고 지적한다(데이터셋 생성 자체는 수 초 내에 가능).

### 실험 2: 8-round SIMON-32/64 (적용 가능성)

SPECK과 동일한 하이퍼파라미터로는 $t_1 = 3$을 만족하는 고유값 비율이 전혀 발견되지 않아 3차원 차원 축소가 불가능했다. 이를 근거로 8-round SIMON의 특성이 5-round SPECK보다 본질적으로 약하다고 추정하고, 고유값 분해 관련 기준을 완화해 $t_0 = 0.003$, $t_1 = 2$, $t_2 = 0.3$으로 조정했다. 이 설정에서 알고리즘은 $\lambda_i \in \Lambda - \lambda_{\text{base}} \geq 0.02$를 만족하는 고유벡터 2개의 존재를 확인하고, 존재하면 2차원 평면으로 투영한 뒤 9개 클러스터 형성 여부와 각 클러스터의 실루엣 점수 0.3 이상 여부를 검사한다.

$hw$ 1–4에 대해 실험한 결과 총 80개의 입력 차분을 찾았다(Table VIII). 탐색된 차분을 분석하니 1 차분이 좌측 워드(left word)보다 우측 워드(right word)에 주로 위치했고, 특히 $hw = 1$에서는 우측 워드에 단일 차분을 갖는 16개가 발견된 반면 좌측 워드 차분은 하나도 없었다. 검증을 위해 시간과 계산 자원 제약상 1비트 차분 데이터셋에 한해 PCA 시각화($10^5$개 real case 암호문 쌍)와 신경 구별자 학습($10^7$ 크기 데이터셋)을 수행했다(Fig. 7, Table IX). 시각화에서는 데이터량이 많아 패턴 식별이 어려워 밀집도를 색으로 표현했다.

결과적으로 우측 워드에 차분이 있는 경우 데이터가 9개 클러스터로 밀집했고, 좌측 워드 차분의 경우 random case와 유사한 단일 클러스터를 형성했다. $\max(|\rho - \lambda_{\text{base}}|)$는 우측 워드에서 0.003 이상, 좌측 워드에서는 약 0.002로 모두 0.003 미만이었으며, 이로 인해 제안 알고리즘이 좌측 워드 사례를 배제하게 된다. 신경 구별자 정확도는 우측 워드 차분에서 대체로 74%를 넘었고, 좌측 워드 차분의 약 61%보다 13% 이상 높았다. 각 워드 내 차분의 비트 위치는 학습에 큰 영향을 주지 않았고, 차분이 어느 쪽 워드에 있는지가 결정적이었다. 투영 데이터에 9개 클러스터로 K-means clustering을 수행한 결과(Fig. 8)도 PCA 시각화에서 우측 워드에 밀집한 9개 클러스터와 잘 대응함을 확인했다.

### 종합

전체적으로 5-round SPECK-32/64에서 Gohr의 알고리즘이 약 55% 정확도의 입력 차분을 찾는 데 그친 반면 제안 알고리즘은 90%를 넘는 입력 차분을 찾아 효과성을, 약 200초 대비 약 140초의 실행 시간으로 효율성을 입증했다. 8-round SIMON-32/64 실험으로 다른 암호에 대한 적용 가능성도 확인했으며, 최종적으로 SPECK용 9개, SIMON용 80개의 활용 가능한 입력 차분을 확보했다. 부수적으로 5-round SPECK-32/64와 8-round SIMON 각각에 대해 모든 1비트 차분 데이터셋으로 학습한 신경 구별자 64개씩, 그리고 해밍 웨이트 2, 3, 4의 입력 차분을 사용한 5-round SPECK-32/64용 신경 구별자 6개를 공개한다.

## 고찰

### PCA 해석의 암호학적 타당성

이 연구는 차분 데이터셋(differential dataset)의 특성을 주성분 분석(Principal Component Analysis, PCA)과 K-means clustering으로 평가한다. 저자들은 가장 높은 정확도를 보인 입력 차분(input difference) (0x0040, 0x0000) 데이터셋에서 편차가 큰 18개의 고유벡터를 분석했다. 고유벡터 계수의 부호가 같고 절댓값이 0보다 충분히 크면 해당 비트가 같은 값(0 차분)을 가지는 양의 상관(positive correlation)으로, 부호가 다르면 1 차분을 뜻하는 음의 상관(negative correlation)으로 해석했다. 예를 들어 PC0에서 $Cl$과 $Cl'$의 비트 위치 1에 해당하는 계수는 부호가 반대이고 절댓값이 0.71이어서 1 차분으로 읽었다. 이 방식으로 모든 PC를 해석해 얻은 결과는

$$(1******00*****10,\ 1******0******00)_2$$

로, Benamira et al. [9]이 5-round SPECK-32/64에 대해 유도한 truncated differential characteristic의 부분집합이다. 이는 고유벡터 계수 해석이 유효하다는 근거로 제시된다. 또한 PC0-8(양의 편차)과 PC55-63(음의 편차)의 해석 결과가 서로 반대로 나타난 점도 이 암호학적 해석을 지지하는 증거로 논의된다.

### 고유값 비율 지표만으로는 부족하다는 점

차원 수가 $n$일 때 각 방향의 설명력이 균일하다면 고유값 비율(eigenvalue ratio) $\rho_i$는 $1/n$이 되므로, 유의한 방향은 $1/n$보다 큰 값을 가진다. SPECK의 암호문 쌍 데이터셋은 차원이 64이므로 기준값은 $\lambda_{base} = 1/64 = 0.015625$이다. 그런데 고유값 비율 기반 지표만으로는 데이터셋의 우열을 가리기 어렵다. 정확도 0.871인 (0x0000, 0x8000) 데이터셋은 (0x0010, 0x0000)보다 정확도가 4% 높지만, $count(|\rho - \lambda_{base}| \ge 0.1 * \lambda_{base})$ 값은 6으로 오히려 2 적다. $\max(|\rho - \lambda_{base}|)$를 보면 0.00750 대 0.00389로 역전되지만, 정확도 0.805인 (0x0000, 0x4000)도 0.00724로 비슷한 값을 가지므로 이 지표 단독 구분도 어렵다. 저자들은 이 한계 때문에 투영된 데이터에 K-means clustering을 적용하고 실루엣 점수(silhouette score) [27]로 군집 밀도를 정량 평가하는 단계를 추가했으며, 정확도가 높을수록 실루엣 점수도 높아지는 상관을 확인했다.

### 기존 방법과의 비교에서 드러난 한계

Gohr의 첫 번째 데이터셋 생성 방식은 높은 확률의 차분 특성을 사전 분석해야 하므로 전문적인 암호 지식과 많은 노력을 요구하며, 이는 differential-neural cryptanalysis의 강점인 효율성을 약화시킨다. SAT/SMT solver를 사용한 [11]의 연구도 최적화 문제로 변환하는 과정에서 대상 암호에 대한 전문 지식이 여전히 필요하다는 한계가 남는다. 저자들이 직접 실행한 neural input difference exploration(NIDE) 알고리즘은 Gohr가 설정한 파라미터($F$: 전처리된 neural distinguisher를 쓰는 Ridge, $t$: 2000, $\alpha$: 0.01, $b$: 32)로 100회 수행 시 모든 실행에서 약 50–55% 정확도의 입력 차분만 찾았고 평균 실행 시간은 약 200초였다. 이는 (0x0040, 0x0000)의 약 93%에 비해 유의미하지 않다. 저자들은 NIDE의 한계를 두 가지로 정리한다. 하나는 입력 차분을 완전히 무작위로 선택해 좋은 차분 특성과 연결된 차분을 찾을 확률이 낮아진다는 점이고, 다른 하나는 distinguisher의 소규모 학습 결과로 입력 차분을 평가하는 것이 학습이 충분히 끝나지 않은 탓에 신뢰하기 어렵다는 점이다. 다만 충분한 학습을 수행하는 보완책은 많은 입력 차분을 빠르게 탐색한다는 NIDE의 목표와 맞지 않는다.

### 제안 방법 자체의 제약

제안 알고리즘의 하이퍼파라미터 $t_0, t_1, t_2$는 Section IV의 분석 결과를 바탕으로 반복 실험을 거친 휴리스틱 방식으로 정했다. 또한 $2^{bs}$ 공간 전체를 탐색하는 것은 비현실적이므로 실험은 해밍 웨이트(hamming weight) $hw$가 1에서 4인 범위로만 수행했다. PCA 단계에서도 계산상의 이점을 위해 neural distinguisher 학습에 쓴 데이터셋의 1/10에 해당하는 $10^6$ 암호문 쌍만 사용했다. 알고리즘이 반환하는 데이터셋 크기는 $n$에 의존하므로, $n$을 작게 잡은 경우에는 탐색된 입력 차분만 취하고 충분한 학습을 위한 더 큰 데이터셋을 다시 생성하는 편이 바람직하다고 저자들은 권고한다.

대상 암호가 바뀌면 하이퍼파라미터도 조정해야 한다. 8-round SIMON-32/64에 SPECK과 같은 설정을 적용했을 때는 $t_1 = 3$을 만족하는 고유값 비율이 없어 3차원 축소 자체가 불가능했다. 저자들은 8-round SIMON의 특성이 5-round SPECK보다 본질적으로 약할 것이라 추정하고 $t_0 = 0.003$, $t_1 = 2$, $t_2 = 0.3$으로 완화해 2차원 평면 투영과 9개 군집 형성 여부를 검사하도록 바꿨다. SIMON 검증 범위도 제한적이다. 시간과 계산 자원의 제약으로 PCA 시각화와 neural distinguisher 학습은 8-round SIMON의 one-bit differential dataset에 대해서만 수행했으며, 시각화는 $10^5$개의 real case 암호문 쌍, 학습은 충분한 학습을 보장하기 위한 $10^7$ 크기 데이터셋을 사용했다. 데이터 양이 많아 패턴을 직관적으로 파악하기 어려워 밀집 정도를 색으로 표현했다.

### SIMON에서 관찰된 추가 논의

탐색된 80개의 입력 차분을 보면 1 차분이 left word보다 right word에 주로 위치했고, $hw = 1$에서는 right word에 차분이 있는 16개가 발견된 반면 left word 쪽은 하나도 없었다. 시각화에서도 right word 차분 사례는 9개 군집으로 밀집했으나 left word 차분 사례는 random case처럼 단일 군집을 형성했다. $\max(|\rho - \lambda_{base}|)$는 right word 사례에서 0.003을 넘고 left word 사례에서는 약 0.002로 모두 0.003 미만이어서, 임계값 0.003에 의해 left word 사례가 배제되었다고 설명한다. 정확도 역시 right word 사례가 대체로 74% 이상, left word 사례가 약 61%로 13% 이상 차이가 났다. 각 워드 내 차분의 위치는 학습에 큰 영향을 주지 않았고 차분이 어느 쪽 워드에 있는지가 유의하게 작용했다는 해석이다.

### 향후 연구

저자들은 본 논문의 PCA 기반 분석 방법론을 토대로 PCA 기반 distinguisher를 개발하고 차분 공격을 수행하는 방향을 제시한다. PCA 결과의 고유벡터 계수를 truncated differential characteristic으로 해석할 수 있다는 점이 가능성을 시사하지만 추가 연구가 필요하다고 밝힌다. 또 다른 방향으로 제안 알고리즘을 다른 암호로 확장하는 것을 든다.

## 결론

이 논문은 differential-neural cryptanalysis를 수행할 때 학습이 잘 되는 차분 데이터셋을 만들기 위한 입력 차분 탐색의 새로운 접근을 제안한다. 암호학적 방법이나 딥러닝으로 입력 차분을 찾는 기존 방식과 구별되며, PCA와 K-means clustering이라는 데이터 분석 기법에 기반한다는 점에서 효과성과 효율성의 이점을 가진다.

분석을 통해, 좋은 입력 차분으로 생성한 차분 데이터셋은 PCA로 축소한 차원에서 여러 개의 구별되는 군집을 형성하며 이것이 좋은 암호학적 성질(구체적으로 truncated differential characteristic)의 존재와 대응한다는 점을 확인했다. 또한 PCA의 고유값 분해 결과와 축소 차원에 투영된 데이터의 K-means clustering, 군집 밀도 평가를 함께 사용해 군집 형성 정도, 즉 그 성질의 강도를 정량적으로 평가할 수 있었다. 이는 연구 질문 Q1과 Q2에 대한 답으로 정리된다.

제안 알고리즘은 차분 공격 관점에서 유리한 낮은 해밍 웨이트의 입력 차분을 먼저 선택한 뒤 PCA와 K-means clustering을 수행해, Gohr의 NIDE 알고리즘이 가진 효과성과 무작위 입력 차분 선택의 한계를 개선한다. 실험 결과 5-round SPECK-32/64에서 Gohr의 알고리즘은 약 55% 정확도의 입력 차분을 찾은 데 비해 제안 알고리즘은 90%를 넘는 정확도의 입력 차분을 찾아 더 효과적임을 확인했다. $hw \ge 3$에서 탐색된 입력 차분은 모두 80%를 넘는 정확도를, $hw = 2$인 경우는 (0x0040, 0x0000)에 근접한 92% 이상의 정확도를 보였다. 효율성 측면에서는 Gohr의 알고리즘이 입력 차분 하나에 약 200초가 걸린 반면 제안 알고리즘은 약 140초로, 약 1/100의 데이터만 사용하면서 실행 시간을 약 30% 줄였다. 다른 알고리즘에 대한 적용 가능성은 8-round SIMON-32/64에서 검증했고 높은 정확도의 입력 차분을 성공적으로 탐색했다. 이 실험들을 통해 SPECK에서 9개, SIMON에서 80개의 사용 가능한 입력 차분을 확보했다.

부가적인 기여로, 저자들은 광범위하고 시간이 많이 드는 neural distinguisher 학습을 수행해 모델을 공개한다. 5-round SPECK-32/64와 8-round SIMON 각각에 대해 가능한 모든 one-bit differential dataset으로 학습한 총 64개의 neural distinguisher와, 해밍 웨이트 2, 3, 4의 입력 차분을 사용한 5-round SPECK-32/64용 6개의 neural distinguisher로 구성되며, 후속 differential-neural cryptanalysis 연구에 활용될 수 있다.
