# Extracting CNNs in the Unknown-Architecture and Feedback-Agnostic Setting

[원문](https://arxiv.org/abs/2609.27427v1) · [PDF](https://arxiv.org/pdf/2609.27427v1)

## 한눈에 보기

합성곱 신경망(convolutional neural networks, CNNs)에 대한 암호해독적 추출(cryptanalytic extraction)에서 기존 공격이 전제했던 아키텍처 기지(known-architecture) 가정을 제거한 연구로, 파라미터 복원 공격이 산출하는 복원 벡터(recovered vector)의 공간적 기하 구조가 레이어 종류·kernel size·stride·padding mode·출력 채널 수·pooling 구조를 그대로 누출한다는 점을 형식화하고, raw-output과 hard-label 양쪽 피드백 설정에서 동일하게 작동하는 feedback-agnostic 아키텍처 복원 공격을 제시한다.

## 초록

이 논문은 합성곱 신경망(convolutional neural networks, CNNs)의 암호해독적 추출(cryptanalytic extraction)을 연구한다. CNNs에 대한 기존 암호해독적 추출 공격은 네트워크 아키텍처가 알려져 있다고 가정하고 모델 파라미터를 복원하려 한다. 이 논문에서 우리는 max pooling과 average pooling을 모두 갖는 CNNs에 대해 아키텍처 가정이 제거될 수 있음을 처음으로 증명한다. 우리의 핵심 발견은, 기존 파라미터 복원 공격이 복원해 내는 가중치 벡터들의 공간적 기하 구조(spatial geometry)가 자연스럽게 아키텍처를 누출한다는 것이다. 우리는 이 기하 구조를 형식화하고, 이를 합성곱 레이어의 아키텍처 지식과 대응시킨다. (1) convolution receptive field와의 희소성 일치(sparsity consistency)는 레이어 종류, kernel size, stride를 드러낸다. (2) kernel 파라미터와의 수치적 일치(numerical consistency)는 padding mode와 출력 채널 수(output-channel number)를 드러낸다. (3) pooling 연산과의 구조적 일치(structural consistency)는 pooling 종류, window size, stride를 드러낸다. 복원된 벡터들은 raw-output 설정과 hard-label 설정에서 서로 다른 방법으로 얻어지지만, 그 공간적 기하 구조는 동일하게 유지된다. 따라서 우리의 아키텍처 복원은 feedback-agnostic하다. 즉, 파라미터 복원 공격과 결합하면 black-box 설정에서 아키텍처와 파라미터를 모두 복원하는 완전한 암호해독적 추출 프레임워크를 얻는다. 광범위한 CNNs에 대해 레이어 단위(layer-wise)와 종단간(end-to-end) 실험을 모두 포함하는 폭넓은 실험을 통해, 네트워크 아키텍처와 모델 파라미터를 동시에 복원하는 것이 실용적임을 보인다.

## 필요성

학습된 심층 신경망(deep neural network, DNN)은 값비싼 데이터, 계산, 전문성을 구현한 자산이므로 통상 원격 black-box 서비스로 배포되며, 사용자는 입력을 제출하고 반환된 피드백만 관찰할 수 있다. 여기서 모델 추출(model extraction) 문제가 제기되는데, 가장 어려운 목표는 추출된 모델이 입력 공간의 모든 점에서 피해 모델과 동일한 raw output을 반환해야 하는 functionally equivalent extraction이다 [14].

DNN은 아키텍처 _A_ 와 파라미터 _Θ_ 로 결정된다. _A_ 는 레이어 종류, 차원, 구조적 하이퍼파라미터 같은 계산 구조를 규정하고, _Θ_ 는 그 구조에 붙는 학습 가능한 수치값이다. 그런데 CNNs에 대한 기존 공격은 모두 _A_ 가 알려져 있다고 가정하고 _Θ_ 만 복원한다. 논문은 이 가정이 비현실적이라고 지적한다. _A_ 는 현실적인 배포에서 공개하지 않는 가치 있는 자산이기 때문이다.

특히 fully connected networks(FCNs)의 경우 미지의 아키텍처 정보는 레이어 차원의 목록에 불과하고 그 복원은 이미 해결되어 있다 [4,11,19,20]. 반면 CNN은 local receptive field와 weight sharing을 이용해 훨씬 적은 파라미터로 이미지 데이터를 처리하므로 아키텍처가 더 풍부하다. 레이어 종류, kernel size, stride, padding mode, 채널 수, pooling 구조로 구성되는데, 각 항목은 네트워크 성능에 영향을 주는 비학습 파라미터이면서 동시에 모델 제공자의 자산이다. 다양성과 복잡성 때문에 CNN의 아키텍처 지식은 공격자에게 더 가치가 크고 얻기도 더 어렵다.

## 연구 분야 흐름

모델 추출에 관한 최초 연구는 1991년으로 거슬러 올라가며 [2], functionally equivalent extraction은 2016년 logistic regression 모델에 대해 [22], 2020년 은닉층 1~2개를 가진 ReLU FCNs에 대해 달성되었다 [14,19]. Crypto 2020에서 Carlini 등은 모델 추출이 위장된 암호해독 문제라고 주장하며 [6], 임의 개수의 은닉층을 가진 ReLU FCNs에 적용되고 functionally equivalent extraction을 달성하는 differential extraction attack을 제안했다. 이 연구가 신경망의 암호해독적 추출이라는 방향을 공식적으로 열었다.

이후 암호학 커뮤니티는 FCNs를 두 가지 피드백 설정에서 연구해 왔다. (1) raw-output setting: 공격자가 완전한 logit 벡터 _F<sub>A,Θ</sub>_(_x_)를 받는다. (2) hard-label setting: 공격자가 예측 레이블 _z_(_x_) = arg max<sub>_i_</sub> _F<sub>A,Θ</sub>_(_x_)<sub>_i_</sub>만 받는다. raw-output 설정에서는 공격이 다항 시간으로 만들어지고 [17], 실제로 더 빠르게 동작하게 되었으며 [12], 종단간 방식으로 깊은 네트워크까지 확장되고 [16], PReLU 등 다른 활성화 함수로 적응되었으며 [1,8,18], 유한 정밀도 평가 하에서 검토되었다 [23]. hard-label 설정에서는 암호해독적 추출이 처음 시도되고 [7], 다항 시간화되었으며 [4,5], 일부 더 깊은 레이어의 추출로 확장되고 [3], 질의 복잡도 관점에서 재검토되었다 [13].

CNNs는 컴퓨터 비전과 이미지 인식의 주류 모델이며, 암호해독적 추출을 FCNs에서 CNNs로 확장하는 것이 최근의 중요한 흐름이다.

## 관련 연구

raw-output 설정에서 Chen 등은 max-pooling CNNs에 대한 최초의 대수적 처리를 제시하고 convolution 파라미터를 복원하기 위해 세 종류의 점(point)을 정의했다 [9]. Liu 등은 receptive-field 분석을 사용해 더 깊은 VGG 계열 CNNs를 레이어 단위로 추출했다 [15]. hard-label 설정에서 Sun 등은 합성곱 레이어를 block-Toeplitz matrix로 재구성하여 average-pooling CNNs를 다루었고 [21], Chen 등은 approximate signature vector 방법과 kernel-centric clustering으로 max-pooling CNNs의 추출을 가속했다 [10].

EUROCRYPT 2024에서 Canales-Martínez 등은 Definition 3의 프레임워크가 수정 없이 CNNs에도 작동한다고 밝혔다 [17]. 각 convolution kernel 배치가 하나의 convolution neuron으로 간주되고, 그 가중치 벡터는 해당 LRF-C 위에서만 0이 아니다. 한편 Sun 등 [21]은 convolution matrix를 기반으로 average pooling을 갖는 ReLU CNNs에 파라미터 추출 프레임워크를 적용했으나, Chen 등 [9]은 max pooling을 갖는 CNNs에는 이 프레임워크가 직접 적용되지 않는다고 지적했다. LRF-P 내 최댓값 선택이 추가적인 비선형성을 도입하기 때문이다. 이에 선행 연구는 ReLU 활성화와 max-pooling 선택을 함께 고려하여 critical point [9]와 dual point [10]를 확장했다.

FCNs 쪽에서는 레이어 폭을 파라미터와 함께 복원하는 아키텍처 복원 결과가 이미 확립되어 있다 [4,11,19,20]. 논문의 공격은 이를 보완하여, CNN의 합성곱 레이어 아키텍처가 복원된 가중치 벡터의 공간적 기하 구조에 직접 드러난다는 점을 보인다. 두 경로가 각각 fully connected 레이어와 합성곱 레이어를 담당하여, 함께 CNNs의 암호해독적 추출에서 아키텍처 사전 지식을 제거한다.

## 배경 지식

### 네트워크와 아키텍처 정의

(_m_ + _n_)-deep CNN은 사상 _F<sub>A,Θ</sub>_ : ℝ<sup>_d_<sub>0</sub></sup> → ℝ<sup>_d_<sub>_n_+1</sub></sup>로, 합성곱 레이어 다음에 fully connected 레이어가 오는 구조이다. 합성곱 레이어 _l_ (1 ≤ _l_ ≤ _m_)에서 _f_<sub>c</sub><sup>(_l_)</sup>, _σ_<sub>c</sub><sup>(_l_)</sup>, _ρ_<sup>(_l_)</sup>는 각각 convolution, ReLU 활성화, pooling 연산을 나타내고, fully connected 레이어 _l_ (1 ≤ _l_ ≤ _n_)에서 _f_<sup>(_l_)</sup>와 _σ_<sup>(_l_)</sup>는 affine 변환과 ReLU 활성화를, 최종 출력 레이어는 affine 변환 _f_<sup>(_n_+1)</sup>를 나타낸다.

모델 아키텍처 _A_ 는 레이어 종류, 차원, 구조적 하이퍼파라미터의 순서열이다. 대상 레이어 인덱스를 _L_ 이라 할 때, _τ_<sup>(_L_)</sup> ∈ {Conv, FC}가 레이어 종류이고, Conv인 경우 kernel size _k_<sup>(_L_)</sup>, convolution stride _s_<sub>_k_</sub><sup>(_L_)</sup>, padding mode _π_<sup>(_L_)</sup> ∈ {Valid, Same}, 출력 채널 수 _C_<sub>out</sub><sup>(_L_)</sup>, pooling 종류 _ρ_<sup>(_L_)</sup> ∈ {NoPool, AvgPool, MaxPool}을 포함하며, pooling이 있으면 pooling window size _p_<sup>(_L_)</sup>와 pooling stride _s_<sub>_p_</sub><sup>(_L_)</sup>도 포함한다. FC인 경우 해당 레이어의 뉴런 수 _d_<sub>fc</sub><sup>(_L_)</sup>가 된다.

### Convolution matrix와 두 종류의 receptive field

convolution을 행렬 연산으로 쓰기 위해 입력 텐서 _IN_<sup>(_L_)</sup>를 1차원 공간으로 평탄화하고, padding mode에 따라 각 공간 차원을 양쪽으로 _t_<sub>pad</sub><sup>(_L_)</sup>개의 0으로 확장한다. 이렇게 얻은 convolution matrix _A_<sup>(_L_)</sup>의 각 행은 같은 kernel을 이동시킨 복사본이며, 0이 아닌 성분은 해당 LRF-C(Local Receptive Field of Convolutional Layer) 위에만 놓인다. LRF-C는 출력 성분 하나를 만들기 위해 kernel _K_<sup>(_L_)</sup>와 곱해지는 _IN_<sup>(_L_)</sup>의 부분행렬이고, LRF-P(Local Receptive Field of Pooling Layer)는 pooling이 처리하여 다음 레이어 입력 성분 하나를 만드는 부분행렬이다.

### 파라미터 추출 프레임워크와 점의 종류

파라미터는 레이어 단위로 복원된다 [6]. 점 _x_ 의 충분히 작은 선형 근방에서 대상 레이어를 _F<sub>A,Θ</sub>_(_x_) = _G_<sub>_x_</sub><sup>(_L_+1)</sup>(_A_<sup>(_L_)</sup>_F_<sub>_x_</sub><sup>(_L_−1)</sup>(_x_) + _B_<sup>(_L_)</sup>)로 분리하고, neuron signature recovery(점 수집, 방정식 풀이, 클러스터링과 정렬, 병합)와 neuron sign recovery의 두 단계로 분해한다.

CNN에는 세 종류의 critical point가 있다 [9]. ReLU-pooling critical point(RPCP)는 합성곱 레이어 _L_ 에서 _i_ 번째 ReLU의 입력, 즉 convolution response가 0이 되는 입력이며, max pooling이 있으면 이 response가 자신의 LRF-P에서 최댓값이어야 한다. pooling switching point(PSP)는 한 LRF-P 안의 두 response가 최댓값을 두고 동률이 되는 입력이다. fully connected critical point(FCP)는 fully connected 레이어 _L_ 에서 _i_ 번째 ReLU의 입력이 0이 되는 입력이다. hard-label 설정에서는 두 최대 logit이 일치하는 decision-boundary point와 critical point를 겸하는 dual point가 쓰이며, dual RPCP, dual PSP, dual FCP로 나뉜다 [10].

각 critical point 또는 dual point _x_ 에 대해 공격자는 작은 섭동 _δ_⃗를 표집하여 _H_(_x_; _δ_⃗) = _F<sub>A,Θ</sub>_(_x_ + _δ_⃗) + _F<sub>A,Θ</sub>_(_x_ − _δ_⃗) − 2_F<sub>A,Θ</sub>_(_x_)를 계산하고, 이들이 이루는 선형 시스템을 풀어 복원 벡터 _v_<sub>_x_</sub>를 얻는다 [6]. Lemma 1에 따르면 _v_<sub>_x_</sub>는 (dual) RPCP에서는 convolution matrix의 한 행을 _K_<sub>_i_</sub><sup>(_L_)</sup>로 제한한 것에 0이 아닌 스칼라 _g_<sub>_x_</sub>를 곱한 형태이고, (dual) PSP에서는 두 행의 차를 _K_<sub>_i_</sub><sup>(_L_)</sup> ∪ _K_<sub>_j_</sub><sup>(_L_)</sup>로 제한한 것, (dual) FCP에서는 한 행 전체가 된다. 즉 critical point와 dual point가 같은 복원 벡터를 주므로, 이후 논의는 critical point를 예로 삼는다.

### 복원 벡터의 공간적 보조 개념

논문은 복원 벡터의 유효 위치 집합 _S_<sub>_x_</sub> = {_i_ ∈ _I_<sup>(_L_)</sup> : (_v_<sub>_x_</sub>)<sub>_i_</sub> ≠ 0}과 convolution matrix 행의 유효 위치 집합 _W_<sub>_i_</sub><sup>(_L_)</sup>를 정의한다. Proposition 1에 따라 _S_<sub>_x_</sub>는 RPCP에서 _W_<sub>_i_</sub><sup>(_L_)</sup>, PSP에서 _W_<sub>_i_</sub><sup>(_L_)</sup> ∪ _W_<sub>_j_</sub><sup>(_L_)</sup>, FCP에서 _I_<sup>(_L_)</sup>와 같고, Proposition 2는 같은 LRF-C(또는 같은 LRF-C 쌍)에 속한 점들의 복원 벡터가 서로 비례한다는 사실을 준다. Proposition 3은 모든 입력 채널 슬라이스가 동일한 유효 위치 집합을 가지므로 다중 입력 채널이 공간적 희소 패턴에 영향을 주지 않음을 보이며, 이에 따라 이후 논의는 단일 입력 채널을 가정한다.

PSP는 두 LRF-C 시작점의 상대 위치에 따라 horizontal PSP(_r_<sub>1</sub> = _r_<sub>2</sub>), vertical PSP(_c_<sub>1</sub> = _c_<sub>2</sub>), off-axis PSP(두 공간 방향 모두에서 다름)로 분류된다. 또한 유효 위치를 모두 담는 최소 축정렬 상자 Box<sub>_x_</sub> = [_u_<sub>min</sub>, _u_<sub>max</sub>] × [_v_<sub>min</sub>, _v_<sub>max</sub>], 그 형상 Shape<sub>_x_</sub> = (_h_<sub>_x_</sub>, _w_<sub>_x_</sub>), 그리고 상자 내부의 이진 패턴 Mask<sub>_x_</sub> ∈ {0,1}<sup>_h_<sub>_x_</sub>×_w_<sub>_x_</sub></sup>가 정의된다. 이 세 가지가 아키텍처 복원의 관찰량이 된다.

## 문제 정의

CNN은 합성곱 레이어 뒤에 하나 또는 두 개의 fully connected 레이어가 오는 구조이고, fully connected 부분의 복원 방법은 이미 존재한다 [4,11,19,20]. 따라서 논문은 아직 미해결로 남아 있는 합성곱 레이어의 아키텍처 복원에 집중하며, 연구 질문을 "네트워크 아키텍처에 대한 지식 없이 CNN의 합성곱 레이어를 추출할 수 있는가"로 설정한다. 그 의의는 두 가지다. (1) fully connected 레이어에 대한 기존 방법과 합쳐 CNN 암호해독적 추출에서 아키텍처 사전 지식을 제거한다. (2) 아키텍처 복원을 파라미터 복원과 독립시켜, 기존 파라미터 복원 방법을 재사용하는 모듈형 프레임워크를 얻는다.

접근의 출발점은 기존 파라미터 복원 프레임워크의 첫 단계인 점 탐색(point search)과 방정식 풀이(equation solving)가 합성곱 아키텍처를 반영하는 관찰 정보를 담고 있는지 분석하는 것이다. 기존 방법들 [9,10,15,21]이 모두 이 단계를 공유하므로, 이 분석에 기반한 아키텍처 복원은 특정 방법에 의존하지 않는다.

공격자와 oracle에 대한 가정은 다음과 같다. full-domain input: 공격자는 임의의 입력 _x_ ∈ ℝ<sup>_d_<sub>0</sub></sup>를 질의할 수 있다. precise computation: 네트워크는 64비트 부동소수점 연산으로 규정되고 평가된다. ReLU activation: 모든 활성화 함수는 ReLU이다. 공격자는 입력 차원 _d_<sub>0</sub>과 출력 차원 _d_<sub>_n_+1</sub>만 알고 있으며, 은닉 레이어의 종류와 하이퍼파라미터는 모두 미지이며 복원 대상이다.

아키텍처 복원 목표는 Table 1의 과제로 분해된다. Task 1은 대상 레이어가 convolutional인지 fully connected인지 식별하여 _τ_<sup>(_L_)</sup>를 얻는 것(§5), Task 2와 3은 kernel size와 convolution stride 복원(§6), Task 4와 5는 padding mode와 출력 채널 수 복원(§7), Task 6은 pooling 종류와 window size, stride 복원(§8)이며, Task 7은 fully connected 레이어의 폭 복원으로 기존 방법 [4,11,19,20]에 맡긴다. Task 1 이후 공격은 합성곱 분기(Task 2~6)나 fully connected 분기(Task 7) 중 하나를 따른다.

## 주요 기여

### 복원 벡터의 형식적 공간 표현

논문은 파라미터 복원 프레임워크의 첫 단계인 점 탐색과 방정식 풀이 위에서 복원 벡터의 공간 구조에 대한 형식적 표현을 제시한다(Section 3). 이 표현은 복원 벡터에서 직접 읽어내므로 피드백 설정과 무관하다. 핵심 관찰은 복원된 벡터들의 공간 구조가 convolution과 pooling에 관련된 모든 하이퍼파라미터를 포함해 CNN 아키텍처를 직접 드러낸다는 것이다. 저자들이 밝히는 바로는 이것이 CNNs에 대한 최초의 아키텍처 복원 방법이다.

### Feedback-agnostic하고 모듈형인 아키텍처 복원

공격은 복원 벡터만 사용하며, 이 벡터는 raw-output 설정과 hard-label 설정 모두에서 모든 파라미터 복원 파이프라인의 첫 단계인 점 탐색과 방정식 풀이가 이미 생산하는 산출물이다. raw-output 설정에서 탐색되는 critical point와 hard-label 설정에서 탐색되는 dual point가 동일한 복원 벡터를 주기 때문이다. 따라서 공격은 CNNs를 대상으로 하는 어떤 기존 파라미터 복원 공격과도 조합되며, 각 레이어의 아키텍처를 그 파라미터보다 먼저 복원하는 완전한 암호해독적 추출 프레임워크를 산출한다(Figure 3).

복원의 핵심 아이디어는 convolution kernel, convolution matrix, 복원 벡터 사이의 기하적·수치적 관계를 활용하는 것이다. 합성곱 레이어와 fully connected 레이어는 생성하는 점의 종류가 다르므로, RPCP와 PSP의 존재는 대상 레이어가 convolutional임을 판정하는 충분 조건이다. RPCP의 복원 벡터는 _S_<sub>_x_</sub> = _W_<sub>_i_</sub><sup>(_L_)</sup>가 크기 _k_<sup>(_L_)</sup> × _k_<sup>(_L_)</sup>의 단일 LRF-C이므로 Box의 형상이 kernel size를 드러내고, 그러한 점들의 Box 시작점 사이 오프셋은 stride _s_<sub>_k_</sub><sup>(_L_)</sup>의 정수배이므로 충분히 조밀한 표집이 stride를 복원한다. Same padding은 입력 주위에 0을 덧붙여 유효 입력 공간을 넓히므로 경계의 LRF-C가 padding 영역으로 뻗고 경계 복원 벡터의 유효 위치 집합이 줄어 Box가 잘리는데, Valid padding에는 그런 영역이 없어 Box가 잘리지 않으며 이 경계 Box의 차이가 두 padding mode를 구분한다. PSP는 max-pooling 선택의 전환에서 비롯하므로 max pooling의 사용을 지시하고, max-pooling 파라미터는 convolution kernel 파라미터와 같은 아이디어로 복원된다. average pooling은 LRF-P의 모든 값을 _p_ × _p_ 창 위로 고르게 퍼뜨리므로 복원 벡터의 각 계수가 그 창에 균등히 퍼지고, 퍼짐의 범위가 _p_ 를 준다. 레이어 _L_ 에 pooling이 없으면 복원 벡터는 희소한 convolution 구조를 유지하므로 그런 반복 블록 패턴이 나타나지 않는다.

### 추가 질의 비용의 상수성

아키텍처 복원에 필요한 점의 개수는 식별 과제에 의해 결정되고 대상 레이어의 파라미터 개수에 의해 결정되지 않는다. 기존 CNN 파라미터 복원 프레임워크에서는 복원 벡터를 쌓아 출력 채널별 kernel을 구하는 선형 시스템을 풀어야 하므로, 출력 채널마다 PSP의 개수가 그 채널 kernel의 파라미터 수 (_k_<sup>(_L_)</sup>)<sup>2</sup>를 넘어야 한다. 반면 아키텍처 복원은 복원 벡터의 정성적 지표만 이용하고, 수치 비율이 단일 후보에 집중되는 최소 PSP 또는 RPCP 군집을 찾는 것으로 충분하다. 따라서 소수의 RPCP와 PSP만으로 모든 식별 과제가 수행되며, 추가 질의 비용은 (_k_<sup>(_L_)</sup>)<sup>2</sup>와 무관한 상수다.

### 실험적 검증

아키텍처 미지(architecture-unknown) 설정에서 시험한 모든 모델의 아키텍처가 두 피드백 설정과 두 upstream 모드 모두에서 정확히 복원되며, 추가 질의는 소수이고 실행 시간 증가도 미미하다. 다양한 아키텍처 하이퍼파라미터를 다룰 수 있음을 보이기 위해 아키텍처적으로 다양한 CNN을 추가로 설계하고, 그 아키텍처 복원의 완전한 증거를 과제별 시각화로 제시한다(Section 9). 완전한 실험 데이터와 소스 코드가 공개되었다.

## 제시한 방법론

### 공격 설정과 가정

논문은 합성곱 신경망(convolutional neural networks, CNNs)의 암호해독적 추출(cryptanalytic extraction)에서 기존 공격이 전제하던 구조 기지(architecture-known) 가정을 제거한다. 대상 모델은 $(m+n)$-deep CNN으로, 합성곱 층 뒤에 완전연결 층이 오는 순서를 가진다.

$$F_{A,\Theta} = f^{(n+1)}\circ\sigma^{(n)}\circ\cdots\circ\sigma^{(1)}\circ f^{(1)}\circ\rho^{(m)}\circ\sigma_c^{(m)}\circ f_c^{(m)}\circ\cdots\circ\rho^{(1)}\circ\sigma_c^{(1)}\circ f_c^{(1)}$$

여기서 $f_c^{(l)},\sigma_c^{(l)},\rho^{(l)}$는 각각 convolution, ReLU 활성, pooling이다. 복원 대상인 구조(architecture) $A$는

$$A^{(L)}=\begin{cases}(\tau^{(L)},k^{(L)},s_k^{(L)},\pi^{(L)},C_{\text{out}}^{(L)},\rho^{(L)},p^{(L)},s_p^{(L)}), & \tau^{(L)}=\texttt{Conv}\\ (\tau^{(L)},d_{\text{fc}}^{(L)}), & \tau^{(L)}=\texttt{FC}\end{cases}$$

로 정의되며, $\pi^{(L)}\in\{\texttt{Valid},\texttt{Same}\}$, $\rho^{(L)}\in\{\texttt{NoPool},\texttt{AvgPool},\texttt{MaxPool}\}$이다. 가정은 세 가지다: 공격자가 임의의 입력 $x\in\mathbb{R}^{d_0}$를 질의할 수 있는 전영역 입력(full-domain input), 64비트 부동소수점으로 지정·평가되는 정밀 계산(precise computation), 모든 활성 함수가 ReLU라는 점. 공격자는 $d_0$와 $d_{n+1}$만 알고 은닉 층의 유형과 하이퍼파라미터는 모른다.

### 복원 벡터(recovered vector)와 그 공간 기하

방법론의 토대는 기존 parameter extraction framework의 첫 단계, 즉 점 탐색(point search)과 방정식 풀이(equation solving)가 산출하는 복원 벡터다. 임계점(critical point) 또는 dual point $x$에 대해 공격자는 작은 교란 $\vec\delta$를 표본추출하여 $H(x;\vec\delta)=F_{A,\Theta}(x+\vec\delta)+F_{A,\Theta}(x-\vec\delta)-2F_{A,\Theta}(x)$를 계산하고, 이들이 이루는 선형 시스템을 풀어 $v_x$를 얻는다. Lemma 1에 따라 0이 아닌 스칼라 $g_x$가 존재하여

$$v_x=\begin{cases}g_x A^{(L)}_{m,i}[\mathcal{K}_i^{(L)}], & x \text{가 (dual) RPCP}\\ g_x\big(A^{(L)}_{m,i}-A^{(L)}_{m,j}\big)[\mathcal{K}_i^{(L)}\cup\mathcal{K}_j^{(L)}], & x \text{가 (dual) PSP}\\ g_x A^{(L)}_i, & x \text{가 (dual) FCP}\end{cases}$$

가 성립한다. 점의 유형은 ReLU-pooling critical point(RPCP, 대상 층 ReLU 입력이 0이 되고 max pooling에서 해당 convolution response가 자기 LRF-P의 최댓값인 점), pooling switching point(PSP, 한 LRF-P 안의 두 response가 최댓값을 두고 동률이 되는 점), fully connected critical point(FCP)로 구분된다. 하드라벨 설정에서는 이들이 decision-boundary point와 결합한 dual RPCP/PSP/FCP가 되지만, **critical point와 dual point는 동일한 복원 벡터를 주므로** 구조 복원은 피드백에 무관(feedback-agnostic)해진다. 이것이 설계의 핵심 근거이며, 덕분에 raw-output 공격[9]과 hard-label 공격[10] 어디에도 모듈식으로 접속한다.

복원 벡터는 convolution matrix(Definition 4)의 한 행이거나 두 행의 차이이고, 각 행은 자신의 LRF-C 위에서만 비영(非零)이다. 이를 형식화하기 위해 유효 위치 집합 $S_x=\{i\in\mathcal{I}^{(L)}:(v_x)_i\neq 0\}$와 행의 유효 위치 집합 $\mathcal{W}_i^{(L)}=(\phi^{(L)})^{-1}\big(\{j\in\widetilde{\mathcal I}^{(L)}:(A^{(L)}_{m,i})_j\neq0\}\cap\mathcal{K}_i^{(L)}\big)$를 도입한다. Proposition 1은 $S_x=\mathcal{W}_i^{(L)}$(RPCP), $\mathcal{W}_i^{(L)}\cup\mathcal{W}_j^{(L)}$(PSP), $\mathcal{I}^{(L)}$(FCP)임을 보이고, Proposition 2는 같은 LRF-C에 속한 점들의 복원 벡터가 비례한다는 것, Proposition 3은 모든 입력 채널 슬라이스 $S_x^{[q]}$가 동일하다는 것(따라서 단일 입력 채널로 논의를 환원할 수 있음)을 보인다. 추가로 PSP를 두 LRF-C 시작점 $(r_1,c_1),(r_2,c_2)$의 상대 위치에 따라 horizontal/vertical/off-axis로 분류하고, 유효 위치를 감싸는 최소 축정렬 상자 $\text{Box}_x=[u_{\min},u_{\max}]\times[v_{\min},v_{\max}]$, 그 형상 $\text{Shape}_x=(h_x,w_x)$, 이진 패턴 $\text{Mask}_x\in\{0,1\}^{h_x\times w_x}$를 정의한다.

### 과제 분해와 각 단계의 알고리즘

구조 복원은 Table 1의 과제로 분해된다: (1) 층 유형, (2) kernel size $k$, (3) convolution stride $s_k$, (4) padding mode $\pi$, (5) output-channel 수 $C_{\text{out}}$, (6) pooling type $\rho$·window size $p$·stride $s_p$, (7) FC 층 폭 $d_{\text{fc}}$(기존 방법 [4,11,19,20] 사용). 층 유형 판별 후 합성곱 분기(2–6)와 완전연결 분기(7)로 갈린다.

**Task 1(층 유형).** Lemma 2는 대상 층 또는 더 깊은 층에서 RPCP나 PSP가 존재하면 $\tau^{(L)}=\texttt{Conv}$임을 보인다. 모든 합성곱 층이 완전연결 층보다 앞에 오므로, $L$이 FC라면 $P^{(L)}=P^{(L)}_{\text{FCP}}\cup\bigcup_{L'>L}P^{(L')}_{\text{FCP}}$가 되어 RPCP/PSP가 나올 수 없기 때문이다. Corollary 1–3은 대상 층 RPCP의 $\text{Shape}_x=(k^{(L)},k^{(L)})$, $\text{Mask}_x=\mathbf{1}_{k^{(L)}\times k^{(L)}}$, 대상 층 PSP의 $\text{Shape}_x=(|r_2-r_1|+k^{(L)},|c_2-c_1|+k^{(L)})$, FCP의 $S_x=\mathcal{I}^{(L)}$, $\text{Shape}_x=(H^{(L)},W^{(L)})$를 준다. Proposition 4·5는 더 깊은 층에서 온 점의 $\psi^{(L)}(S_x)=\bigcup_{m\in M_x}[r_m,r_m+k^{(L)}-1]\times[c_m,c_m+k^{(L)}-1]$, 즉 LRF-C들의 합집합임을 층 거리에 대한 재귀로 증명한다. 따라서 $P_{\text{full}}=\{x\in P^{(L)}:\text{Shape}_x=(H^{(L)},W^{(L)})\}$, $P_{\text{conv}}=P^{(L)}\setminus P_{\text{full}}$로 두고 $P_{\text{conv}}\neq\emptyset$이면 $\widetilde\tau^{(L)}=\texttt{Conv}$로 판정한다.

**Task 2–3(kernel size와 stride).** `Same` padding의 경계 효과를 배제하기 위해 내부 집합 $\widetilde{P}^{\circ}_{\text{conv}}=\{x\in P_{\text{conv}}:\text{Box}_x\subseteq\{1,\dots,H^{(L)}-2\}\times\{1,\dots,W^{(L)}-2\}\}$를 정의한다. Lemma 3은 $k^{(L)}=h_x=w_x$(RPCP), $b_\partial(\text{Mask}_x)=\min\{h_x,w_x\}$(horizontal/vertical PSP), $b_\partial(\text{Mask}_x)$(off-axis PSP)임을 준다($b_\partial$는 $\text{Mask}_x$ 경계의 최단 연속 비영 구간 길이). 대상 층 RPCP를 걸러내는 필터는 두 가지다: $\text{Mask}_x=\mathbf{1}_{k'\times k'}$를 요구해 정사각 off-axis PSP를 제거하고, 더 깊은 층 점은 중간 층들의 ReLU 활성 배치가 동일할 때만 같은 $v_x$를 내므로(즉 $L$과 $L'$ 사이 pooling이 max pooling이 아닐 때만) RPCP가 둘 이상이면 올바른 $P^{\circ}_{\text{RPCP}}$를 남긴다. PSP 식별에는 Proposition 6의 경계–커널 대응(예: horizontal PSP에서 $v_x(B_{x,\text{left}})=\pm g_x K^{(L)}_{:,0}$, $v_x(B_{x,\text{right}})=\pm g_x K^{(L)}_{:,k^{(L)}-1}$)을 쓰되, 미지의 $\pm g_x$를 소거하기 위해 두 항목의 비를 취한다.

$$\frac{v_{x_1}(\min S_{x_1})}{v_{x_1}(\max S_{x_1})}=\frac{v_{x_2}(\min S_{x_2})}{v_{x_2}(\max S_{x_2})}=\frac{\big(K^{(L)}\big)_{0,0}}{\big(K^{(L)}\big)_{k^{(L)}-1,k^{(L)}-1}}$$

이 비는 $x$에 무관한 불변량이므로 커널 사전 지식 없이 복원 벡터만으로 평가할 수 있고, 같은 커널을 공유하는 PSP를 묶는 군집 기준이 된다. 겹침 영역은 이동된 커널 사본의 차이가 나타나므로 비 계산에서 제외하고 비겹침 영역만 사용한다. $P^{\circ}_{\text{RPCP}}=\emptyset$일 때는 PSP 투표 $V(k')=\sum_{x\in\widetilde P^{\circ}_{\text{PSP}}}[\,b_\partial(\text{Mask}_x)=k'\,]$로 $\widetilde k=\arg\max_{k'}V(k')$를 정한다. stride는 Lemma 4($r_{x_1}-r_{x_2}\in s_k^{(L)}\mathbb{Z}$, $c_{x_1}-c_{x_2}\in s_k^{(L)}\mathbb{Z}$)에 근거해, 시작점 집합 $\mathcal S_{\text{conv}}$의 비영 행·열 차이 집합 $\Delta_{\text{conv}}$를 모아 $\widetilde{s}_k=\min\Delta_{\text{conv}}$로 복원한다.

**Task 4–5(padding mode와 output-channel 수).** Lemma 5는 LRF-C가 zero-padding 영역과 교차하는 절단점(truncated point)이 존재하면 $\pi^{(L)}=\texttt{Same}$임을 준다(`Valid`에는 padding 영역이 없다). 경계 후보 $\widetilde P_\partial=P_{\text{conv}}\setminus\widetilde P^{\circ}_{\text{conv}}$에서, Proposition 7의 조건 — 좌측 절단점은 $v_x(B_{x,\text{right}})=\pm g_x K^{(L)}_{:,k^{(L)}-1}$을 만족하되 좌측 경계는 첫 커널 열과 일치하지 않음 — 을 수치 템플릿 점(우선 $P^{\circ}_{\text{RPCP}}$의 RPCP, 없으면 horizontal 또는 off-axis PSP)과 대조해 네 경계의 $P_{\partial,\text{left}},P_{\partial,\text{right}},P_{\partial,\text{top}},P_{\partial,\text{bottom}}$을 얻는다. $P_\partial\neq\emptyset$이면 $\texttt{Same}$, 아니면 $\texttt{Valid}$다. 이어 $P^{\circ}_{\text{RPCP}}$는 Proposition 2로, $P^{\circ}_{\text{PSP}}$는 복원된 $\widetilde k,\widetilde s_k$로 PSP 유형을 분류한 뒤 Proposition 6으로, $P_\partial$의 네 부분집합은 각각 별도로 군집화하고, 마지막에 비겹침 영역에 노출된 커널 값으로 군집들을 병합한다. 병합된 클래스 수가 $\widetilde C_{\text{out}}$이다.

**Task 6(pooling 구조).** PSP는 max pooling이 도입하는 추가 비선형성에서만 생기므로 $P^{\circ}_{\text{PSP}}\neq\emptyset$이거나 $P_\partial$에 PSP가 있으면 $\widetilde\rho=\texttt{MaxPool}$이다. 이때 Proposition 8은 한 PSP의 두 LRF-C 시작점 간 오프셋이 $|r_x-r'_x|=a\,s_k^{(L)}$, $|c_x-c'_x|=a\,s_k^{(L)}$, $a\in\{0,\dots,p-1\}$임을 보이므로(두 response가 같은 pooling window 안에 있어 오프셋이 최대 $p-1$ stride), 값 집합 $D$에서 $\widetilde p=(\max D)/s_k^{(L)}+1$을 얻는다. 최대 오프셋을 달성하는 점 집합 $P^{r}_{\max},P^{c}_{\max}$의 좌표 $\mathcal R_{\max},\mathcal V_{\max}$에 대해 Proposition 9가 $r_{x_1}-r_{x_2}\in s_p s_k^{(L)}\mathbb{Z}$를 보장하므로, stride 단위로 정규화한 차이 집합 $\Delta=\{|r-r'|/\widetilde s_k\}\cup\{|c-c'|/\widetilde s_k\}$에서 $\widetilde s_p=\min\Delta$를 얻는다(인접 pooling window 앵커 두 개가 포함된 경우).

max pooling이 배제되면 남은 $\texttt{NoPool}$과 $\texttt{AvgPool}$은 모두 선형이어서 완전연결 관점의 pooling 행렬이 고정된다($\texttt{NoPool}$은 $P^{(L)}=I$, $\texttt{AvgPool}$은 각 행이 하나의 LRF-P 위에서 상수 $1/p^2$). 이에 대해 **skip-and-determine** 전략을 쓴다: 층 $L$의 pooling을 건너뛰고 층 $L+1$의 복원 벡터로 판별한다. $\overleftarrow{v}^{(L+1)}_x=v^{(L+1)}_x P^{(L)}$이고 pooled 좌표 $i$의 평탄화된 LRF-P는

$$\mathcal{K}^P_i=\Big\{\big(\lfloor i/w_\rho^{(L)}\rfloor s_p+j\big)w_o^{(L)}+\big(i \bmod w_\rho^{(L)}\big)s_p+m \;:\; 0\le j<p,\;0\le m<p\Big\}$$

이다. 복원 벡터 $\overleftarrow{v}^{(L+1)}_x$를 $\big(\overleftarrow{v}^{(L+1)}_x\big)_r=p^2\sum_{i':\,r\in\mathcal K^P_{i'}}\big(v^{(L+1)}_x\big)_{i'}$로 되돌리면 Proposition 10이 성립한다: (1) $\bigcup_{i'\in S^{(L+1)}_x}\mathcal K^P_{i'}$ 밖에서는 0이고, (2) $s_p\ge p$면 각 $\mathcal K^P_i$ 위에서 값 $p^2(v^{(L+1)}_x)_i$로 상수이며 연속 구간은 길이 $g=s_p-p$의 0으로 분리되고, (3) $s_p<p$면 길이 $\ell=s_p$의 배타 구간에서 $p^2(v^{(L+1)}_x)_i$를 갖고 겹친 위치는 인접 복원값들의 합을 갖는다. 따라서 항목 수열에서 상수 구간 길이 $\ell$, 0-간격 $g$, 겹침 길이 $o$를 읽어 Corollary 4로

$$(p,s_p)=\begin{cases}(\ell,\ell), & s_p=p\\ (\ell,\ell+g), & s_p>p\\ (\ell+o,\ell), & s_p<p\end{cases}$$

를 확정한다. 반복 상수 블록 패턴이 없으면 $P^{(L)}=I$이고 희소한 convolution 구조가 유지되므로 $\texttt{NoPool}$로 판정한다.

### 복잡도와 설계 근거

구조 복원에 필요한 점의 수는 대상 층의 파라미터 개수가 아니라 식별 과제가 결정한다. 기존 파라미터 복원은 출력 채널마다 PSP 수가 커널 파라미터 수 $(k^{(L)})^2$를 넘어야 하지만, 구조 복원은 복원 벡터의 정성적 서명만 이용하므로 수치 비가 하나의 후보로 집중되는 최소 군집만 찾으면 충분하다. 즉 추가 질의 비용은 $(k^{(L)})^2$에 무관한 상수이며, 점 탐색과 방정식 풀이를 파라미터 복원과 공유하므로 구조 복원이 소비하는 질의는 파라미터 복원 질의의 부분집합이 된다. 전체 프레임워크는 층별로 "구조 먼저, 파라미터 다음" 순서로 동작하여 기존 CNN 파라미터 복원 공격을 그대로 재사용하는 모듈식 구성을 이룬다.

## 실험 및 평가

### 실험 설정
모든 실험은 2.10 GHz의 Intel Xeon Gold 5318Y CPU 2개와 503 GB 메모리를 갖춘 서버에서 수행되었다. 평가는 제안된 아키텍처 복원(architecture recovery) 공격을 기존 CNN 파라미터 복원(parameter recovery) 공격과 결합하는 방식으로 진행되었으며, raw-output 설정에서는 [9]의 공격을, hard-label 설정에서는 [10]의 공격을 상위(upstream) 모듈로 사용하였다. 또한 layer-by-layer 파이프라인과 end-to-end 파이프라인 두 가지 모드를 모두 적용하여, 공격이 피드백 방식과 파이프라인 방식 모두에 대해 독립적임(feedback-agnostic)을 확인하였다.

### 대상 모델(데이터셋·베이스라인)
요약 실험의 대상 모델은 기존 CNN 공격 [9, 10]이 채택한 두 모델, 즉 (2 + 1) CNN과 LeNet-5 변형인 (2 + 2) CNN이다. 두 모델 모두 합성곱 층 2개를 쓰고 5 × 5 kernel, stride 1, Valid padding, 2 × 2 max pooling을 사용하며, 차이는 출력 채널 수(output-channel number)뿐이다. 즉 베이스라인은 아키텍처를 이미 알고 있다고 가정하는 기존 파라미터 복원 공격이고, 비교 기준은 아키텍처를 모르는 상태에서도 동일한 복원 결과에 도달하는지 여부다.

시각화 실험에서는 다양한 하이퍼파라미터를 다룰 수 있음을 보이기 위해 저자들이 직접 설계한 (3 + 1) CNN을 사용하였다. 이 모델은 32 × 32로 크기를 조정한 MNIST 학습 집합으로 학습되어 학습 정확도 94.03%, 테스트 정확도 89.30%를 기록하였다. 정답 아키텍처는 층 1이 kernel 3, stride 1, Same, 출력 채널 1, NoPool이고, 층 2가 kernel 5, stride 1, Same, 출력 채널 2, AvgPool (2, 2)이며, 층 3이 kernel 3, stride 2, Valid, 출력 채널 3, MaxPool (3, 2)이고, 그 뒤에 폭 18의 FC 층과 출력 10의 층이 이어진다.

### 평가 지표와 주요 결과
평가 지표는 각 층 아키텍처의 정확한 복원 여부, 후속 파라미터 복원 정확도, 그리고 추가로 소모되는 질의 수와 실행 시간이다. 결과적으로 시험된 모든 모델에서, 두 피드백 설정과 두 상위 모드 모두에서 각 층의 아키텍처가 정확히 복원되었고, 이어지는 파라미터 복원은 원래 공격과 동일한 정확도를 달성하였다. 복잡도 측면에서 아키텍처 복원의 유일한 비용은 point search와 equation solving이 이미 생성해 둔 recovered vector를 분석하는 시간이다. 두 단계가 이 과정을 공유하므로 아키텍처 복원이 소비하는 질의는 파라미터 복원이 소비하는 질의의 부분집합이며, 원문은 raw-output 설정의 (2 + 1) CNN에 대해 전체 파라미터 복원의 질의 수·소요 시간과 그중 아키텍처 복원 단계가 차지하는 질의 수·소요 시간을 2의 거듭제곱 형태로 함께 보고한다. 즉 아키텍처 사전 지식 없이도 추가 질의와 실행 시간이 소폭 증가하는 수준에 머문다.

### 과제별 복원 과정 검증
(3 + 1) CNN에 대해서는 raw-output 설정에서 층 단위로 아키텍처를 복원하였다. 점 수집과 방정식 풀이는 [9]의 공격을 그대로 쓰고 그 사이에 아키텍처 복원을 삽입하며, 균일성을 위해 각 층에서 탐색하는 critical point 수를 700개로 고정하였다. 과제별 증거는 다음과 같다.

- Task 1(층 종류): 세 층 모두 _P_conv가 비어 있지 않아 Lemma 2에 의해 convolutional로 식별되었다.
- Task 2(kernel size): 경계 필터링과 RPCP 필터링을 통과한 점들의 투표가 단일 후보에 집중되어 층 1–3의 kernel size가 각각 3, 5, 3으로 복원되었다.
- Task 3(stride): 시작 위치 간 최소 차이가 각각 1, 1, 2로 나타나 Lemma 4에 따라 stride가 복원되었다.
- Task 4(padding mode): 층 1과 2에서는 네 경계 모두에서 truncated point가 나타났고 층 3에서는 전혀 나타나지 않아 Same, Same, Valid로 복원되었다.
- Task 5(출력 채널 수): RPCP·PSP 기록의 군집이 각각 1, 2, 3개로 형성되어 출력 채널 수가 복원되었다. 군집화는 안정적인 RPCP 비율 기록을 묶는 1단계, 군집 중심과 수치 비율이 일치하는 PSP를 더하는 2단계, 남은 PSP에 새 군집을 부여하는 3단계로 진행된다.
- Task 6(pooling 구조): 층 1의 restored vector에는 반복 블록이 없어 NoPool, 층 2에는 반복되는 상수 블록이 있어 AvgPool로 판정되고 Corollary 4로 window size와 stride가 결정된다. 층 3은 PSP의 존재로 MaxPool이 식별되고, anchor 위치 집합 _R_max와 _V_max에서 얻은 시작점으로부터 Proposition 8·9에 따라 window size와 stride가 도출된다. 최종적으로 NoPool, AvgPool (2, 2), MaxPool (3, 2)가 정답과 일치하게 복원되었다.

전체 실험 데이터와 소스 코드는 공개되었다고 밝히고 있으며, 모든 시험 모델의 상세 결과도 해당 저장소에서 제공된다.

## 고찰

### 문제 설정과 핵심 발견

이 논문은 합성곱 신경망(convolutional neural networks, CNNs)에 대한 암호해독적 추출(cryptanalytic extraction)을 다룬다. 기존 CNN 공격 [9,10,15,21]은 모두 아키텍처 _A_ 를 이미 안다고 가정하고 파라미터 _Θ_ 만 복원하는데, 실제 배포 환경에서 _A_ 는 공개되지 않는 자산이므로 이 가정은 비현실적이다. 저자들은 max pooling과 average pooling을 모두 포함하는 CNN에 대해 이 가정을 제거할 수 있음을 처음으로 보인다. 핵심 발견은 기존 파라미터 복원 공격이 산출하는 복원 벡터(recovered vector)의 공간적 기하 구조가 아키텍처를 그대로 누출한다는 것이다. 저자들은 이 기하 구조를 형식화하고 합성곱 층의 아키텍처 지식과 다음 세 가지 대응으로 연결한다. (1) 합성곱 수용영역(receptive field)과의 희소성 일치(sparsity consistency)는 층 종류·커널 크기·스트라이드를 드러내고, (2) 커널 파라미터와의 수치 일치(numerical consistency)는 패딩 모드와 출력 채널 수를 드러내며, (3) 풀링 연산과의 구조 일치(structural consistency)는 풀링 종류·윈도 크기·스트라이드를 드러낸다.

### 복원 벡터의 공간적 형식화

아키텍처는 _A_^(L) = ( _τ_, _k_, _s_k_, _π_, _C_out_, _ρ_, _p_, _s_p_ )(합성곱 층) 또는 ( _τ_, _d_fc_ )(fully connected 층)로 정의된다. 공격은 Carlini 등 [6]의 파라미터 추출 프레임워크를 전제로 하는데, 이 프레임워크의 첫 단계인 점 탐색(point search)과 방정식 풀이(equation solving)가 산출하는 복원 벡터만 사용한다. CNN에서 임계점(critical point)은 ReLU-pooling critical point(RPCP), pooling switching point(PSP), fully connected critical point(FCP) 세 종류이며, 하드 라벨 설정에서는 결정 경계 점이자 임계점인 이중점(dual point)이 같은 역할을 한다. Lemma 1에 따라 복원 벡터는 합성곱 행렬(convolution matrix)의 한 행(RPCP, FCP)이거나 두 행의 차(PSP)이고, 각 행은 자신의 LRF-C(Local Receptive Field of Convolutional Layer) 위에서만 0이 아니다. raw-output 설정의 임계점과 hard-label 설정의 이중점이 동일한 복원 벡터를 주기 때문에, 이 공격은 피드백 불특정(feedback-agnostic)이며 기존 어떤 파라미터 복원 공격과도 조합된다.

저자들은 유효 위치 집합 _S_x_, 합성곱 행렬 행의 유효 위치 집합 _W_i_^(L), 공간 경계 상자 Box_x_, 그 형상 Shape_x_, 이진 패턴 Mask_x_ 를 정의한다. Proposition 1은 _S_x_ 가 RPCP에서는 하나의 _W_i_^(L), PSP에서는 _W_i_^(L) ∪ _W_j_^(L), FCP에서는 전체 _I_^(L) 임을 보이고, Proposition 2는 같은 LRF-C에 속한 점들의 복원 벡터가 비례함을 보인다. Proposition 3은 입력 채널 블록마다 희소성 패턴이 동일함을 보여, 이후 논의를 단일 입력 채널로 단순화할 근거를 제공한다. PSP는 두 LRF-C 시작점의 상대 위치에 따라 horizontal, vertical, off-axis로 분류된다.

### 과제 분해와 복원 절차

Table 1은 아키텍처 복원을 일곱 과제로 분해한다. 과제 1(층 종류)은 Lemma 2로 해결되는데, 모든 합성곱 층이 fully connected 층보다 앞에 오므로 목표 층 또는 그보다 깊은 층에서 RPCP나 PSP가 관측되면 _τ_^(L) = Conv가 확정된다. 실무적으로는 Shape_x_ = ( _H_^(L), _W_^(L) )인 전체 상자 점 집합 _P_full_ 과 그 여집합 _P_conv_ 를 비교해, _P_conv_ 가 비지 않으면 합성곱 층으로 판정한다. 깊은 층에서 유래한 RPCP·PSP의 지지집합은 Proposition 4와 5에 의해 목표 층 LRF-C들의 합집합이 되어 Box가 커지므로 구분된다.

과제 2·3(커널 크기와 스트라이드)에서는 Same 패딩의 영향을 배제하기 위해 경계를 제외한 내부 점 집합을 정의한다. Lemma 3은 RPCP의 경우 _k_^(L) = _h_x_ = _w_x_, horizontal·vertical PSP는 Mask_x_ 경계상의 최단 연속 비영(非零) 구간 길이 _b_∂_(Mask_x_) = min{ _h_x_, _w_x_ }, off-axis PSP는 _b_∂_(Mask_x_) 임을 제시한다. Lemma 4는 임의의 두 내부 점의 Box 시작점 차가 _s_k_^(L) 의 정수배임을 보이므로, 시작점 차의 집합 _Δ_conv_ 의 최솟값이 스트라이드가 된다. 목표 층 점을 식별할 때는 Mask_x_ 가 전부 1인 정사각 패턴만 남기는 공간적 필터와, _g_x_ 가 상쇄되는 비율 불변량(Eq. (2))을 이용한 수치 군집화를 함께 쓴다. RPCP가 없을 때는 PSP들의 _b_∂_(Mask_x_) 투표 _V_( _k′_ )로 커널 크기를 결정한다.

과제 4·5에서는 Same 패딩이 경계 LRF-C를 영 패딩 영역으로 밀어내 복원 벡터를 절단(truncate)시킨다는 점을 쓴다. Lemma 5에 따라 절단 점이 존재하면 _π_^(L) = Same이고, 없으면 Valid이다. 절단 점은 Proposition 7의 두 수치 검증 조건으로 네 경계에서 각각 판별한다. 출력 채널 수는 남은 목표 층 점들을 RPCP(Proposition 2), PSP 유형별(Proposition 6), 경계별 절단 점 집합으로 각각 군집화한 뒤 비중첩 영역에 노출된 커널 값으로 병합하여, 병합된 군집 수로 _C_out_ 을 얻는다.

과제 6에서는 PSP의 존재 자체가 max pooling의 추가 비선형성에서 비롯되므로 MaxPool을 지시한다. Proposition 8은 PSP 두 LRF-C 시작점의 오프셋이 _a·s_k_^(L) ( _a_ ∈ {0,…, _p_ −1})임을 보여 _p_ = (max _D_ )/ _s_k_ + 1을 준다. Proposition 9는 풀링 윈도 앵커가 _s_p·s_k_^(L) 격자 위에 있음을 보여 _s_p_ = min _Δ_ 를 준다. MaxPool이 배제된 뒤에는 NoPool과 AvgPool이 모두 선형이므로, 층 _L_ 의 풀링을 건너뛰고 층 _L_ +1의 복원 벡터로 판정하는 skip-and-determine 전략을 쓴다. NoPool이면 _P_^(L) = _I_ 이고 희소한 합성곱 구조가 유지되며, AvgPool이면 각 계수가 _p × p_ 윈도 위에 1/ _p_² 로 퍼진다. Proposition 10은 _s_p_ ≥ _p_ 일 때 복원 벡터가 각 LRF-P 상에서 상수이고 구간 사이에 _g_ = _s_p_ − _p_ 개의 0이 놓이며, _s_p_ < _p_ 일 때는 배타 구간 길이가 _ℓ_ = _s_p_ 이고 중첩 위치는 인접 값의 합이 됨을 보인다. Corollary 4는 읽어낸 ( _ℓ_, _g_, _o_ )로부터 ( _p_, _s_p_ )를 _s_p_ = _p_, _s_p_ > _p_, _s_p_ < _p_ 세 경우로 환원한다.

복잡도 측면에서, 파라미터 복원은 출력 채널마다 ( _k_^(L) )² 개를 넘는 PSP를 요구하지만, 아키텍처 복원은 복원 벡터의 정성적 서명만 쓰기 때문에 수치 비율이 한 후보로 집중되는 최소 군집만 찾으면 된다. 따라서 추가 질의 비용은 ( _k_^(L) )² 와 무관한 상수이다.

### 실험 결과에 대한 논의

실험은 Intel Xeon Gold 5318Y 2.10 GHz CPU 두 개와 503 GB 메모리를 갖춘 서버에서 수행되었다. 저자들은 자신들의 아키텍처 복원을 기존 파라미터 복원 공격과 결합했는데, raw-output 설정에서는 [9]의 공격, hard-label 설정에서는 [10]의 공격을 쓰고, 층별(layer-by-layer) 파이프라인과 종단(end-to-end) 파이프라인을 모두 시험했다. 대상 모델은 기존 공격 [9,10]이 채택한 (2+1) CNN과 LeNet-5 변형인 (2+2) CNN이며, 두 모델 모두 5×5 커널, 스트라이드 1, Valid 패딩, 2×2 max pooling의 합성곱 층 두 개를 쓰고 출력 채널 수만 다르다. 시험한 모든 설정에서 각 층의 아키텍처가 정확히 복원되었고, 이후 파라미터 복원은 원래 공격과 동일한 정확도를 달성했다.

비용 측면에서, 아키텍처 복원의 유일한 추가 비용은 점 탐색과 방정식 풀이가 이미 산출한 복원 벡터를 분석하는 시간이며, 두 단계가 이 과정을 공유하므로 아키텍처 복원이 소비하는 질의는 파라미터 복원이 소비하는 질의의 부분집합이다. raw-output 설정의 (2+1) CNN에서 전체 파라미터 복원은 2^20.48 질의와 2^7.31 초를 요구하는데, 그중 아키텍처 복원 단계는 2^17.71 질의와 2^4.08 초를 차지한다. 즉 아키텍처가 미지인 설정에서도 질의 몇 개와 약간의 실행 시간만 추가된다.

다양한 하이퍼파라미터를 다룰 수 있음을 보이기 위해 저자들은 커널 크기, 스트라이드, 패딩 모드, 출력 채널 수, 풀링 연산이 모두 다른 (3+1) CNN을 따로 설계했다. 진짜 아키텍처(Table 2)는 층 1이 Conv, 커널 3, 스트라이드 1, Same, 채널 1, NoPool, 층 2가 Conv, 커널 5, 스트라이드 1, Same, 채널 2, AvgPool (2,2), 층 3이 Conv, 커널 3, 스트라이드 2, Valid, 채널 3, MaxPool (3,2), 층 4가 FC 18, 출력층 10이다. 이 모델은 32×32로 변환한 MNIST 학습 집합으로 훈련되어 학습 정확도 94.03%, 시험 정확도 89.30%를 얻었다. 복원은 raw-output 설정에서 층별로 수행되었고, 점 수집과 방정식 풀이는 [9]의 공격에서 가져오고 그 사이에 아키텍처 복원을 삽입했으며, 균일성을 위해 층마다 탐색하는 임계점 수를 700개로 고정했다.

과제별 결과는 다음과 같다. 과제 1에서는 세 층 모두 _P_conv_ 가 비지 않아 Lemma 2로 합성곱 층으로 식별되었다. 과제 2에서는 경계·RPCP 필터링을 통과한 점들의 정사각 Shape 투표가 단일 후보로 집중되어 커널 크기가 층 1–3에 대해 3, 5, 3으로 복원되었다. 과제 3에서는 내부 점 시작 위치의 최소 차가 1, 1, 2로 나타나 Lemma 4로 스트라이드가 복원되었다. 과제 4에서는 층 1과 2에서 네 경계 모두에 절단 점이 나타나고 층 3에서는 전혀 나타나지 않아 패딩 모드가 Same, Same, Valid로 복원되었다. 과제 5에서는 RPCP 비율 기록을 군집화한 뒤 비율이 일치하는 PSP를 더하고 남은 PSP로 새 군집을 만드는 3단계 절차를 거쳐 각 층의 기록이 1, 2, 3개 군집을 형성해 출력 채널 수가 복원되었다. 과제 6에서는 층 1의 복원 벡터에 반복 블록이 없어 NoPool, 층 2에 반복 상수 블록이 있어 AvgPool로 판정되고 Corollary 4로 (2,2)가 얻어졌으며, 층 3은 PSP 존재로 MaxPool이 판정되고 앵커 위치 _R_max_ 와 _V_max_ 로부터 Proposition 8·9를 통해 (3,2)가 얻어졌다. 모든 결과가 진짜 아키텍처와 일치했다. 저자들은 전체 실험 데이터와 소스 코드를 공개했다고 밝힌다.

### 한계와 전제

공격은 세 가지 전제에 의존한다. 공격자가 임의의 입력 _x_ ∈ ℝ^{ _d_0 } 을 질의할 수 있는 전정의역 입력(full-domain input), 신경망이 64비트 부동소수점으로 지정·평가되는 정밀 계산(precise computation), 그리고 모든 활성 함수가 ReLU라는 가정이다. 공격자는 입력 차원 _d_0_ 와 출력 차원 _d_n+1_ 만 알고 은닉 층의 종류와 하이퍼파라미터는 모른다.

복원 범위 자체도 제한적이다. 이 논문은 합성곱 층의 아키텍처 복원에 집중하며, fully connected 층의 폭 복원은 기존 방법 [4,11,19,20]에 위임한다. 즉 완전한 프레임워크는 두 경로의 조합으로만 성립한다. 또한 Proposition 3을 근거로 이후 논의를 단일 입력 채널로 단순화하며, Proposition 1의 PSP 증명은 일반적(generic) 커널에서 중첩 영역의 상쇄가 일어나지 않는다는 조건에 기댄다. 깊은 층 점을 걸러내는 필터 중 하나는 두 개 이상의 RPCP가 있을 때 올바른 목표 층 RPCP 집합을 남길 수 있다고 하며, 깊은 층 점 두 개가 같은 복원 벡터를 주는 상황은 층 _L_ 과 _L′_ 사이의 풀링이 max pooling이 아닐 때만 발생한다 [16]. 스트라이드 복원은 충분히 조밀한 표본 추출을 전제하고, max pooling 스트라이드 복원은 남은 PSP가 인접한 두 풀링 윈도 앵커를 포함할 때 성립한다. 실험에서 기존 공격과 비교 가능한 모델은 두 개의 합성곱 층을 가진 (2+1)·(2+2) CNN이고, 하이퍼파라미터 다양성 검증은 저자들이 직접 설계한 (3+1) CNN 한 개에 대한 시각화로 제시된다.

## 결론

저자들은 CNN의 아키텍처 복원 연구를 처음으로 개시했다. 합성곱 층에 초점을 맞추어, 각 층의 파라미터보다 먼저 그 층의 아키텍처를 복원하는 공격을 제안했고, fully connected 층에 대한 기존 방법과 결합해 CNN에 대한 완전한 암호해독적 추출 프레임워크를 완성했다. 접근의 토대는 복원 벡터가 자신의 공간 구조 안에 아키텍처를 드러낸다는 직접적 관찰이며, 저자들은 합성곱 수용영역과의 희소성 일치, 커널 파라미터와의 수치 일치, 풀링 연산과의 구조 일치라는 세 신호를 식별해 층 종류, 커널 크기와 스트라이드, 패딩 모드, 출력 채널 수, 풀링 구조를 복원했다. 다양한 하이퍼파라미터를 가진 목적 설계 모델과 기존 공격이 채택한 모델들에 대한 실험이 공격의 유효성을 검증했다.

이 결과는 fully connected 네트워크에 대해 확립된 아키텍처 복원 결과를 보완한다. 기존 방법은 fully connected 네트워크의 층 폭을 파라미터와 함께 복원하는 데 반해, 이 논문은 CNN 합성곱 층의 아키텍처가 복원된 가중치 벡터의 공간적 기하 구조에 의해 직접 드러남을 보인다. 두 경로가 각각 fully connected 층과 합성곱 층을 담당하며, 함께 CNN의 암호해독적 추출에서 아키텍처 사전 지식이라는 전제를 제거한다. 아키텍처 복원이 피드백 설정과 무관하고 모듈화되어 있어 기존 파라미터 복원 공격에 그대로 결합되고 추가 비용이 상수에 머문다는 점은, 아키텍처와 파라미터를 동시에 복원하는 일이 실용적임을 뜻한다.
