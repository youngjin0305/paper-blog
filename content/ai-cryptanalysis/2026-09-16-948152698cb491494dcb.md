# s-MDM: Generative Virtualization of Multi-Device Hardware Variations for Portable DL-SCA

[원문](https://arxiv.org/abs/2609.18783v1) · [PDF](https://arxiv.org/pdf/2609.18783v1)

## 한눈에 보기

딥러닝 부채널 분석(DL-SCA)이 보지 못한 하드웨어로 옮겨갈 때 성능이 급락하는 이식성 문제를 다루며, 타깃 장치 트레이스를 전혀 쓰지 않고 소스 장치만으로 가상 장치 스타일을 합성하는 생성 프레임워크 s-MDM을 제안한다. AES_PTv2 벤치마크에서 전기적 복제 보드(D4)는 물리적 MDM이 우수한 반면, 레이아웃·계측이 달라진 Piñata 타깃에서는 s-MDM이 세 시드 모두 GE ≤ 3.3으로 안정적인 키 복구를 보였다.

## 초록

딥러닝 기반 부채널 분석(DL-SCA)은 인쇄회로기판(PCB) 배선 차이, 실리콘 공정 편차, 측정 잡음 변화로 인해 처음 보는 하드웨어에서 치명적인 성능 저하를 자주 겪는다. 본 포스터는 장치 간 이식성을 개선하기 위해 설계된 제로-타깃-트레이스 생성 프레임워크인 합성 다중 장치 모델(Synthetic Multiple Device Model, s-MDM)을 제시한다. s-MDM은 구조화된 cVAE 생성기, Walsh–Hadamard 누설 앵커, 연속적 스타일 변조, 그리고 분리된 누설–스타일–도메인 크리틱을 결합하여 가상의 소스 장치 프로파일을 오프라인에서 합성한다. 32비트 부채널 트레이스(AES_PTv2)를 대상으로 벤치마크한 결과, s-MDM은 정확한 동작 경계를 규명한다. 즉, 전기적으로 동일한 복제 장치(D4)에서는 물리적 MDM이 여전히 우수한 반면, 레이아웃/획득 조건이 달라진 Piñata 타깃에서는 물리적 기준선이 불안정하거나 정렬되지 않는 데 비해 s-MDM이 일관되게 낮은 키 순위를 달성한다.

## 필요성

DL-SCA는 암호 구현을 효율적으로 깨뜨리지만 [3], 분류기는 처음 보는 타깃 하드웨어에서 심각한 성능 저하를 겪는다. 공정 편차, PCB 배선 차이, 잡음 이동이 물리적 누설 분포 자체를 바꾸는 *이식성 문제(portability problem)* 때문이다 [1, 8].

기존 해법은 운영상 제약이 크다. 첫째, 물리적 다중 장치 모델링(MDM)은 여러 보드로 이루어진 물리 플릿 전체에서 분류기를 학습해 플릿 불변 특징을 배우고 단일 보드의 특성은 잡음으로 취급하지만 [1], 물리 플릿을 조달하고 프로파일링하는 데 막대한 비용과 물류 부담이 든다 [1]. 둘째, CDPA [4]나 UDA 파인튜닝 [9] 같은 타깃 보조 도메인 적응은 하드웨어 간 특징을 정렬하지만, 프로파일링 단계에서 타깃 장치의 레이블 없는 트레이스를 반드시 확보해야 하며 이는 비허용적(non-permissive) 상황에서 실현 불가능하다 [6, 8].

## 연구 분야 흐름

MDM [1] 이후의 이식성 연구는 장치 간 특징 분포를 정렬하는 방향으로 전개되었다. 교차 장치 프로파일링 공격(CDPA) [4], MMD 최소화 [9], 적대적 도메인 학습 [5, 10]이 여기에 속하는데, MDM과 달리 이들은 프로파일링 중 피해 장치의 레이블 없는 트레이스를 요구한다 [4, 8, 9].

한편 생성 모델 기반 SCA는 데이터 증강 [7], 단항식 기저 위에서의 명시적 잡음–누설 인수분해(cVAE-SA [11], cVAE-OSM [2]), 화이트박스 참조 특징을 블랙박스 타깃으로 전이하는 방식(CGAN-SCA [6]) 등으로 발전해 왔다. 기존 생성형 SCA 구조는 대체로 도메인 전이를 위해 피해 장치 측정치에 의존하거나 [5, 6], 서로 다른 하드웨어 구성을 아우르지 못한 채 단일 물리 장치 내 잡음 모델링에 머물렀다 [2, 11]. s-MDM은 이와 대조적으로 소스 장치 트레이스만 사용해 배포 이전에 가상 장치 스타일 변동을 합성한다.

## 관련 연구

- **물리적 MDM [1]**: 복수 보드 학습으로 플릿 불변 특징 확보. 물리 장치 확보 비용이 병목.
- **CDPA [4], UDA 파인튜닝 [9], 적대적 도메인 학습 [5, 10]**: 특징 분포 정렬 기반 교차 장치 공격. 타깃(피해) 장치의 비레이블 트레이스가 필수.
- **GAN 기반 증강 [7]**: 소형 장치용 트레이스 데이터 증강.
- **cVAE-SA [11], cVAE-OSM [2]**: 확률적 공격 및 조건부 VAE로 잡음과 누설을 구조적으로 분리하고 차원을 축소. s-MDM 생성기의 백본.
- **CGAN-SCA [6]**: 조건부 GAN으로 화이트박스 참조 특징을 블랙박스 타깃에 전이.
- **DL-SCA 일반 [3, 8]**: CNN과 데이터 증강을 통한 지터 대응, 그리고 물리 부채널 분석의 체계화.

## 배경 지식

**누설 분해.** s-MDM은 cVAE-OSM [2]의 구조적 누설 인수분해를 토대로, 원시 트레이스 관측 벡터 T ∈ R^D를 세 항의 합으로 모델링한다: 결정론적 AES 종속 누설 템플릿 Ψ(Y), 잠재 코드 z와 이분산 분산 σ²로 표현되는 확률적 내용 변동 N_content(z, σ²), 그리고 장치별 물리 스타일 서명 N_style(z_style)이다. 여기서 Ψ(Y) = b(Y)ᵀW_ψ이며, b(Y)는 8비트 중간값 Y의 256차원 Walsh–Hadamard 기저 표현이고 [2], 스타일 코드는 연속적인 16차원 벡터다.

**주요 구성 요소.** FiLM(Feature-wise Linear Modulation)은 트레이스 길이 크기의 스케일 벡터 γ와 시프트 벡터 β로 잔차 잡음 경로를 변조하는 기법이며, 경사 반전 계층(GRL)은 순전파에서는 항등 사상이지만 역전파에서 기울기 부호를 뒤집어(∂R_λ/∂φ = −λI) 보드 식별 특징을 억제하는 장치 불변 표현 학습 도구다.

**평가 지표.** 추측 엔트로피 GE는 정답 키의 0 기반 평균 순위, 성공률 SR은 순위 0에 도달한 실행 비율이다. 256개 키 기준 무작위 수준은 GE_rand = 127.5이며, 이보다 큰 값은 역상관(무작위보다 나쁜) 순위를 뜻한다. 장치 특성은 누설 피크 샘플 인덱스, 피크 SNR, ρ = SNR/(1 + SNR)로 기술된다.

## 문제 정의

목표는 **제로-타깃-트레이스 장치 효율적 이식성(device-efficient portability)** 이다. 즉, 타깃 장치에서 어떠한 트레이스도 학습·적응·검증·증강에 사용하지 않은 채, 가용한 프로파일링 장치만으로 생성 모델을 학습하고 이를 오프라인에서 가상 장치 스타일 합성에 사용해 하류 공격 분류기를 더 넓은 범위의 물리적으로 타당한 누설 조건에 노출시키는 것이다. 최종 타깃 장치는 학습과 검증 전 구간에서 완전히 미관측 상태로 유지되어야 한다.

이 조건을 지키기 위해 s-MDM은 밀봉된(sealed) 타깃 평가를 오염시키지 않도록 LOBO(Leave-One-Board-Out) 검증 프로토콜을 사용한다. 소스 보드로 학습하고 소스 장치 계열에서 남겨 둔 보드를 의사 타깃(pseudo-target)으로 삼아 검증하며, 이 보드가 SNR_Ψ, 추측 엔트로피, 성공률 같은 누설 충실도 진단과 체크포인트 선택을 위한 이식성 프록시 역할을 한다. 실제 공격 시에는 생성기와 모든 적대적 크리틱을 폐기하고, 타깃 트레이스를 학습된 분류기 C_θ에 직접 입력해 p(Y | T_target)를 얻은 뒤 키 랭킹을 수행한다.

## 주요 기여

- **생성적 가상화 프레임워크**: 최소한의 소스 하드웨어로부터 연속적인 합성 장치 매니폴드를 구성한다. 학습이 끝나면 생성기를 동결하고, 확장된 잠재 포락선 z_style ∼ N(0, αI), α = 1.5에서 스타일 코드를 샘플링해 관측된 소스 보드 외형을 보간하고 완만히 외삽하는 가상 플릿을 만든다. 최종 학습 집합은 실제 프로파일링 데이터와 s-MDM 합성 데이터의 합집합이다.
- **하이브리드 cVAE-GAN 구조**: 기저 투영 모델링 [2, 11]을 경사 반전 계층(GRL), 연속적 스타일 변조, 분리된 크리틱으로 확장해 결정론적 누설과 물리적 스타일 변동을 분리한다. 구조화된 cVAE 생성기는 Ψ(Y) 부분공간을 엄격히 고정해 최적화 중 특징 표백(feature bleaching)을 막고, 비밀값을 모르는 블라인드 인코더가 추출한 스타일 코드로 FiLM 변조를 수행하며, D_style(물리적 현실성), D_leak(암호학적 정렬), D_domain(장치 불변성)의 세 크리틱이 각각의 역할을 담당한다.
- **동작 경계의 실증적 규명**: AES_PTv2 상에서 물리적 풀링과 합성 가상화 사이의 경계를 특성화했다. 전기적 복제 타깃 D4(SNR = 0.224, ρ = 0.183)에서는 물리적 MDM이 109 트레이스로 완전 복구해 우수했고 s-MDM은 평가 예산 내에 수렴하지 못했다. 반대로 레이아웃/획득이 이동한 Piñata(SNR = 2.796, ρ = 0.737)에서는 단일 장치 학습이 실패하고 2장치 학습은 시드 민감하며 물리적 MDM은 무작위보다 나쁜 순위를 보인 반면, s-MDM은 세 시드에서 GE = 0.42, 0.69, 3.28로 복구에 성공했다. 절제 실험에서는 연속적 스타일 다양성 제거만이 시드 변동 범위를 벗어난 성능 저하(GE = 7.39, SR 0.71 → 0.33)를 일으켜, 해당 요소가 유일하게 분해 가능한 기여 요인으로 확인되었다.

## 제시한 방법론

s-MDM(Synthetic Multiple Device Model)은 타깃 장치의 트레이스를 단 한 개도 사용하지 않는(zero-target-trace) 이식성 확보를 목표로 한다. 타깃의 비라벨 트레이스를 요구하는 도메인 적응 계열[4, 9]과 달리, 확보 가능한 프로파일링 장치들만으로 생성 모델을 학습한 뒤 이를 오프라인에서 가상 장치 스타일 합성기로 사용한다. 설계 의도는 배포 이전에 하위 공격 분류기를 물리적으로 그럴듯한 더 넓은 범위의 누설 조건에 노출시키되, 최종 타깃 장치는 학습·검증 전 과정에서 완전히 미관측 상태로 봉인해 두는 것이다.

### 누설 분해

원시 트레이스 관측 벡터 $\mathbf{T} \in \mathbb{R}^{D}$를 cVAE-OSM[2]의 구조적 누설 인수분해를 토대로 다음과 같이 분해한다.

$$\mathbf{T} = \Psi(Y) + N_{\text{content}}(\mathbf{z}, \boldsymbol{\sigma}^2) + N_{\text{style}}(\mathbf{z}_{\text{style}})$$

- $\Psi(Y) = b(Y)^{\top} \mathbf{W}_{\psi}$는 AES 중간값에 의존하는 결정론적 누설 템플릿이며, $b(Y)$는 8비트 중간값 $Y$의 256차원 Walsh–Hadamard 기저 표현이다[2].
- $N_{\text{content}}(\mathbf{z}, \boldsymbol{\sigma}^2)$는 잠재 코드 $\mathbf{z}$와 이분산(heteroscedastic) 분산 $\boldsymbol{\sigma}^2$로 확률적 콘텐츠 변동을 모델링한다.
- $N_{\text{style}}(\mathbf{z}_{\text{style}})$는 연속적인 16차원 스타일 코드로 장치 고유의 물리적 스타일 서명을 모델링한다.

### 하이브리드 cVAE-GAN 구조

위 분해를 cVAE와 GAN 비평자(critic)를 결합한 하이브리드 구조로 구현한다. cVAE의 구조적 밀도 모델링에 적대적 피드백을 더해 VAE 특유의 파형 블러링을 우회하려는 설계 선택이다. 생성기는 실행 콘텐츠와 스타일을 분리하고, 세 개의 분리된(decoupled) 비평자 $D_{\text{style}}$, $D_{\text{leak}}$, $D_{\text{domain}}$이 각각 물리적 사실성, 암호학적 정렬, 장치 불변성을 강제한다. 핵심 구성 요소는 네 가지다.

**(1) 구조적 cVAE 생성기.** cVAE-OSM 백본[2] 위에서 콘텐츠 인코더가 $q_{\phi}(\mathbf{z} \mid \mathbf{T}, b(Y))$와 이분산 잔차 분산 $\boldsymbol{\sigma}^2$를 추정한다. 결정론적 부분공간 $\Psi(Y) = b(Y)^{\top}\mathbf{W}_{\psi}$는 최적화 도중 특징이 표백(feature bleaching)되는 것을 막기 위해 엄격히 고정(anchor)된다.

**(2) 연속 스타일 변조.** 비밀값을 모르는(secret-unaware) 블라인드 인코더가 파형의 물리적 외형을 포착하는 스타일 코드 $\mathbf{z}_{\text{style}}$를 추출한다. 디코더는 FiLM(Feature-wise Linear Modulation)으로 잔차 노이즈 경로를 변조해 트레이스를 재렌더링한다.

$$\widetilde{\mathbf{T}} = \Psi(Y) + \boldsymbol{\gamma}(\mathbf{z}_{\text{style}}) \odot N_{\text{content}}(\mathbf{z}, \boldsymbol{\sigma}^2) + \boldsymbol{\beta}(\mathbf{z}_{\text{style}})$$

여기서 $\boldsymbol{\gamma}$와 $\boldsymbol{\beta}$는 트레이스 길이의 스케일·시프트 벡터다. 즉 첫 식의 스타일 항은 실제 구현에서 $N_{\text{style}}(z_{\text{style}}) = (\gamma(z_{\text{style}}) - 1) \odot N_{\text{content}} + \beta(z_{\text{style}})$로 실현된다. 개념적 분해식과 구현 디코더의 대응을 명시한 점이 특징이다.

**(3) 분리된 적대적 비평자.** $D_{\text{style}}$은 비밀값과 무관하게 물리적 파형 형태만을 평가한다. 동시에 누설 비평자

$$D_{\text{leak}}(\mathbf{T}, Y) = \psi(\phi(\mathbf{T})) + \phi(\mathbf{T})^{\top} \mathbf{V} b(Y)$$

가 CNN 특징 맵 $\phi(\mathbf{T})$로 하여금 트레이스–라벨 간 암호학적 정렬을 유지하도록 강제한다.

**(4) GRL 도메인 안전장치.** 도메인 헤드 $D_{\text{domain}}$이 $\phi(\mathbf{T})$로부터 프로파일링 보드 ID를 예측하고, 그 앞단의 Gradient Reversal Layer가 순전파에서는 항등 사상 $\mathcal{R}_{\lambda}(\phi(\mathbf{T})) = \phi(\mathbf{T})$, 역전파에서는 $\frac{\partial \mathcal{R}_{\lambda}}{\partial \phi} = -\lambda I$로 기울기를 반전시켜 보드 식별 특징에 벌점을 주고 장치 불변 표현을 유도한다.

### 연속 매니폴드 가상화와 배포 절차

학습이 끝나면 생성기를 동결하고 오프라인 가상 장치 합성기로만 사용한다. 관측된 프로파일링 스타일에서만 샘플링하지 않고, 확장된 잠재 포락선 $\mathbf{z}_{\text{style}} \sim \mathcal{N}(0, \alpha I)$, $\alpha = 1.5$에서 스타일 코드를 뽑아 $Y$ 및 콘텐츠 잠재와 함께 위 FiLM 식에 투입한다. $\alpha > 1$로 둔 이유는 관측된 소스 보드 외형들 사이를 보간할 뿐 아니라 그 바깥으로 완만히 외삽하는 스타일 다양성 확보를 위해서다. 그 결과 만들어진 가상 플릿을 실제 프로파일링 데이터와 합쳐 $\mathcal{D}^{\text{attack}}_{\text{train}} = \mathcal{D}^{\text{profiling}}_{\text{real}} \cup \mathcal{D}^{\text{s-MDM}}_{\text{synthetic}}$로 하위 공격 분류기 $C_{\theta}$를 오프라인 학습한다. 실제 키 복구 단계에서는 생성기와 모든 적대적 비평자를 폐기하고 타깃 트레이스를 분류기에 직접 투입한다: $\mathbf{T}_{\text{target}} \rightarrow C_{\theta}(\mathbf{T}_{\text{target}}) \rightarrow p(Y \mid \mathbf{T}_{\text{target}}) \rightarrow$ 키 랭킹.

### LOBO 검증 프로토콜

봉인된 타깃 평가가 오염되지 않도록 Leave-One-Board-Out(LOBO) 검증을 사용한다. 소스 보드들로 학습하고, 소스 장치 계열에서 떼어낸 한 보드를 유사 타깃(pseudo-target)으로 삼아 검증한다. 이 홀드아웃 보드는 학습 체크포인트 선택과 $\mathrm{SNR}_{\Psi}$, guessing entropy, success rate 같은 누설 충실도 진단의 이식성 프록시 역할을 한다. 최종 타깃은 마지막 배포 평가 시점까지 완전히 미관측 상태로 유지되며, 생성기의 학습·적응·검증·증강 어디에도 타깃 트레이스가 쓰이지 않는다. 모델 입력 측면에서는 모든 트레이스를 각 장치의 누설 피크 주변에서 공통 120 샘플 폭으로 크롭해 장치별 특성 창 차이를 흡수한다.

## 실험 및 평가

### 실험 설정과 장치 구성
평가는 보호되지 않은 32비트 소프트웨어 AES-128 구현을 대상으로 AES_PTv2 부채널 트레이스 인프라 위에서 수행되었다. 장치 풀은 명목상 동일한 STM32F411E-DISCO 보드 4개(_D_1–_D_4)와 이와 구별되는 Riscure Piñata 보드 1개로 구성된다. _D_1–_D_4는 STM32F411VE Cortex-M4 플랫폼이며 침습성이 낮지만 잡음이 큰 EM 측정 환경에서 수집되고, Piñata는 전원망이 변경된 Cortex-M4F 기반 학습용 보드로 더 깨끗한 직접 전력 측정을 사용한다. 역할 분담은 _D_1·_D_2를 프로파일링, _D_3을 LOBO(Leave-One-Board-Out) 검증용 의사 타깃, _D_4를 미관측 전기적 클론 타깃, Piñata를 레이아웃/획득 조건이 이동한 타깃으로 두는 방식이다. 모델 입력을 위해 모든 트레이스는 각 장치의 누출 피크를 중심으로 공통 120 샘플 폭으로 잘라 사용한다.

### 장치 물리 특성
각 장치는 누출 피크 샘플 인덱스, 피크 SNR, ρ = SNR/(1+SNR), 장치별 특성화 윈도로 기술된다. 프로파일링 보드는 잡음 지배적이며 _D_1은 피크 인덱스 48, SNR 0.077, ρ 0.072이고 _D_2는 인덱스 63, SNR 0.135, ρ 0.119이다. 검증용 _D_3은 인덱스 39, SNR 0.260, ρ 0.206, 클론 타깃 _D_4는 인덱스 39, SNR 0.224, ρ 0.183이다. 반면 Piñata는 인덱스 104에서 SNR 2.796, ρ 0.737로 신호 지배적 영역에 속해, 통상적인 클론 간 변동이 아니라 실질적인 레이아웃/획득 이동에 해당한다.

### 평가 지표와 비교 대상
지표는 정답 키의 0-기반 평균 순위인 추측 엔트로피(GE)와 순위 0에 도달한 실행 비율인 성공률(SR)이며, 수렴에 필요한 트레이스 수도 함께 보고한다. 256개 키 가정에서 무작위 기준은 GE_rand = 127.5이고, 이보다 큰 값은 반상관(무작위보다 나쁜) 순위를 의미한다. 베이스라인은 단일 장치 학습, 2개 장치 학습, 그리고 물리 3개 보드를 모두 쓰는 Physical MDM [1]이다.

### 매니폴드 내부 평가: 전기적 클론 _D_4
클론 타깃 _D_4에서는 물리적 풀링이 최적이었다. Physical MDM은 109개 트레이스에서 완전 복원에 도달했고(GE 0.00, SR 1.00), 2개 장치 베이스라인은 586개 트레이스에서 복원했다. 단일 장치 학습은 GE 18.36, SR 0.16에 머물렀다. s-MDM(Full)은 GE 5.72, SR 0.21로 단일 장치 학습보다는 개선되었으나 주어진 트레이스 예산 내에서 수렴하지 못했다. 타깃이 소스 매니폴드 내부에 있는 상황에서는 실제 다중 장치 트레이스가 합성 재렌더링보다 정보량이 많고, 생성기가 이식성 이득이 아니라 압축 병목처럼 작동한다는 해석이다.

### 매니폴드 외부 평가: 레이아웃/획득 이동(Piñata)
이점은 서포트 밖 설정에서 나타난다. 3개의 독립 난수 시드 실험에서 단일 장치 학습은 GE 36.32, 18.00, 16.95로 복원에 실패했고, 2개 장치 학습은 시드에 매우 민감해 불안정했으며, Physical MDM은 세 시드 모두 무작위 기준보다 나쁜 반상관 순위를 보였다. 반면 s-MDM(Full)은 GE 0.42, 0.69, 3.28로 모든 시드에서 GE ≤ 3.3의 낮은 값을 유지하며 키를 복원했다. 저자들은 연속 스타일 가상화가 배포 전에 분류기를 더 넓은 누출 형태에 노출시켜 저SNR 프로파일링 보드 형태에 대한 의존을 줄인 결과로 해석한다.

### 구성 요소 제거 실험
Piñata 타깃에서 구성별 단일 학습 실행으로 ablation을 수행했다. 완전 구성은 GE 0.42, SR 0.71, 누출 충실도 SNR_Ψ 0.057이다. 연속 스타일 다양성을 제거하면 GE 7.39, SR 0.33(SNR_Ψ 0.058)으로, 세 시드에서 관측된 완전 구성 범위(GE 0.42–3.28)를 벗어나 유일하게 분해 가능한 성능 저하를 보였다. 장치 불변성 제거는 GE 0.56, SR 0.81, 적대적 크리틱 제거는 GE 0.03, SR 0.97, 부분공간 앵커 제거는 GE 0.43, SR 0.80으로 모두 시드 산포 범위 안에 들어가 개별적으로 판별되지 않았다. 특히 크리틱 제거가 이 실행에서 GE 0.03을 기록했지만, 다중 시드 반복 없이는 완전 모델 대비 확정적 개선으로 볼 수 없다고 명시한다.

## 고찰

### 제안 방법의 구조적 의미

s-MDM은 대상 장치의 트레이스를 전혀 사용하지 않는(zero-target-trace) 조건에서 DL-SCA의 이식성 문제를 다루려는 시도다. 기존 이식성 연구는 크게 두 갈래로 나뉘는데, 하나는 물리적으로 여러 보드를 확보해 fleet 불변 특징을 학습하고 단일 보드 고유 특성을 잡음으로 취급하는 물리적 MDM [1]이고, 다른 하나는 CDPA [4]나 MMD 최소화 기반 미세조정 [9], 적대적 도메인 학습 [5, 10]처럼 프로파일링 단계에서 레이블 없는 피해 장치 트레이스를 요구하는 도메인 적응 계열이다. 전자는 보드 확보와 측정에 따르는 비용·물류 부담이 크고, 후자는 공격자가 대상 장치에 접근할 수 없는 비허용 시나리오에서는 전제 자체가 성립하지 않는다 [6, 8]. s-MDM은 소스 장치 트레이스만으로 생성 모델을 학습한 뒤 이를 오프라인 가상 장치 합성기로 사용해, 배포 전에 분류기가 더 넓은 범위의 물리적으로 타당한 누설 조건을 보도록 만든다는 점에서 두 계열의 제약을 동시에 피하려 한다.

방법론의 핵심은 누설 분해다. 원시 트레이스 T를 결정적 AES 의존 누설 템플릿 Ψ(Y), 확률적 내용 변동 N_content(z, σ²), 장치별 물리 스타일 서명 N_style(z_style)의 합으로 모델링하며, Ψ(Y)는 8비트 중간값 Y의 256차원 Walsh–Hadamard 기저 표현 b(Y)에 가중치 W_ψ를 곱한 형태로 cVAE-OSM [2] 계열의 구조화된 누설 인자화를 계승한다. 이 결정적 부분공간은 최적화 중 특징이 희석되는 것을 막기 위해 고정(anchored)된다. 구현 단계의 디코더는 스타일 항을 별도 가산항으로 두지 않고, 16차원 연속 스타일 코드로부터 얻은 스케일·이동 벡터 γ, β를 잔차 내용 잡음 경로에 FiLM 방식으로 곱하고 더하는 형태로 실현한다. 즉 개념적 분해식과 실제 디코더의 관계가 N_style(z_style) = (γ(z_style) − 1) ⊙ N_content + β(z_style)로 명시된다. 스타일 인코더는 비밀값을 모르는(secret-unaware) 블라인드 구조이며, 세 개의 분리된 비평자가 각각 다른 제약을 담당한다. D_style은 비밀값과 무관하게 파형 형태의 물리적 현실성을, D_leak은 CNN 특징 맵 φ(T)가 트레이스–레이블 간 암호학적 정렬을 유지하도록, 그리고 도메인 헤드 D_domain은 Gradient Reversal Layer(역전파 시 기울기가 −λI로 반전)를 통해 보드 식별 특징을 억제해 장치 불변 표현을 유도한다. cVAE의 구조화된 밀도 모델링에 GAN 계열 비평자의 적대적 피드백을 결합한 이유는 VAE 특유의 파형 흐림(blurring)을 우회하기 위한 것으로 제시된다.

학습이 끝나면 생성기를 동결하고, 관측된 프로파일링 스타일에만 국한하지 않고 확장된 잠재 포락선 z_style ∼ N(0, αI), α = 1.5에서 스타일 코드를 샘플링해 가상 fleet을 합성한다. 이렇게 실제 프로파일링 데이터와 합성 데이터를 합친 집합으로 하위 공격 분류기 C_θ를 학습하고, 실제 공격 시점에는 생성기와 모든 비평자를 폐기하고 대상 트레이스를 분류기에 직접 넣어 키 순위를 산출한다. 평가 오염을 막기 위해 Leave-One-Board-Out(LOBO) 프로토콜을 채택해 소스 계열의 보류 보드를 의사 대상으로 삼아 체크포인트 선택과 SNR_Ψ, 추측 엔트로피, 성공률 같은 누설 충실도 진단에 사용하고, 최종 대상은 배포 평가 시점까지 봉인한다.

### 실험 결과의 해석

평가는 보호되지 않은 32비트 소프트웨어 AES-128 엔진과 AES_PTv2 트레이스 인프라 위에서 수행되었다. 장치 fleet은 명목상 동일한 STM32F411E-DISCO 보드 네 개(D1–D4)와 구조가 다른 Riscure Piñata 보드 하나로 구성된다. D1–D4는 STM32F411VE Cortex-M4 플랫폼이며 잡음이 있는 비침습적 EM 측정으로 획득되고, Piñata는 전원망이 변경된 Cortex-M4F 기반 보드로 더 깨끗한 직접 전력 측정이 사용된다. 역할은 D1·D2 프로파일링, D3 LOBO 검증, D4 미공개 전기적 클론 대상, Piñata 레이아웃/획득 이동 대상으로 배분되었고, 모든 트레이스는 장치별 누설 피크 주변을 공통 120 샘플 폭으로 크롭해 입력한다. 물리적 특성표를 보면 프로파일링 보드는 강하게 잡음 지배적이다(D1 피크 SNR 0.077, ρ = 0.072; D2 0.135/0.119). 검증 보드 D3는 0.260/0.206, 클론 대상 D4는 0.224/0.183이다. 반면 Piñata는 피크 인덱스 104에서 SNR 2.796, ρ = 0.737로 신호 지배 영역에 놓이며, 이는 통상적인 클론 간 변동이 아니라 상당한 레이아웃/획득 이동에 해당한다고 해석된다.

전기적 클론 D4에서는 물리적 풀링이 우월했다. 물리적 MDM은 109 트레이스에서 완전 복구에 도달했고 2-장치 기준선은 586 트레이스에서 도달했다. 단일 장치 학습은 GE 18.36, SR 0.16으로 실패했으며, s-MDM(Full)은 GE 5.72, SR 0.21로 단일 장치보다는 개선되었으나 평가된 트레이스 예산 내에서 수렴하지 못했다. 저자들은 대상이 소스 매니폴드 내부에 있는 클론 설정에서는 실제 다중 장치 트레이스가 합성 재렌더링보다 더 정보량이 많고, 이 경우 생성기가 이식성 이점이 아니라 압축 병목처럼 작동한다고 해석한다.

반대로 매니폴드 외부 설정인 Piñata에서 이점이 드러난다. 무작위 기준은 GE_rand = 127.5(256 키)이며 그보다 큰 값은 무작위보다 나쁜 역상관 순위를 뜻한다. 세 개의 독립 시드에서 단일 장치는 36.32/18.00/16.95로 복구 실패, 2-장치는 25.50/0.98/235.47로 시드 민감도가 극심한 불안정, 물리적 MDM은 146.36/239.07/243.79로 무작위보다 나쁜 역상관을 보였다. s-MDM(Full)은 0.42/0.69/3.28로 세 실현 모두 GE ≤ 3.3의 낮은 추측 엔트로피를 달성했다. 저자들은 연속 스타일 가상화가 배포 전에 분류기를 더 넓은 누설 외형에 노출시켜 프로파일링 보드의 저SNR 형태에 대한 의존을 줄인 결과로 본다.

절제 실험은 Piñata 대상에서 구성별 단일 학습 실행으로 수행되었다. 완전 구성은 GE 0.42, SR 0.71, 충실도 SNR_Ψ 0.057이며, 연속 스타일 다양성을 제거하면 GE 7.39, SR 0.33으로 악화된다. 장치 불변성 제거는 0.56/0.81, 부분공간 앵커 제거는 0.43/0.80, 적대적 비평자 제거는 0.03/0.97로 나타났다. 시드 간 변동 범위(GE 0.42–3.28)를 보정 기준으로 삼으면 그 범위를 벗어나 해소 가능한 성능 저하를 일으키는 구성 요소는 스타일 다양성뿐이고, 나머지 절제는 시드 산포 안에 들어가 개별적으로 분해되지 않는다. 특히 비평자 제거가 해당 실행에서 GE 0.03을 얻었더라도 다중 시드 반복 없이는 완전 모델에 대한 확정적 개선으로 볼 수 없다고 저자들은 못 박는다.

### 한계와 논의

원문이 스스로 제시하는 한계는 명확하다. 첫째, 대상이 소스 매니폴드 내부에 있는 클론 상황(D4)에서는 물리적 MDM이 여전히 우수하므로 s-MDM은 만능 대체물이 아니라 적용 경계가 있는 기법이다. 둘째, 절제 실험이 구성별 단일 실행에 기반해 비평자와 도메인 불변성, 부분공간 앵커의 역할을 통계적으로 분리하지 못했고, 다중 시드 반복이 필요하다. 셋째, 평가 범위가 보호되지 않은 32비트 소프트웨어 AES-128, 네 개의 클론 보드와 한 개의 이질 보드라는 제한된 fleet에 한정된다. 또한 D4에서 s-MDM이 평가된 트레이스 예산 내에 수렴하지 않았다는 점도 보고된 대로 미해결 상태다. 향후 과제로는 비평자 최적화 개선, 스타일 사전(prior)의 보정, 더 큰 다중 보드 fleet에 대한 평가가 제시된다.

## 결론

s-MDM은 대상 장치 트레이스를 전혀 쓰지 않는 생성적 가상화만으로도 심한 레이아웃·획득 이동 하에서 DL-SCA의 이식성 병목을 개선할 수 있음을 보였다. 전기적 클론 대상 D4에서는 물리적 MDM이 우월하며, 이는 대상이 소스 매니폴드 안에 있을 때 합성 재렌더링이 정보 필터로 작동함을 뜻한다. 반면 Piñata에서는 물리적 기준선이 불안정하거나 역상관을 보이는 가운데 s-MDM만이 낮은 GE에 도달했다. 절제 결과는 연속 스타일 다양성을 해소 가능한 성능 저하를 유발하는 유일한 구성 요소로 지목하며, 비평자들의 역할은 다중 시드 반복 검증을 필요로 한다. 결국 이 포스터의 기여는 물리적 다중 장치 모델링이 여전히 선호되는 영역과 합성 가상화가 일반화를 개선하는 영역 사이의 운영 경계를 AES_PTv2 상에서 경험적으로 특성화한 데 있다.
